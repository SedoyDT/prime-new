# Obsidian Kanban Desk

Система для управления:

- идеями
    
- разработкой
    
- AI-проектами
    
- состояниями
    
- обучением
    
- долгими задачами
    

Потому что человеческий мозг отлично умеет придумывать 400 направлений одновременно и потом смотреть в стену от перегруза.

# Принципы системы

## 1. Inbox обязателен

Все идеи сначала летят туда.  
Не хранить задачи в голове.  
Мозг плох как RAM.  
Особенно человеческий.

---

## 2. Today должен быть маленьким

Не больше:

- 1 тяжелой задачи
    
- 2 средних
    
- нескольких мелких
    

Иначе Kanban превращается в музей чувства вины.

---

## 3. Deep Work отдельно

Сложные задачи не должны смешиваться с бытовыми.

"Починить Docker" и "купить соль" не равны когнитивно.  
Хотя иногда Docker ведет себя как проклятая кухонная техника.

---

## 4. Experiments важны

Отдельная колонка для:

- безумных идей
    
- AI-экспериментов
    
- нестандартных решений
    

Это поддерживает интерес к системе.

# Рекомендуемый Workflow

## Утро

1. Открыть Daily Note
    
2. Проверить Main Board
    
3. Выбрать одну главную задачу
    
4. Убрать шум
    

---

## День

- Inbox → сортировка
    
- Deep Work → фокус
    
- Learning → исследование
    

---

## Вечер

- Переместить Done
    
- Записать идеи
    
- Зафиксировать состояние

# Идея высокого уровня

Тебе нужна не просто todo-система.

Тебе нужен:

- внешний мозг
    
- центр управления проектами
    
- cognitive dashboard
    
- система удержания фокуса
    
- журнал состояний
    
- AI operating system
    

Obsidian для этого подходит пугающе хорошо.  
Почти как будто человечество случайно собрало IDE для мышления.
