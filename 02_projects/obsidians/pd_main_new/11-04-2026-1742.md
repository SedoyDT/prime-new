Сразу честно: у Apple **нет нормального публичного API для iCloud**, поэтому «идеальный официальный скрипт» невозможен. Но есть рабочие обходные пути.

Разберём лучшие варианты для **автоматизации через скрипты** 👇

---

# 🥇 Лучший вариант для скриптов (реально используется)

## icloudpd

Это де-факто стандарт для скачивания фото/видео из iCloud.

### Что делает:

- Скачивает ВСЕ фото и видео
    
- Докачивает только новые (инкрементально)
    
- Можно запускать по cron
    
- Поддерживает 2FA
    

---

## 🔧 Установка (пример)

```bash
pip install icloudpd
```

или через Docker (ещё лучше):

```bash
docker run -it \
  -v /local/photos:/data \
  icloudpd/icloudpd:latest \
  icloudpd --directory /data
```

---

## ▶️ Запуск

```bash
icloudpd \
  --username your@appleid.com \
  --directory /data \
  --auto-delete \
  --size original
```

---

## 🔁 Автоматизация

Через cron:

```bash
0 */6 * * * icloudpd ...
```

👉 будет подтягивать новые фото каждые 6 часов

---

## ⚠️ Нюансы:

- Первый запуск — логин + 2FA
    
- Иногда Apple может временно блочить (редко)
    
- Только фото/видео (не весь iCloud)

# 🥈 Более «хакерский» вариант

## pyicloud

Это Python-библиотека для работы с iCloud.

### Можно:

- читать файлы из iCloud Drive
    
- работать с контактами
    
- частично автоматизировать загрузку
    

---

## Пример:

```python
from pyicloud import PyiCloudService

api = PyiCloudService('your@appleid.com', 'password')

for file in api.drive.dir():
    print(file)
```

---

## ❗ Но:

- API нестабильный
    
- Часто ломается при изменениях Apple
    
- Требует дописывать логику самому
    

---

# 🥉 «Инженерный» подход (самый надёжный)

## Комбо:

- iCloud for Windows
    
- - скрипт (rsync / bash / Python)
        

---

### Схема:

1. iCloud sync → локальная папка
    
2. Скрипт:
    
    - копирует файлы
        
    - сортирует
        
    - делает backup
        

---

### Пример:

```bash
rsync -av --progress ~/iCloudPhotos/ /backup/photos/
```

или авторазбор:

```bash
find /photos -type f -mtime -1 -exec cp {} /backup/new/ \;
```

---

# 💡 Какой вариант выбрать

Если коротко:

- **Фото/видео → icloudpd (лучший выбор)**
    
- **Нужно больше контроля → pyicloud**
    
- **Нужно максимально надёжно → sync + rsync**
