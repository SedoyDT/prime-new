# Права доступа

### Создание прав доступа
Создайте файл `tests/suites/default/tools/acl-export/access/amd-1.acl` со следующим содержимым:

```
ADD counteragent BRANCH auto Контрагент
ADD counteragent>access CRUD auto Доступ
ADD counteragent>excel ACCESS auto Выгрузка в Excel
```


Выполните команду:
```shell
php bin/devconsole.php amdcoru access:update-tree amd-1.acl
```

Перейдите по ссылке `/access/module` и проверьте, что создана новая ветка с правами.

### Скрытие кнопок

#### Передача набора прав на Frontend
Обновите [файл](../../application/modules/counteragent/controllers/IndexController.php) контроллера:

Добавьте параметр `access` в метод `setParams`:
```php
$this->view->getRequire()
           ->setDataMain('/js/app/application/counteragent/index/config')
           ->setParams('page.module', [
                // ...
                'access' => App_Access::get('all', 'counteragent')
            ]);
```

#### Применение прав к разметке
Для работы с правами на клиенте используется сервис `AmdAccessService`.

Добавьте импорт сервиса в [файл](../../typescript/app/application/counteragent/index/component/page.component.ts):
```ts
import {AmdAccessService} from "../../../../angular/service/amd-access.module";
```

Добавьте атрибут `ng-if` для скрытия всего блока с кнопками `Добавить`, `Редактировать`, `Удалить`:
```html
<grid-header>
    <div class="amd-grid-controls__row"
         ng-if="$ctrl.accessService.getCrud('access').isEdit()"
    >
        <!-- ... -->
    </div>
</grid-header>
```

Для применения пра доступа к кнопке `Выгрузить в Excel` необходимо переопределить её разметку.
```html
<!-- ... -->
</grid-header>

<grid-footer>
    <amd-button ng-if="$ctrl.accessService.getAccess('excel').isAllowed()"
                ng-click="$ctrl.grid.downloadExcel($event)"
    >Выгрузить в Excel</amd-button>
</grid-footer>
```

Внедрите сервис в конструкторе контроллера:
```ts
constructor(
    // ...
    @Inject(AmdAccessService) private accessService: AmdAccessService,
)
```

#### Обновление зависимостей модуля
Обновите зависимости модуля в [файле](../../typescript/app/application/counteragent/index/page.module.ts).

Добавьте импорт:
```ts
import {AMD_ACCESS_SERVICE_DATA, AmdAccessModule} from "../../../angular/service/amd-access.module";
```

Подключите зависимости:
```ts
@Module({
    imports: [
        // ...
        AmdAccessModule,
    ],
    // ...
    providers: [
        // ...
        {provide: AMD_ACCESS_SERVICE_DATA, useValue: mod.config().access},
        // ...
    ],
})
```
Перейдите по ссылке `/counteragent` и проверьте работу прав (отображение кнопок).
Измените права доступа и повторно проверьте работу прав.
