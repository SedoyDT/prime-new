На основе информации из указанных источников, вот универсальный алгоритм в виде блок-схемы для нахождения оптимальных решений:

```
НАЧАЛО
   ↓
Определить тип задачи
   ↓
/-----------------------------\
|                             |
Да → Является ли задача творческой? → Нет
|                             |
\-----------------------------/
        ↓                     ↓
  ТВОРЧЕСКИЙ ПОДХОД     ЛОГИЧЕСКИЙ ПОДХОД
        ↓                     ↓
/-----------\          /----------------\
|           |          |                |
Да → Есть ли функциональная фиксация? → Применить метод Декарта
|           |          |                |
\-----------/          \----------------/
   ↓                         ↓
Преодолеть функциональную    Разбить на простые части
фиксацию (4 метода)              ↓
   ↓                    Анализировать последовательно
Выбрать тип мышления            ↓
   ↓                    Проверить все гипотезы
/-----------------\            ↓
|                 |       Сформулировать вывод
Конвергентное → Дивергентное
мышление      мышление
   ↓                         ↓
Найти одно             Генерировать много
оптимальное решение     возможных решений
        \-----------------------/
                 ↓
         Применить латеральное
              мышление
                 ↓
/-------------------------------------\
|                                     |
Применить инструменты: дерейлмент,    Применить SCAMPER
фокусировку, сортировку
|                                     |
\-------------------------------------/
                 ↓
         Оценить результаты
                 ↓
/-------------------------------------\
|                                     |
Да → Решение найдено? → Нет → Вернуться к началу
|                                     |
\-------------------------------------/
                 ↓
          ЗАВЕРШЕНИЕ
```

Основные элементы алгоритма:

1. Ветка творческого подхода:
- Преодоление функциональной фиксации (4 метода)
- Выбор типа мышления (конвергентное/дивергентное)
- Применение латерального мышления
- Использование инструментов (дерейлмент, SCAMPER)

1. Ветка логического подхода:
- Применение метода Декарта
- Последовательный анализ
- Проверка всех гипотез

1. Общие элементы:
- Возможность вернуться к началу при неудаче
- Адаптивность под разные типы задач
- Комбинирование творческих и логических подходов

Этот алгоритм можно использовать как каркас для решения различных задач, выбирая наиболее подходящие ветки в зависимости от ситуации.
