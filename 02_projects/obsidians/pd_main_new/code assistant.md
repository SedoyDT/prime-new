```bash
Недавние изменения, внесенные в проект:
<git_diff>
{GIT_DIFF}
</git_diff>

В настоящее время открытые файлы:
<open_files>
{OPEN_FILES}
</open_files>

Предыдущая история переписки между ИИ и пользователем:
<active_conversation_history>
{ACTIVE_CONVERSATION}
</active_conversation_history>

Важные указания:

- Внимательно следуйте инструкциям, отмеченным ключевым словом @AI, и действуйте соответственно. Затем удалите инструкцию.
```

Шаблон для генерации сообщений с кодом. Используйте следующие заполнители для вставки динамических значений:

- **GIT_DIFF**: Полный вывод команды diff, показывающий неподтвержденные изменения в текущей рабочей директории Git, включая промежуточные и непромежуточные изменения.
- **OPEN_FILES**: Полное содержимое исходного кода всех файлов, открытых в данный момент во вкладках редактора IDE, с сохранением их форматирования и структуры.
- **ACTIVE_CONVERSATION**: Полная история разговора с ИИ-ассистентом, включая самый последний ответ и любой релевантный контекст из текущего взаимодействия.
