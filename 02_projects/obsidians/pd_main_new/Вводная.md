# Вводная задача  
Это тренировочное задание, цель которого ознакомить разработчика с устройством проекта.  
Задание будет состоять из нескольких разделов.  
`Раздел 1` - это основное задание, все последующие разделы будут в формате доработок задачи из раздела `Раздел 1`.  
  
## Раздел 1:  
Необходимо реализовать модуль для работы с контрагентами.  
Реализовать в виде `стандартной` страницы с `фильтрами`, `гридом`, `выгрузкой в Excel`  
  
### Ключевые функции  
- просмотр списка контрагентов  
- добавление новых контрагентов  
- редактирование данных контрагента  
- удаление данных контрагента  
  
### Необходимы следующие данные  
- юридическое наименование контрагента `обязательное`  
- ИНН контрагента `обязательное`  
- дата создания компании контрагента `обязательное`  
- номер счёта контрагента `опциональное`  
- возможность работы с контрагентом по ЭДО `обязательное`  
- тип контрагента `обязательное`  
  - контрагент по отношению к нам может быть `Покупателем` или `Поставщиком`  
- статус контрагента `обязательное`  
  - возможные статусы: `действующий`, `ликвидированный`, `находится в стадии ликвидации`  
- номера телефонов для связи с контрагентом `обязательное`  
  - контрагент может иметь несколько номеров  
  - к номеру можно писать комментарий  
  
### Права доступа  
- право на доступ к модулю  
  - `просмотр` - пользователи имеют доступ к модулю, но могут только просматривать данные  
  - `редактирование` - пользователи имеют доступ к модулю, и могут редактировать данные  
  - в остальных случаях доступ к модулю запрещен  
- выгрузка данных в `Excel` по права доступа  
  
### Логирование  
Необходимо добавить логирование, в формате `было`, `стало`
