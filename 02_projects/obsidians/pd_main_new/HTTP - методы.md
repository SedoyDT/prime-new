## 🏙️ Район: HTTP-Методы

## 🚪 Улица: GET
> 🔍 «Курьер-Шпион»  

- **Задача:** Принести информацию, но не трогать ничего на сервере.
- **Как передаётся?** — Все данные везутся *на спине* в виде **параметров строки запроса** (query string).
- **Пример:**  
  `GET /api/products?category=books&page=2`  
  Это как если бы курьер шёл мимо книжного магазина и просто заглядывал в окно, чтобы узнать цены.

🧠 **Запомни:**  
- GET — это **только читать**, никогда не изменять.
- GET — можно закладывать в закладки, делиться ссылкой.

📍 **Дом:** `/api/products`  
👉 Там живёт библиотекарь, который показывает книги, но не даёт их взять.

---

## 🚪 Улица: POST
> 📦 «Новый Строитель»

- **Задача:** Создать новый объект на сервере.  
- **Как передаётся?** — В **теле запроса**, как настоящий грузовик с материалами.
- **Пример:**  
  ```json
  POST /api/users
  {
    "name": "John",
    "email": "john@example.com"
  }
  ```
  Это как заказ строительства нового дома: ты присылаешь чертежи (данные), и сервер строит тебе нового пользователя.

🧠 **Запомни:**  
- POST — для **создания** новых ресурсов.
- Часто возвращает статус `201 Created`.

📍 **Дом:** `/api/users`  
👉 Там работает робот-строитель, который принимает заявки и создаёт профили пользователей.

---

## 🚪 Улица: PUT
> 🧱 «Ремонтник до основания»

- **Задача:** Полностью заменить существующий ресурс или создать его, если он не существует.
- **Как передаётся?** — В теле запроса, как полный ремонт всей квартиры.
- **Пример:**  
  ```json
  PUT /api/users/1
  {
    "name": "Jane",
    "email": "jane@example.com"
  }
  ```
  Это как прийти к владельцу квартиры и сказать:  
  > «Снеси всё, что было, и сделай так, как я скажу».

🧠 **Запомни:**  
- PUT — это **полное обновление**.
- Если объекта нет, может создать его (в зависимости от сервера).

📍 **Дом:** `/api/users/1`  
👉 Там живёт сварливый мастер, который ремонтирует квартиру целиком.

---

## 🚪 Улица: PATCH
> 🛠️ «Частичный Ремонтник»

- **Задача:** Обновить только часть ресурса.
- **Как передаётся?** — В теле запроса, но только то, что нужно поменять.
- **Пример:**  
  ```json
  PATCH /api/users/1
  {
    "email": "newemail@example.com"
  }
  ```
  Это как вызвать сантехника, чтобы он только поменял смеситель, а не весь санузел.

🧠 **Запомни:**  
- PATCH — это **частичное обновление**.
- Не затрагивает остальные поля объекта.

📍 **Дом:** `/api/users/1`  
👉 Теперь там работает аккуратный мастер на часах — приходит, фиксирует только одно место и уходит.

---

## 🚪 Улица: DELETE
> 🗑️ «Демонтажник»

- **Задача:** Удалить ресурс.
- **Как передаётся?** — Иногда в URL (например, ID), иногда в теле (реже).
- **Пример:**  
  `DELETE /api/users/1`

  Это как заказать демонтаж старого здания. Бульдозер приезжает, дом исчезает.

🧠 **Запомни:**  
- DELETE — удаление.
- Может возвращать `204 No Content`, если всё прошло успешно.

📍 **Дом:** `/api/users/1`  
👉 Там раньше жил пользователь, но теперь стоит пустое место. Осталась только табличка:  
> “Был, но удалился”.

---

## 🚪 Улица: HEAD
> 🧠 «Информатор без содержания»

- **Задача:** Получить заголовки ответа, без самого тела.
- **Как передаётся?** — То же, что и GET, но сервер не отправляет данные.

🧠 **Запомни:**  
- HEAD — это GET без данных.
- Используется для проверки наличия файла, размера, типа и т.п.

📍 **Дом:** `/api/users`  
👉 Там работает охранник, который говорит:  
> «Я знаю, что есть внутри, но не покажу. Но могу рассказать, сколько места занимает».

---

## 🚪 Улица: OPTIONS
> 📋 «Проверка возможностей»

- **Задача:** Узнать, какие методы поддерживаются для данного URL.
- **Как передаётся?** — Без тела, обычно просто URL.

🧠 **Запомни:**  
- OPTIONS — это как спросить:  
  > «А что здесь вообще можно сделать?»

📍 **Дом:** `/api/users`  
👉 Там живёт администратор района, который говорит:  
> «Вы можете создавать, читать, частично обновлять и удалять».

---

## 🚪 Улица: CONNECT & TRACE
> 🌐 «Специальные Агенты»

🟩 **CONNECT**  
- **Задача:** Открыть TCP-соединение (например, для HTTPS через прокси).  
- Это как туннель под рекой — безопасная связь между клиентом и сервером.

🟥 **TRACE**  
- **Задача:** Диагностика — возвращает обратно полученные заголовки.  
- Это как послать письмо самому себе, чтобы проверить, что оно не исказилось по пути.

🧠 **Запомни:**  
- Эти методы редкие, но очень специфические.
- TRACE может быть опасен из-за утечки информации.

📍 **Дом:** `/secure-tunnel`  
👉 Там живёт секретный агент в маске, который открывает туннели и проверяет связи.

## 🧭 Навигация по району

Вот твой маршрут:

1. Сначала идём на **улицу GET** — узнаём, что есть.
2. Потом на **POST** — строим новое.
3. На **PUT** — полностью меняем.
4. На **PATCH** — правим по мелочи.
5. На **DELETE** — убираем ненужное.
6. Заходим на **HEAD** и **OPTIONS**, чтобы понять возможности.
7. И, если нужно, заглядываем к **CONNECT** и **TRACE** — для диагностики.
