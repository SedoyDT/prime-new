### 10. **Документирование**

- **Документирование структуры:** Документируйте структуру базы данных, включая таблицы, столбцы, индексы и связи.
- **Обновление документации:** Обновляйте документацию по мере изменений в структуре базы данных.

### Примеры

**Пример проектирования таблиц:**

```

CREATE TABLE customers (
    customer_id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE
);

CREATE TABLE orders (
    order_id INT AUTO_INCREMENT PRIMARY KEY,
    customer_id INT,
    order_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
);

```

**Пример использования индекса:**

```

CREATE INDEX idx_customer_name ON customers(name);

```
