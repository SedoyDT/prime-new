Какие типы данных есть в mysql?::


MySQL поддерживает множество типов данных, которые можно использовать для хранения различных видов информации. Эти типы данных делятся на несколько категорий в зависимости от их назначения: числовые, строковые, датированные и другие.

### 1. Числовые типы данных

**a. Целые числа (Integer):**

- **TINYINT**: Хранит небольшие целые числа от -128 до 127 или от 0 до 255 (без знака).
- **SMALLINT**: Хранит целые числа от -32,768 до 32,767 или от 0 до 65,535 (без знака).
- **MEDIUMINT**: Хранит целые числа от -8,388,608 до 8,388,607 или от 0 до 16,777,215 (без знака).
- **INT**: Хранит целые числа от -2,147,483,648 до 2,147,483,647 или от 0 до 4,294,967,295 (без знака).
- **BIGINT**: Хранит целые числа от -9,223,372,036,854,775,808 до 9,223,372,036,854,775,807 или от 0 до 18,446,744,073,709,551,615 (без знака).

**b. Числа с плавающей точкой:**

- **FLOAT**: Хранит числа с плавающей точкой одинарной точности. Диапазон и точность зависят от реализации.
- **DOUBLE**: Хранит числа с плавающей точкой двойной точности. Диапазон и точность зависят от реализации.
- **DECIMAL**: Хранит числа с фиксированной точностью и масштабом. Подходит для точных вычислений, например, для финансовых данных.

### 2. Строковые типы данных

**a. Символьные строки:**

- **CHAR**: Хранит фиксированную длину строк (до 255 символов). Если строка короче, то она дополняется пробелами.
- **VARCHAR**: Хранит переменную длину строк (до 65,535 символов). Эффективнее, чем CHAR, когда длина строк варьируется.

**b. Текстовые строки:**

- **TINYTEXT**: Хранит до 255 символов текста.
- **TEXT**: Хранит до 65,535 символов текста.
- **MEDIUMTEXT**: Хранит до 16,777,215 символов текста.
- **LONGTEXT**: Хранит до 4,294,967,295 символов текста.

**c. Двоичные строки:**

- **BINARY**: Хранит фиксированную длину двоичных данных (до 255 байт).
- **VARBINARY**: Хранит переменную длину двоичных данных (до 65,535 байт).
- **TINYBLOB**: Хранит до 255 байт двоичных данных.
- **BLOB**: Хранит до 65,535 байт двоичных данных.
- **MEDIUMBLOB**: Хранит до 16,777,215 байт двоичных данных.
- **LONGBLOB**: Хранит до 4,294,967,295 байт двоичных данных.

### 3. Датированные типы данных

- **DATE**: Хранит дату в формате `YYYY-MM-DD`.
- **DATETIME**: Хранит дату и время в формате `YYYY-MM-DD HH:MM:SS`.
- **TIMESTAMP**: Хранит дату и время в формате `YYYY-MM-DD HH:MM:SS`. Автоматически обновляется при изменении записи.
- **TIME**: Хранит время в формате `HH:MM:SS`.
- **YEAR**: Хранит год в формате `YYYY`.

### 4. Другие типы данных

- **ENUM**: Хранит один из заранее определённых значений. Например, `ENUM('small', 'medium', 'large')`.
- **SET**: Хранит набор значений из заранее определённого списка. Можно выбирать несколько значений одновременно. Например, `SET('a', 'b', 'c')`.

### Примеры использования

- **Числовой тип**:
  ```

  CREATE TABLE products (
      id INT AUTO_INCREMENT PRIMARY KEY,
      price DECIMAL(10, 2)
  );
  
```

- **Строковый тип**:
  ```

  CREATE TABLE users (
      id INT AUTO_INCREMENT PRIMARY KEY,
      username VARCHAR(50)
  );
  
```

- **Дата и время**:
  ```

  CREATE TABLE events (
      id INT AUTO_INCREMENT PRIMARY KEY,
      event_date DATETIME
  );
  
```

- **ENUM и SET**:
  ```

  CREATE TABLE orders (
      id INT AUTO_INCREMENT PRIMARY KEY,
      status ENUM('pending', 'shipped', 'delivered')
  );

  CREATE TABLE options (
      id INT AUTO_INCREMENT PRIMARY KEY,
      tags SET('red', 'blue', 'green')
  );
  
```

### Резюме

MySQL предоставляет широкие возможности для хранения различных типов данных, что позволяет эффективно управлять данными и проектировать схемы базы данных в соответствии с конкретными потребностями приложения.
