# Проблема здесь в том, что ваше регулярное выражение `/[(\*|\+|\/|\-)]*/` не соответствует ожидаемому поведению из-за нескольких факторов:
<!-- basicblock-start  deck='R_regexp' -->
Проблема здесь в том, что ваше регулярное выражение `/[(\*|\+|\/|\-)]*/` не соответствует ожидаемому поведению из-за нескольких факторов:::


1. **Квадратные скобки `[...]`**: В регулярных выражениях квадратные скобки используются для создания классов символов, что означает "любой из перечисленных символов". В вашем случае `[(*|+\/\-)]*` будет искать любое количество символов, соответствующих `(`, `*`, `+`, `/`, или `-`.

2. **Квантификатор `*`**: Символ `*` означает "ноль или более повторений предыдущего символа или группы символов". В вашем случае `[(\*|\+|\/|\-)]*` означает любое количество символов из перечисленных в квадратных скобках.

Для вашей строки "1 +     2   * 2 / 3", вы хотите извлечь операторы (`+`, `*`, `/`). Лучше всего использовать следующее регулярное выражение:

```
[\+\*\/\-]
```

Это выражение будет искать любой из операторов `+`, `*`, `/`, `-` в строке. Если вы хотите найти все вхождения операторов, вы можете использовать метод соответствия в Python или PHP:

```
import re

text = "1 +     2   * 2 / 3"
operators = re.findall(r'[\+\*\/\-]', text)
print(operators)  # Вывод: ['+', '*', '/']
```

Этот код найдет все операторы в вашей строке и вернет список строк, содержащий найденные операторы.
