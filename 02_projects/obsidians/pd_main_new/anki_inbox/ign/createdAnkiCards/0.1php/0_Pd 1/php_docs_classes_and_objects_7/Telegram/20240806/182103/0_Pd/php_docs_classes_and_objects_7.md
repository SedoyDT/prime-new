### Примеры::


**Абстрактный класс с абстрактными и обычными методами:**

```

abstract class Vehicle {
    abstract public function start();
    
    public function stop() {
        echo "Vehicle stopped.";
    }
}

class Car extends Vehicle {
    public function start() {
        echo "Car started.";
    }
}

$car = new Car();
$car->start(); // Вывод: "Car started."
$car->stop();  // Вывод: "Vehicle stopped."

```

В общем, абстрактные классы позволяют организовать код более структурированно и гибко, обеспечивая возможность создания и работы с объектами через четко определенный интерфейс, сохраняя при этом возможность расширения и модификации без изменения базовой структуры.

# Начало карточки

Для чего создается абстрактный класс? почему бы не использовать просто класс?::


Абстрактные классы в PHP предоставляют особый механизм для проектирования и организации кода, который отличается от использования обычных классов. Они играют важную роль в объектно-ориентированном программировании (ООП) и обладают рядом преимуществ и особенностей по сравнению с обычными классами. Вот основные причины, почему абстрактные классы используются и чем они отличаются от обычных классов:

### 1. **Определение общего интерфе**йса

Абстрактные классы позволяют определить общий интерфейс и базовую функциональность, которую должны реализовать дочерние классы.

- **Объявление абстрактных метод**ов: Абстрактные методы в абстрактном классе задают сигнатуру методов, которые должны быть реализованы в дочерних классах. Это обеспечивает единообразие интерфейса.
  
  ```

  abstract class Shape {
      abstract public function getArea();
      abstract public function getPerimeter();
  }
  
  class Rectangle extends Shape {
      private $width;
      private $height;
      
      public function __construct($width, $height) {
          $this->width = $width;
          $this->height = $height;
      }
      
      public function getArea() {
          return $this->width * $this->height;
      }
      
      public function getPerimeter() {
          return 2 * ($this->width + $this->height);
      }
  }
```
  

### 2. **Запрет создания экземпля**ров

Абстрактные классы не могут быть инстанциированы напрямую. Это означает, что вы не можете создать объект абстрактного класса, что предотвращает использование его как обычного класса.

- **Исключение создания экземпляр**ов: Это полезно, когда вы хотите создать базовый класс, который только определяет структуру, но не предназначен для непосредственного использования.

  ```

  abstract class Animal {
      abstract public function makeSound();
  }

  // Не допустимо:
  // $animal = new Animal(); // Ошибка
  
  class Dog extends Animal {
      public function makeSound() {
          echo "Bark!";
      }
  }
```
  

### 3. **Повторное использование к**ода

Абстрактные классы позволяют определить общие свойства и методы, которые могут быть унаследованы и использованы дочерними классами, что способствует повторному использованию кода.

- **Определение общих методов и свойс**тв: Абстрактный класс может содержать реализацию общих методов и свойств, которые могут быть унаследованы и использованы или переопределены в дочерних классах.

  ```

  abstract class Animal {
      protected $name;
      
      public function __construct($name) {
          $this->name = $name;
      }
      
      public function getName() {
          return $this->name;
      }
      
      abstract public function makeSound();
  }
```
  

### 4. **Поддержка полиморфи**зма

Абстрактные классы поддерживают полиморфизм, позволяя обрабатывать объекты разных классов через общий интерфейс.

- **Использование абстрактного класса в качестве ти**па: Вы можете использовать абстрактный класс для определения переменной или параметра типа, что позволяет передавать объекты различных конкретных классов, которые расширяют этот абстрактный класс.

  ```

  function printAnimalSound(Animal $animal) {
      echo $animal->makeSound();
  }

  $dog = new Dog("Buddy");
  printAnimalSound($dog); // Выведет "Bark!"
```
  

### 5. **Упрощение расширения и модифика**ции

Абстрактные классы упрощают расширение и модификацию кода, предоставляя четкую структуру для наследования и реализации.

- **Гибкость при добавлении новых функциональност**ей: Вы можете добавлять новые дочерние классы, которые реализуют абстрактные методы по своему усмотрению, не изменяя код базового абстрактного класса.

  ```

  class Circle extends Shape {
      private $radius;
      
      public function __construct($radius) {
          $this->radius = $radius;
      }
      
      public function getArea() {
          return pi() * $this->radius * $this->radius;
      }
      
      public function getPerimeter() {
          return 2 * pi() * $this->radius;
      }
  }
```
