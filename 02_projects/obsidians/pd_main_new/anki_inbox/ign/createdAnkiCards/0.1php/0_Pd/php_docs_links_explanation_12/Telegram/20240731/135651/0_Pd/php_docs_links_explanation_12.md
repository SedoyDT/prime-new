Что ссылки собой не представляют ?::


Как говорилось в предыдущих разделах, ссылки — не указатели. Следующая конструкция не будет делать то, что ожидается:
```PHP
  
<?php

function foo(&$var) {

    $var =& $GLOBALS["baz"];

}

foo($bar);

?>
```

PHP свяжет переменную $var в функции foo с переменной $bar, которую передали при вызове, но затем перепривяжет к переменной [$GLOBALS["baz"]](https://www.php.net/manual/ru/reserved.variables.globals.php). Невозможно связать переменную $bar в области видимости вызова с чем-то другим через механизм ссылок, поскольку переменная $bar недоступна в функции foo, её представляет только переменная $var, но у переменной $var есть только содержимое переменной, а не привязка имя-значение в таблице имён переменных. Вы можете воспользоваться [возвратом ссылок](https://www.php.net/manual/ru/language.references.return.php) из функции для привязки внешней переменной к другому значению.
