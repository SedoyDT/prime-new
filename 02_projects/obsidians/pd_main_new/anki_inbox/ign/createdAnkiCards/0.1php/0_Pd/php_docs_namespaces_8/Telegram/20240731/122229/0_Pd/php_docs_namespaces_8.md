Какой простой пример есть для понимания логики пространства имен?

Думаю, это может помочь другим новичкам, таким как я...

 Конфликты имен означают: 
 вы создаете функцию с именем db_connect, и чей-то код, который вы используете в своем файле (например, включение), имеет ту же функцию с тем же именем.

 Чтобы обойти эту проблему, вы переименовываете свою функцию в SteveWa_db_connect, что делает ваш код длиннее и труднее для чтения.

 Теперь вы можете использовать пространства имен, чтобы отделить имя вашей функции от имени любой другой функции, и вам не придется создавать функции extra_long_named, чтобы обойти проблему конфликта имен.

 Таким образом, пространство имен похоже на указатель на путь к файлу, где вы можете найти источник функции, с которой работаете.
