1.1 Задача: "Создайте пользовательскую функцию, которая проверяет, является ли переданное число четным или нечетным." ::  
1.2 Решение: "Определите функцию, которая принимает число в качестве аргумента и возвращает строку, указывающую, четное это число или нечетное."  
Пример кода:
```PHP
// Определение функции для проверки четности числа
function checkEvenOdd($number) {
    if ($number % 2 == 0) {
        return "$number is even.";
    } else {
        return "$number is odd.";
    }
}

// Вызов функции
echo checkEvenOdd(7); // Вывод: 7 is odd.
```

2.1 Задача: "Напишите функцию, которая принимает строку и количество повторений и возвращает строку, повторенную указанное количество раз." ::  
2.2 Решение: "Используйте аргументы для передачи строки и количества повторений в функцию, которая возвращает строку, повторенную указанное количество раз."  
Пример кода:
```PHP
// Определение функции для повторения строки
function repeatString($string, $times) {
    return str_repeat($string, $times);
}

// Вызов функции
echo repeatString('Hello ', 3); // Вывод: Hello Hello Hello 
```

Пример кода:

8.1 Задача: "Создайте класс с методом, который можно вызвать с использованием синтаксиса callable-объектов первого класса." ::  
8.2 Решение: "Определите класс с методом и используйте синтаксис callable-объектов первого класса для вызова этого метода."  
Пример кода:
```PHP
// Определение класса с методом
class MathOperations {
    public function add($a, $b) {
        return $a + $b;
    }
}

// Создание объекта класса
$math = new MathOperations();

// Использование метода как callable
$addFunction = [$math, 'add'];

// Вызов метода через callable
echo call_user_func($addFunction, 5, 10); // Вывод: 15
```
