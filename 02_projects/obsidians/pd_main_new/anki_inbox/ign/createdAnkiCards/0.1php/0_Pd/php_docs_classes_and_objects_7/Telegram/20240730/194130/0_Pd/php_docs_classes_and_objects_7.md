Как php работает c классами и объектами?::


PHP работает с объектами так же, как с ссылками или дескрипторами, это означает что каждая переменная содержит ссылку на объект, а не его копию. Более подробную информацию смотрите в разделе [Объекты и ссылки](https://www.php.net/manual/ru/language.oop5.references.php).
