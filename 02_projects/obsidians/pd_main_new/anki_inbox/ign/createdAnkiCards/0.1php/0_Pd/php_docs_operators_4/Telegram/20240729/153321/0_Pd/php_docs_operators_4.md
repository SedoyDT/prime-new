Строковые операторы ¶::


В PHP со строками (string) работают два оператора. Первый — оператор конкатенации («.»), который возвращает строку, которая представляет соединение левого и правого аргумента. Второй — оператор присваивания с конкатенацией («.=»), который присоединяет правый аргумент к левому. Подробнее об этом рассказывает раздел «Операторы присваивания».

<?php

$a = "Привет, ";
$b = $a . "Мир!"; // Переменная $b теперь содержит строку «Привет, Мир!»

$a = "Привет, ";
$a .= "Мир!";   // Переменная $a теперь содержит строку «Привет, Мир!»

?>
