1.1 Вопрос: "Что такое классы и объекты в PHP и как они используются?" ::  
1.2 Ответ: "Классы являются шаблонами для создания объектов. Объекты — это экземпляры классов, содержащие данные и методы. Классы позволяют объединять данные и функции в единое целое."  
Пример кода:
```PHP
// Определение класса
class Car {
    public $color;
    public $model;

    // Конструктор
    public function __construct($color, $model) {
        $this->color = $color;
        $this->model = $model;
    }

    // Метод
    public function displayInfo() {
        return "Model: " . $this->model . ", Color: " . $this->color;
    }
}

// Создание объекта класса
$myCar = new Car("Red", "Toyota");
echo $myCar->displayInfo(); // Вывод: Model: Toyota, Color: Red
```

2.1 Вопрос: "Как объявляются и используются свойства класса в PHP?" ::  
2.2 Ответ: "Свойства класса объявляются внутри класса с помощью модификаторов доступа. Они могут быть публичными, защищенными или приватными и хранят данные объекта."  
Пример кода:
```PHP
// Определение класса с свойствами
class Person {
    public $name;
    protected $age;
    private $password;

    // Конструктор
    public function __construct($name, $age, $password) {
        $this->name = $name;
        $this->age = $age;
        $this->password = $password;
    }

    // Метод для доступа к защищенному свойству
    public function getAge() {
        return $this->age;
    }
}

// Создание объекта класса
$person = new Person("Alice", 30, "secret");
echo $person->name; // Вывод: Alice
echo $person->getAge(); // Вывод: 30
```

6.1 Вопрос: "Как работают модификаторы доступа в PHP и чем они отличаются?" ::  
6.2 Ответ: "Модификаторы доступа определяют, где и как свойства и методы класса могут быть доступны. `public` доступен везде, `protected` — только в классе и его наследниках, а `private` — только в самом классе."  
Пример кода:
```PHP
class Example {
    public $publicProp = 'Public Property';
    protected $protectedProp = 'Protected Property';
    private $privateProp = 'Private Property';

    public function getProps() {
        return $this->publicProp . ', ' . $this->protectedProp . ', ' . $this->privateProp;
    }
}

$example = new Example();
echo $example->publicProp; // Вывод: Public Property
// echo $example->protectedProp; // Ошибка: Cannot access protected property
// echo $example->privateProp; // Ошибка: Cannot access private property
echo $example->getProps(); // Вывод: Public Property, Protected Property, Private Property
```

7.1 Вопрос: "Что такое наследование в PHP и как его использовать?" ::  
7.2 Ответ: "Наследование позволяет одному классу использовать свойства и методы другого класса. Класс, от которого наследуют, называется родительским, а класс, который наследует, — дочерним."  
Пример кода:
```PHP
// Определение родительского класса
class Animal {
    public function speak() {
        return "Animal speaks.";
    }
}

// Определение дочернего класса
class Dog extends Animal {
    public function bark() {
        return "Dog barks.";
    }
}

// Создание объекта дочернего класса
$dog = new Dog();
echo $dog->speak(); // Вывод: Animal speaks.
echo $dog->bark();  // Вывод: Dog barks.
```

10.1 Вопрос: "В чем разница между абстрактным классом и интерфейсом в PHP?" ::  
10.2 Ответ: "Абстрактный класс может содержать реализованные методы и свойства, а интерфейс определяет только методы, которые должны быть реализованы классом. Интерфейсы поддерживают множественное наследование, а абстрактные классы — нет."  
Пример кода:
```PHP
// Определение абстрактного класса
abstract class Shape {
    abstract public function area();
}

// Определение интерфейса
interface Drawable {
    public function draw();
}

// Класс, реализующий абстрактный класс и интерфейс
class Circle extends Shape implements Drawable {
    private $radius;

    public function __construct($radius) {
        $this->radius = $radius;
    }

    public function area() {
        return pi() * $this->radius * $this->radius;
    }

    public function draw() {
        return "Drawing a circle.";
    }
}

// Создание объекта класса
$circle = new Circle(5);
echo $circle->area(); //

 Вывод: 78.539816339745
echo $circle->draw(); // Вывод: Drawing a circle.
```

12.1 Вопрос: "Как работает клонирование объектов в PHP и что такое метод `__clone`?" ::  
12.2 Ответ: "Клонирование объектов в PHP осуществляется с помощью функции `clone`. Метод `__clone` вызывается автоматически при клонировании объекта и может использоваться для дополнительной настройки клонированного объекта."  
Пример кода:
```PHP
// Определение класса с методом __clone
class Cloneable {
    public $property;

    public function __construct($property) {
        $this->property = $property;
    }

    public function __clone() {
        // Дополнительная настройка клонированного объекта
        $this->property .= " (cloned)";
    }
}

// Создание и клонирование объекта
$original = new Cloneable("Original");
$clone = clone $original;

echo $original->property; // Вывод: Original
echo $clone->property;    // Вывод: Original (cloned)
```
