1.1 Вопрос: "Как создать пользовательскую функцию в PHP?" ::  
1.2 Ответ: "Пользовательская функция создается с помощью ключевого слова `function`, за которым следует имя функции и ее тело."  
Пример кода:
```PHP
// Определение функции для вычисления факториала
function factorial($number) {
    if ($number <= 1) {
        return 1;
    } else {
        return $number * factorial($number - 1);
    }
}

// Вызов функции
echo factorial(5); // Вывод: 120
```

2.1 Вопрос: "Как передать аргументы в функцию в PHP?" ::  
2.2 Ответ: "Аргументы передаются функции в скобках после ее имени и используются внутри функции как переменные."  
Пример кода:
```PHP
// Функция для умножения двух чисел
function multiply($a, $b) {
    return $a * $b;
}

// Вызов функции с аргументами
echo multiply(4, 5); // Вывод: 20
```

3.1 Вопрос: "Как функция возвращает значение в PHP?" ::  
3.2 Ответ: "Функция возвращает значение с помощью ключевого слова `return`, которое затем можно использовать в месте вызова функции."  
Пример кода:
```PHP
// Функция для получения максимального числа
function getMax($a, $b) {
    return $a > $b ? $a : $b;
}

// Вызов функции и использование возвращаемого значения
echo getMax(7, 12); // Вывод: 12
```

4.1 Вопрос: "Что такое функции переменных в PHP?" ::  
4.2 Ответ: "Функции переменных позволяют использовать имя функции, хранящееся в переменной, для вызова функции."  
Пример кода:
```PHP
// Определение функции
function sayGoodbye() {
    echo "Goodbye!";
}

// Хранение имени функции в переменной
$functionName = 'sayGoodbye';

// Вызов функции через переменную
$functionName(); // Вывод: Goodbye!
```

6.1 Вопрос: "Что такое анонимные функции в PHP?" ::  
6.2 Ответ: "Анонимные функции не имеют имени и могут быть присвоены переменным или переданы как аргументы другим функциям."  
Пример кода:
```PHP
// Определение анонимной функции
$square = function($n) {
    return $n * $n;
};

// Вызов анонимной функции
echo $square(6); // Вывод: 36
```

7.1 Вопрос: "Что такое стрелочные функции в PHP?" ::  
7.2 Ответ: "Стрелочные функции — это сокращенный синтаксис для анонимных функций, который автоматически захватывает переменные из внешнего контекста."  
Пример кода:
```PHP
// Определение стрелочной функции
$multiply = fn($a, $b) => $a * $b;

// Вызов стрелочной функции
echo $multiply(3, 7); // Вывод: 21
```

8.1 Вопрос: "Как использовать синтаксис callable-объектов первого класса в PHP?" ::  
8.2 Ответ: "Синтаксис callable-объектов первого класса позволяет использовать объекты и методы как функции, используя массив, содержащий объект и метод."  
Пример кода:
```PHP
// Определение класса с методом
class Greeter {
    public function greet($name) {
        return "Hello, $name!";
    }
}

// Создание объекта класса
$greeter = new Greeter();

// Использование метода объекта как callable
$greetFunction = [$greeter, 'greet'];

// Вызов метода через callable
echo call_user_func($greetFunction, 'Alice'); // Вывод: Hello, Alice!
```
