Что такое ссылки?::


Ссылки в PHP — средство доступа к одному и тому же содержимому переменной под разными именами. Ссылки в PHP не похожи на указатели языка C; например, нельзя выполнять над ссылками адресную арифметику, они не хранят адрес памяти другой переменной и т. д. Дополнительную информацию даёт раздел «Что ссылки собой не представляют». Напротив, ссылки в PHP — псевдонимы в таблице имён переменных. Обратите внимание, в PHP имя переменной и её содержимое — не одно и то же, поэтому одно и то же значение разрешается хранить под разными именами. Близкое сходство образовывают названия файлов и сами файлы в Unix-системах: имена переменных — записи каталога, а значение переменной — сам файл. Ссылки в PHP — аналогичны жёстким ссылкам в файловых системах Unix.
