NULL ¶::


Тип null — это единичный тип PHP, то есть он имеет только одно значение: null.

Неопределённые и удалённые языковой конструкцией unset() переменные преобразуются в значение null.
Синтаксис ¶

Существует только одно значение типа null — регистронезависимая константа null.
<?php
$var = NULL;
?>
Приведение к null ¶

Внимание

Эта функциональность объявлена УСТАРЕВШЕЙ начиная с PHP 7.2.0 и была УДАЛЕНА в версии PHP 8.0.0. Использовать эту функцию крайне не рекомендуется.

Приведение переменной к null через выражение (unset) $var не удаляет переменную и её значение. Данное выражение только возвращает значение null.
