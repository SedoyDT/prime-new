Объясни в двухсловах конваринтность php и контравариантность ::


**Ковариантность**: Поддержка заменяемости возвращаемых типов.

**Контравариантность**: Гибкость типов параметров метода.

Конечно, вот немного более подробное объяснение:

### Ковариантность

**Ковариантность** относится к возможности изменять возвращаемый тип метода в подклассе таким образом, чтобы он был более специализированным, чем в суперклассе. Это позволяет возвращать объекты более конкретного типа, чем тот, который указан в суперклассе. 

**Пример:**
Если у вас есть метод в суперклассе, который возвращает объект типа `Animal`, в подклассе вы можете переопределить этот метод, чтобы он возвращал объект типа `Cat` или `Dog`, который является более конкретным.

**Ковариантность в PHP:**
С PHP 7.4 и выше, поддержка ковариантности реализована для возвращаемых типов. Пример:

```

class Animal {}
class Cat extends Animal {}

class AnimalShelter {
    public function adopt(): Animal {
        return new Animal();
    }
}

class CatShelter extends AnimalShelter {
    // Переопределяем метод, чтобы вернуть более конкретный тип
    public function adopt(): Cat {
        return new Cat();
    }
}

```

### Контравариантность

**Контравариантность** связана с возможностью изменять типы параметров метода в подклассе таким образом, чтобы они были более универсальными. Это позволяет методам подкласса принимать параметры более широких типов, чем те, которые принимает метод суперкласса.

**Пример:**
Если метод в суперклассе принимает объект типа `Animal`, в подклассе этот метод может принимать объект типа `Cat`, который является более специализированным, или вообще более общий тип.

**Контравариантность в PHP:**
PHP не поддерживает контравариантность для параметров метода в полной мере, как это реализовано в некоторых других языках. Однако, можно использовать принципы обратной совместимости в аргументах:

```

class Animal {}
class Cat extends Animal {}

class AnimalFeeder {
    public function feed(Animal $animal) {
        // Логика кормления животного
    }
}

class CatFeeder extends AnimalFeeder {
    // Переопределяем метод, принимая более конкретный тип
    public function feed(Cat $cat) {
        // Логика кормления кота
    }
}

```

Обратите внимание, что в PHP методы могут переопределяться только с параметрами того же типа или с более универсальным типом, но нельзя явно указать, что типы параметров в подклассе являются контравариантными.
