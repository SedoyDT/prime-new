Глобальное пространство::


Без определения пространства имён определения классов и функций помещаются в глобальном пространстве — так же, как это было в PHP до введения пространств имён. Добавление префикса \ к именам указывает, что требуется имя из глобального пространства, даже в контексте пространства имён. 

Пример #1 Спецификация глобального пространства

```


<?php

namespace A\B\C;

/* Функция — это A\B\C\fopen */
function fopen() {
     /* ... */
     $f = \fopen(...); // Вызов глобальной функции fopen
     return $f;
}

?>
```
