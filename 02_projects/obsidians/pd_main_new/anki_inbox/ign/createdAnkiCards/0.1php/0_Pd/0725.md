13.1 Вопрос: "Что такое трейты в PHP и как они используются?" ::  
13.2 Ответ: "Трейты в PHP позволяют повторно использовать методы в нескольких классах. Они служат для объединения функциональности без необходимости использования множественного наследования."  
Пример кода:
```PHP
// Определение трейта
trait Logger {
    public function log($message) {
        echo "Log: $message<br>";
    }
}

// Определение класса, использующего трейт
class Application {
    use Logger;

    public function run() {
        $this->log("Application is running");
    }
}

// Создание объекта класса
$app = new Application();
$app->run(); // Вывод: Log: Application is running
```

14.1 Вопрос: "Можно ли использовать несколько трейтов в одном классе? Если да, то как?" ::  
14.2 Ответ: "Да, в PHP можно использовать несколько трейтов в одном классе. Трейты подключаются с помощью ключевого слова `use`, и они могут быть перечислены через запятую."  
Пример кода:
```PHP
// Определение первых двух трейтов
trait FileLogger {
    public function logToFile($message) {
        echo "Log to file: $message<br>";
    }
}

trait ConsoleLogger {
    public function logToConsole($message) {
        echo "Log to console: $message<br>";
    }
}

// Определение класса, использующего оба трейта
class MultiLogger {
    use FileLogger, ConsoleLogger;
}

// Создание объекта класса
$logger = new MultiLogger();
$logger->logToFile("File log message"); // Вывод: Log to file: File log message
$logger->logToConsole("Console log message"); // Вывод: Log to console: Console log message
```

15.1 Вопрос: "Как разрешаются конфликты методов при использовании нескольких трейтов в PHP?" ::  
15.2 Ответ: "Если два трейта содержат методы с одинаковыми именами, PHP вызывает ошибку при попытке использования этих трейтов. Конфликты можно разрешить с помощью ключевого слова `insteadof`, которое указывает, какой метод должен быть использован, и `as`, чтобы переименовать метод."  
Пример кода:
```PHP
// Определение двух трейтов с конфликтующими методами
trait TraitA {
    public function conflict() {
        echo "TraitA conflict method<br>";
    }
}

trait TraitB {
    public function conflict() {
        echo "TraitB conflict method<br>";
    }
}

// Определение класса, использующего оба трейта
class Resolver {
    use TraitA, TraitB {
        TraitA::conflict insteadof TraitB;
        TraitB::conflict as conflictB;
    }
}

// Создание объекта класса
$resolver = new Resolver();
$resolver->conflict(); // Вывод: TraitA conflict method
$resolver->conflictB(); // Вывод: TraitB conflict method
```
