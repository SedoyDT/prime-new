Неявная работа механизма ссылок ::


Многие синтаксические конструкции в PHP реализовали через механизм ссылок. Поэтому информация этого раздела о ссылочном связывании касается и этих конструкций. Отдельные конструкции наподобие передачи и возврата по ссылке, объяснили другие подразделы. Другие конструкции с синтаксисом ссылок: 

Ссылки global ¶

При объявлении переменной синтаксисом global $var фактически создаётся ссылка на глобальную переменную. Такое объявление — то же, что и: 

```


<?php

$var =& $GLOBALS["var"];

?>

```
 Удаление переменной $var конструкцией unset() не удалит глобальную переменную.
