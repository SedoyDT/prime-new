Что можно сказать про интерфейс SplObserver?::


Интерфейс SplObserver используется совместно с SplSubject для реализации шаблона проектирования Наблюдатель (Observer). 

```

 interface SplObserver {
/* Методы */
public update(SplSubject $subject): void
}

```
