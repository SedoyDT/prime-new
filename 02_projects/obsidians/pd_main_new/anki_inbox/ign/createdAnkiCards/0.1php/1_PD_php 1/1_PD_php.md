**Какие магические методы у класса есть ?**::

*Спросят с вероятностью 13%*

<u>Магические методы</u> — это специальные методы, которые начинаются и заканчиваются двойным подчеркиванием (`__`). Эти методы позволяют разработчикам реализовать поведение объектов, которое изменяет или дополняет стандартные операции, такие как создание объектов, арифметические операции, доступ к атрибутам и многое другое. Вот список основных магических методов в Python, сгруппированных по категориям:

**Инициализация и уничтожение**

✅``__init__(self, ...)``: Инициализация нового объекта. Вызывается после создания экземпляра класса.
✅``__del__(self)``: Деструктор, вызывается при уничтожении объекта.

**Представление**

✅``__str__(self)``: Возвращает строковое представление объекта, используемое при вызове `str(obj)` или `print(obj)`.
✅``__repr__(self)``: Возвращает строковое представление объекта для разработчиков, используемое при вызове `repr(obj)`.

**Арифметические операции**

✅``__add__(self, other)``: Операция сложения (`+`).
✅``__sub__(self, other)``: Операция вычитания (`-`).
✅``__mul__(self, other)``: Операция умножения (`*`).
✅``__truediv__(self, other)``: Операция деления (`/`).
✅``__floordiv__(self, other)``: Операция целочисленного деления (`//`).
✅``__mod__(self, other)``: Операция остатка от деления (`%`).
✅``__pow__(self, other)``: Операция возведения в степень (`**`).

**Операции сравнения**

✅`__eq__(self, other)`: Операция равенства (``==``).**
✅**`__ne__(self, other)`: Операция неравенства (``!=``).**
✅**`__lt__(self, other)`: Операция меньше (``<``).**
✅**`__le__(self, other)`: Операция меньше или равно (``<=``).**
✅**`__gt__(self, other)`: Операция больше (``>``).**
✅**`__ge__(self, other)`: Операция больше или равно (``>=``).**

Контейнерные методы

✅**``__len__(self)``: Возвращает количество элементов при вызове ``len(obj)``**.
✅**``__getitem__(self, key)``: Позволяет доступ к элементам по индексу `obj[key]`.**
✅**``__setitem__(self, key, value)``: Позволяет устанавливать значение элемента по индексу` obj[key] = value.`**
✅**``__delitem__(self, key)``: Позволяет удалять элемент по индексу `del obj[key]`.**
✅**``__iter__(self)``: Возвращает итератор объекта, который используется в циклах `for`.**
✅**``__next__(self)``: Возвращает следующий элемент итератора.**

Управление контекстом

✅**`__enter__(self)`: Вызывается при входе в контекст` with.`**
✅**`__exit__(self, exc_type, exc_value, traceback)`: Вызывается при выходе из контекста with.**

Другие методы

✅**`__call__(self, ...)`: Позволяет вызывать экземпляры класса как функции.**
✅**`__contains__(self, item)`: Определяет поведение оператора**** `in.`**
✅**`__bool__(self)`: Возвращает значение логического типа для объекта, используется в логических выражениях.

Магические методы предоставляют мощные возможности для изменения и расширения стандартного поведения объектов. Они обеспечивают гибкость и удобство работы с объектами, что делает более выразительным и функциональным языком.
