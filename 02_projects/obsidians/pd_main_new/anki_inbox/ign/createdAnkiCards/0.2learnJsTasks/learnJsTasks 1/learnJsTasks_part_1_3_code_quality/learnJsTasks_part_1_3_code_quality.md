# Что такое Babel?
<!-- basicblock-start oid="Obsl6FSI6WY8tsbAXel3bhKU"  deck='learnJsTasks_part_1_3_code_quality' -->
Что такое Babel?::


Babel – это транспилер. Он переписывает современный JavaScript-код в предыдущий стандарт.

На самом деле, есть две части Babel:

    Во-первых, транспилер, который переписывает код. Разработчик запускает Babel на своём компьютере. Он переписывает код в старый стандарт. И после этого код отправляется на сайт. Современные сборщики проектов, такие как webpack или brunch, предоставляют возможность запускать транспилер автоматически после каждого изменения кода, что позволяет экономить время.

    Во-вторых, полифил.

    Новые возможности языка могут включать встроенные функции и синтаксические конструкции. Транспилер переписывает код, преобразовывая новые синтаксические конструкции в старые. Но что касается новых встроенных функций, нам нужно их как-то реализовать. JavaScript является высокодинамичным языком, скрипты могут добавлять/изменять любые функции, чтобы они вели себя в соответствии с современным стандартом.

    Термин «полифил» означает, что скрипт «заполняет» пробелы и добавляет современные функции.

    Интересное хранилище полифилов:
        core js поддерживает много функций, можно подключать только нужные.

Таким образом, чтобы современные функции поддерживались в старых движках, нам надо установить транспилер и добавить полифил.

# Как может выглядить полифил для map?
<!-- basicblock-start oid="ObsE3xHeF9Szj2pa9ie1jAR4"  deck='learnJsTasks_part_1_3_code_quality' -->
Как может выглядить полифил для map?::


Вот подробные комментарии для кода:

```

// Добавляем новый метод myMap к объекту Array с помощью его прототипа.
Array.prototype.myMap = function(callback, arg) {
  
  // Проверяем, не является ли массив null или undefined, а также проверяем контекст вызова.
  // Если это так, выбрасываем ошибку TypeError.
  if (this == null || this === window) {
    throw TypeError('myMap called on null or undefined');
  }
  
  // Проверяем, является ли аргумент callback функцией.
  // Если нет, выбрасываем ошибку TypeError.
  if (typeof callback !== 'function') {
    throw TypeError(`${callback} is not a function`);
  }
  
  // Создаем новый массив, который будет содержать результаты применения callback к каждому элементу исходного массива.
  const newArray = [];
  
  // Проходим по всем элементам текущего массива с помощью цикла for.
  for (let i = 0; i < this.length; i++) {
    
    // Вызываем callback для текущего элемента (this[i]), передавая ему следующие аргументы:
    // - this[i]: текущий элемент массива
    // - i: индекс текущего элемента
    // - this: сам исходный массив
    // Если передан контекст (arg), метод call вызовет функцию в этом контексте.
    // Результат выполнения callback сохраняется в новый массив.
    newArray[i] = callback.call(arg, this[i], i, this);
  }
  
  // Возвращаем новый массив, содержащий результаты вызовов callback для каждого элемента исходного массива.
  return newArray;
}

```

### Разбор ключевых моментов:
- **Расширение прототипа массива**: Этот код добавляет метод `myMap` в прототип массива `Array.prototype`, что делает его доступным для всех массивов.
- **Проверка на null или undefined**: Метод проверяет, не является ли массив, на котором он вызывается, `null` или `undefined`. Если это так, выбрасывается ошибка, предотвращая выполнение на несуществующем объекте.
- **Проверка callback**: Проверяется, что переданный аргумент `callback` является функцией. Если нет, метод выбрасывает ошибку.
- **Цикл обработки массива**: Внутри цикла `for` происходит итерация по элементам массива, и для каждого элемента вызывается `callback`, результат выполнения которого сохраняется в новый массив.
- **Использование `call`**: Метод `callback.call(arg, ...)` позволяет задать контекст выполнения функции (значение `this` внутри `callback`) и передать ей аргументы.
- **Возврат результата**: После завершения цикла создается новый массив, который и возвращается в качестве результата работы метода `myMap`.

# Что можно рассказать про полифилы?
<!-- basicblock-start oid="Obss7CEQKyQl13bvAmX3fVFe"  deck='learnJsTasks_part_1_3_code_quality' -->
Что можно рассказать про полифилы?::


**Полифилы** (Polyfills) в JavaScript — это кусочки кода (обычно библиотеки или функции), которые предоставляют функциональность, которую браузеры могут не поддерживать. Полифилы позволяют разработчикам использовать современные функции языка или API, даже если они не поддерживаются всеми браузерами.

### Почему нужны полифилы?

JavaScript, как и другие языки программирования, развивается со временем. Добавляются новые функции, методы и объекты, которые делают язык более мощным и удобным. Однако не все браузеры сразу начинают поддерживать новые возможности. Это может создавать проблемы с кросс-браузерной совместимостью. Чтобы избежать этих проблем и обеспечить поддержку всех пользователей, разработчики используют полифилы.

### Пример использования полифилов

Допустим, вы хотите использовать метод `Array.prototype.includes`, который был добавлен в ECMAScript 2016 (ES7). Этот метод позволяет легко проверить, существует ли определённое значение в массиве:

```

let arr = [1, 2, 3];

if (arr.includes(2)) {
    console.log('2 присутствует в массиве');
}

```

Однако если этот код выполняется в старом браузере, который не поддерживает метод `includes`, будет выброшена ошибка. Чтобы избежать этого, можно использовать полифил:

```

if (!Array.prototype.includes) {
  Array.prototype.includes = function(value) {
    return this.indexOf(value) !== -1;
  };
}

```

Этот полифил проверяет, поддерживает ли текущий браузер метод `includes`. Если не поддерживает, добавляется его собственная реализация, использующая более старый метод `indexOf`.

### Где найти полифилы?

Существует много готовых полифилов, которые можно использовать в своих проектах. Некоторые популярные источники полифилов:

- **MDN Web Docs**: Часто на страницах документации MDN для различных методов и функций можно найти раздел "Polyfill", где приведён пример полифила для этой функции.
- **core-js**: Очень популярная библиотека, предоставляющая полифилы для многих функций ES5, ES6 и далее.
- **Polyfill.io**: Сервис, который предоставляет полифилы для браузеров в зависимости от их возможностей. Вы можете включить только те полифилы, которые нужны для вашего проекта, что уменьшает размер загружаемого кода.

### Важные моменты

- **Совместимость**: Полифилы обеспечивают совместимость кода с более старыми браузерами.
- **Производительность**: Иногда использование полифилов может замедлить работу, поскольку добавляется дополнительный слой абстракции.
- **Поддержка стандартов**: С течением времени полифилы могут стать ненужными, поскольку поддержка новых функций языка увеличивается среди браузеров.

### Заключение

Полифилы — это полезный инструмент для обеспечения кросс-браузерной совместимости, позволяющий использовать современные возможности языка JavaScript даже в старых браузерах.
