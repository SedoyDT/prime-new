23.1 Вопрос: "Что такое `DOMContentLoaded` и как оно отличается от события `load`?" ::  
23.2 Ответ: "`DOMContentLoaded` срабатывает, когда первоначальная HTML-страница полностью загружена и обработана, тогда как `load` срабатывает после загрузки всех ресурсов, включая изображения и стили."  
Пример кода:
```javascript
document.addEventListener('DOMContentLoaded', () => {
    console.log('DOM полностью загружен');
});

window.addEventListener('load', () => {
    console.log('Все ресурсы загружены');
});
```

24.1 Вопрос: "Как использовать методы `focus` и `blur` для управления фокусировкой на элементах формы?" ::  
24.2 Ответ: "Метод `focus` устанавливает фокус на элемент, а `blur` убирает его."  
Пример кода:
```javascript
const inputField = document.querySelector('input');

inputField.focus(); // Устанавливает фокус на поле ввода
inputField.blur(); // Убирает фокус с поля ввода
```
<!-- basicblock-end -->

25.1 Вопрос: "Как получать размеры элементов с помощью свойства `getBoundingClientRect`?" ::  
25.2 Ответ: "Метод `getBoundingClientRect` возвращает размеры элемента и его позицию относительно окна просмотра."  
Пример кода:
```javascript
const element = document.querySelector('.my-element');
const rect = element.getBoundingClientRect();

console.log('Ширина:', rect.width);
console.log('Высота:', rect.height);
console.log('Координаты:', rect.top, rect.left);
```
<!-- basicblock-end -->

26.1 Вопрос: "Как обрабатывать события прокрутки окна?" ::  
26.2 Ответ: "Событие `scroll` позволяет отслеживать прокрутку окна, что полезно для выполнения действий при прокрутке."  
Пример кода:
```javascript
window.addEventListener('scroll', () => {
    console.log('Страница прокручивается', window.scrollY);
});
```

27.1 Вопрос: "Что такое делегирование событий и как его использовать?" ::  
27.2 Ответ: "Делегирование событий позволяет установить обработчик события на родительский элемент, чтобы перехватывать события дочерних элементов."  
Пример кода:
```javascript
const list = document.querySelector('.my-list');

list.addEventListener('click', (event) => {
    if (event.target.matches('li')) {
        console.log('Элемент списка был нажат:', event.target.textContent);
    }
});
```
<!-- basicblock-end -->

28.1 Вопрос: "Как использовать `async` и `defer` для загрузки скриптов?" ::  
28.2 Ответ: "`async` загружает скрипт асинхронно, не блокируя загрузку страницы, а `defer` гарантирует, что скрипт будет выполнен после полной загрузки HTML-документа."  
Пример кода:
```html
<script src="script.js" async></script>
<script src="script2.js" defer></script>
```
<!-- basicblock-end -->

29.1 Вопрос: "Как работать с событием `keydown` для обработки ввода с клавиатуры?" ::  
29.2 Ответ: "Событие `keydown` срабатывает, когда клавиша нажата, позволяя перехватывать ввод с клавиатуры."  
Пример кода:
```javascript
document.addEventListener('keydown', (event) => {
    console.log('Нажата клавиша:', event.key);
});
```
