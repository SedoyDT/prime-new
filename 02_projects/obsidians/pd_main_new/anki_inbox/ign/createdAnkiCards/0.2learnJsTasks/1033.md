16.1 Вопрос: "Как навигировать по DOM-элементам с помощью свойств parentNode и childNodes?" ::  
16.2 Ответ: "Свойство parentNode позволяет получить родительский узел, а childNodes возвращает список дочерних узлов текущего элемента."  
Пример кода:
```javascript
const element = document.querySelector('.my-element');
const parent = element.parentNode;
const children = element.childNodes;

console.log('Родитель:', parent);
console.log('Дочерние узлы:', children);
```

17.1 Вопрос: "Как использовать метод querySelector для поиска элементов?" ::  
17.2 Ответ: "Метод querySelector позволяет находить элементы на странице с помощью CSS-селекторов."  
Пример кода:
```javascript
const firstDiv = document.querySelector('div'); // находит первый <div> на странице
const specialElement = document.querySelector('.special'); // находит элемент с классом 'special'
```

18.1 Вопрос: "Что такое событие mouseenter и как оно отличается от mouseover?" ::  
18.2 Ответ: "Событие mouseenter срабатывает, когда указатель мыши входит в элемент, без учета дочерних элементов, в то время как mouseover срабатывает для всех дочерних."  
Пример кода:
```javascript
const element = document.querySelector('.hoverable');
element.addEventListener('mouseenter', function() {
    console.log('Mouse entered the element');
});

element.addEventListener('mouseover', function() {
    console.log('Mouse is over the element or its children');
});
```

19.1 Вопрос: "Как управлять стилями элементов с помощью JavaScript?" ::  
19.2 Ответ: "Стиль элемента можно изменить, используя свойство style, чтобы установить CSS-свойства напрямую."  
Пример кода:
```javascript
const element = document.querySelector('.my-element');
element.style.color = 'blue'; // меняем цвет текста на синий
element.style.backgroundColor = 'yellow'; // меняем цвет фона на желтый
```

20.1 Вопрос: "Как использовать MutationObserver для отслеживания изменений в DOM?" ::  
20.2 Ответ: "MutationObserver позволяет отслеживать изменения, такие как добавление или удаление узлов в DOM."  
Пример кода:
```javascript
const observer = new MutationObserver((mutationsList) => {
    for (let mutation of mutationsList) {
        console.log('Изменение в DOM:', mutation);
    }
});

const config = { childList: true, subtree: true };
observer.observe(document.body, config);

// Пример изменения DOM
const newElement = document.createElement('div');
document.body.appendChild(newElement);
```

21.1 Вопрос: "Как обрабатывать события копирования и вставки в форму?" ::  
21.2 Ответ: "События cut, copy и paste позволяют перехватывать действия с буфером обмена."  
Пример кода:
```javascript
const inputField = document.querySelector('input');

inputField.addEventListener('cut', function() {
    console.log('Текст вырезан');
});

inputField.addEventListener('copy', function() {
    console.log('Текст скопирован');
});

inputField.addEventListener('paste', function() {
    console.log('Текст вставлен');
});
```

22.1 Вопрос: "Что такое события beforeunload и unload?" ::  
22.2 Ответ: "Событие beforeunload срабатывает перед закрытием страницы, позволяя показать предупреждение, а unload — когда страница закрывается."  
Пример кода:
```javascript
window.addEventListener('beforeunload', function(event) {
    event.preventDefault(); // Стандарт для предотвращения закрытия
    event.returnValue = ''; // Отображает стандартное предупреждение
});

window.addEventListener('unload', function() {
    console.log('Страница закрывается');
});
```
