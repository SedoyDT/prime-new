# Как с помощью js получить 4 td в tr
<!-- basicblock-start oid="ObsJ6OiesKX0D03NUnL8u2Ed"  deck='J_js_tables' -->
Как с помощью js получить 4 td в tr::


Чтобы получить 4-й элемент `<td>` в строке `<tr>` с помощью JavaScript, вы можете использовать несколько различных методов, в зависимости от структуры HTML и ваших требований.

### 1. **Через `children` или `getElementsByTagName`**

Если у вас есть строка таблицы (`<tr>`), и вы хотите получить 4-й элемент `<td>`, вы можете воспользоваться коллекцией дочерних элементов или методом `getElementsByTagName` для поиска всех `<td>` в строке.

Вот пример:

```
<table>
  <tr>
    <td>1</td>
    <td>2</td>
    <td>3</td>
    <td>4</td>
    <td>5</td>
  </tr>
</table>
```

### 1.1. **Использование `children`**

Если у вас есть доступ к строке `<tr>`, вы можете использовать свойство `children`, которое вернет все дочерние элементы (включая `<td>`) в виде HTMLCollection.

```
// Получаем строку таблицы (предположим, что это первый <tr> в таблице)
let tr = document.querySelector('tr');

// Получаем 4-й элемент <td> (индексация с 0)
let fourthTd = tr.children[3];

console.log(fourthTd);  // Выведет <td>4</td>
```

### 1.2. **Использование `getElementsByTagName`**

Метод `getElementsByTagName` вернет коллекцию всех `<td>` элементов внутри строки, и затем вы можете получить 4-й элемент (по индексу 3, так как индексация начинается с 0).

```
// Получаем строку таблицы (предположим, что это первый <tr> в таблице)
let tr = document.querySelector('tr');

// Получаем все <td> внутри <tr>
let tds = tr.getElementsByTagName('td');

// Получаем 4-й <td>
let fourthTd = tds[3];

console.log(fourthTd);  // Выведет <td>4</td>
```

### 2. **Если нужно найти все строки и получить 4-й `<td>` из конкретной строки**

Если у вас несколько строк в таблице и вам нужно найти 4-й элемент `<td>` в определенной строке, вы можете использовать `querySelectorAll` для поиска всех строк и затем работать с конкретной строкой.

```
// Получаем все строки в таблице
let rows = document.querySelectorAll('tr');

// Допустим, мы хотим получить 4-й <td> из первой строки
let tr = rows[0];

// Получаем 4-й <td> в этой строке
let fourthTd = tr.children[3];

console.log(fourthTd);  // Выведет <td>4</td>
```

### 3. **Использование индекса в `nth-child` для CSS**

Если вам нужно выбрать 4-й элемент `<td>` с помощью CSS, вы можете использовать псевдокласс `nth-child`.

```
let fourthTd = document.querySelector('tr td:nth-child(4)');
console.log(fourthTd);  // Выведет <td>4</td>
```

Это позволяет вам выбрать 4-й `<td>` внутри строки, не обращая внимания на другие элементы в строке.

### Итог

- **`children[3]`** — Это наиболее прямой способ получения 4-го `<td>` из строки `<tr>`.
- **`getElementsByTagName('td')[3]`** — Еще один способ через `getElementsByTagName`.
- **`querySelector('tr td:nth-child(4)')`** — Простой способ с использованием CSS-селекторов.

Выбор метода зависит от ваших предпочтений и структуры вашего документа.
