Вот список вопросов по указанным темам с примерами кода:

1.1 Вопрос: "Что такое DOM и как он представлен в браузере?" ::  
1.2 Ответ: "DOM (Document Object Model) представляет собой структурированное представление документа в виде дерева, где каждый узел соответствует элементу, атрибуту или тексту в HTML."  
Пример кода:
```javascript
// Получение корневого элемента документа
const rootElement = document.documentElement;
console.log(rootElement.tagName); // "HTML"
```
<!-- basicblock-end -->

<!-- basicblock-start oid="ObssgYknyxCkDV1KBSSPkgbk" deck='generated' -->

2.1 Вопрос: "Как навигировать по элементам DOM?" ::  
2.2 Ответ: "Навигация по DOM позволяет перемещаться между узлами дерева с помощью свойств, таких как parentNode, childNodes и nextSibling."  
Пример кода:
```javascript
const list = document.querySelector('ul');
const firstItem = list.firstChild; // первый узел (может быть текстовым)
const secondItem = firstItem.nextSibling.nextSibling; // второй элемент списка
console.log(secondItem.textContent); // текст второго элемента
```
<!-- basicblock-end -->

<!-- basicblock-start oid="ObsN6QTi9omNJolML0EudkZu" deck='generated' -->

3.1 Вопрос: "Как использовать методы getElement* и querySelector* для поиска элементов?" ::  
3.2 Ответ: "Методы getElementById, getElementsByClassName и querySelector позволяют находить элементы по их ID, классам или селекторам."  
Пример кода:
```javascript
const elementById = document.getElementById('myElement');
const elementsByClass = document.getElementsByClassName('myClass');
const firstMatchingElement = document.querySelector('.myClass');
console.log(elementById, elementsByClass, firstMatchingElement);
```
<!-- basicblock-end -->

<!-- basicblock-start oid="ObsVjTUG9JAO3olnURmTYdq8" deck='generated' -->

4.1 Вопрос: "Как изменить атрибуты и свойства элементов в DOM?" ::  
4.2 Ответ: "Атрибуты элементов могут быть изменены с помощью setAttribute, а свойства с помощью прямого доступа к свойствам объекта."  
Пример кода:
```javascript
const image = document.querySelector('img');
image.setAttribute('src', 'newImage.jpg'); // Изменение атрибута src
image.alt = 'New image'; // Изменение свойства alt
```
<!-- basicblock-end -->

5.1 Вопрос: "Что такое всплытие и погружение событий в JavaScript?" ::  
5.2 Ответ: "Всплытие событий происходит от целевого элемента к родителям, в то время как погружение — от родителя к целевому элементу."  
Пример кода:
```javascript
document.querySelector('ul').addEventListener('click', function() {
    console.log('Событие на ul');
});

document.querySelector('li').addEventListener('click', function(event) {
    console.log('Событие на li');
    event.stopPropagation(); // Остановка всплытия
});
```
<!-- basicblock-end -->

<!-- basicblock-start oid="Obs2ybhW6bUDABIoB8U0FUZl" deck='generated' -->

6.1 Вопрос: "Что такое делегирование событий и как его использовать?" ::  
6.2 Ответ: "Делегирование событий позволяет устанавливать обработчики на родительских элементах, чтобы избежать назначения их на каждый дочерний элемент."  
Пример кода:
```javascript
document.querySelector('ul').addEventListener('click', function(event) {
    if (event.target.tagName === 'LI') {
        console.log('Элемент списка был кликнут: ' + event.target.textContent);
    }
});
```
<!-- basicblock-end -->

7.1 Вопрос: "Как использовать события клавиатуры в JavaScript?" ::  
7.2 Ответ: "События keydown и keyup позволяют отслеживать нажатия клавиш на клавиатуре."  
Пример кода:
```javascript
document.addEventListener('keydown', function(event) {
    console.log('Нажата клавиша: ' + event.key);
});
```
<!-- basicblock-end -->

8.1 Вопрос: "Что такое MutationObserver и как он используется?" ::  
8.2 Ответ: "MutationObserver позволяет отслеживать изменения в DOM, такие как добавление или удаление элементов."  
Пример кода:
```javascript
const observer = new MutationObserver(function(mutations) {
    mutations.forEach(function(mutation) {
        console.log('Изменения в DOM:', mutation);
    });
});

observer.observe(document.body, { childList: true, subtree: true });
```
