9.1 Вопрос: "Как работать с размерами и прокруткой элементов в JavaScript?" ::  
9.2 Ответ: "Свойства offsetWidth, offsetHeight, scrollWidth и scrollHeight позволяют получать размеры элементов и управлять прокруткой."  
Пример кода:
```javascript
const element = document.querySelector('.my-element');
console.log('Ширина:', element.offsetWidth);
console.log('Высота:', element.offsetHeight);
console.log('Прокрутка по вертикали:', element.scrollTop);
```
<!-- basicblock-end -->

10.1 Вопрос: "Как определить размеры и прокрутку окна?" ::  
10.2 Ответ: "Свойства window.innerWidth и window.innerHeight позволяют получить размеры окна, а scrollY и scrollX — прокрутку."  
Пример кода:
```javascript
console.log('Ширина окна:', window.innerWidth);
console.log('Высота окна:', window.innerHeight);
console.log('Прокрутка по вертикали:', window.scrollY);
```
<!-- basicblock-end -->

11.1 Вопрос: "Что такое пользовательские события и как их создавать?" ::  
11.2 Ответ: "Пользовательские события могут быть созданы с помощью конструктора CustomEvent и затем диспатчены на целевой элемент."  
Пример кода:
```javascript
const event = new CustomEvent('myCustomEvent', { detail: { someData: 123 } });
document.dispatchEvent(event);

document.addEventListener('myCustomEvent', function(e) {
    console.log('Пользовательское событие:', e.detail.someData);
});
```
<!-- basicblock-end -->

12.1 Вопрос: "Как обрабатывать события отправки формы?" ::  
12.2 Ответ: "Событие submit позволяет перехватывать отправку формы для выполнения валидации или предотвращения отправки."  
Пример кода:
```javascript
const form = document.querySelector('form');
form.addEventListener('submit', function(event) {
    event.preventDefault(); // предотвращаем отправку
    console.log('Форма отправлена');
});
```
<!-- basicblock-end -->

13.1 Вопрос: "Как использовать события прокрутки?" ::  
13.2 Ответ: "Событие scroll позволяет отслеживать прокрутку элементов и окна."  
Пример кода:
```javascript
window.addEventListener('scroll', function() {
    console.log('Прокрутка окна:', window.scrollY);
});

const element = document.querySelector('.scrollable');
element.addEventListener('scroll', function() {
    console.log('Прокрутка элемента:', element.scrollTop);
});
```
<!-- basicblock-end -->

14.1 Вопрос: "Что такое событие DOMContentLoaded?" ::  
14.2 Ответ: "Событие DOMContentLoaded срабатывает, когда весь HTML-документ был полностью загружен и разобран, без ожидания стилей и изображений."  
Пример кода:
```javascript
document.addEventListener('DOMContentLoaded', function() {
    console.log('DOM полностью загружен и разобран');
});
```

15.1 Вопрос: "Как использовать атрибуты async и defer для загрузки скриптов?" ::  
15.2 Ответ: "Атрибут async позволяет загружать скрипт асинхронно, в то время как defer гарантирует, что скрипт будет выполнен после полной загрузки документа."  
Пример кода:
```html
<script src="script.js" async></script>
<script src="script.js" defer></script>
```
