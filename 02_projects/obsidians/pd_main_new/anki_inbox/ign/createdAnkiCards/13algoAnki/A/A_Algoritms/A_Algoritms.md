# Объясни алгоритм быстрой сортировки
<!-- basicblock-start oid="ObsXgE2rDz6ZgULB3t3ks5Bx"  deck='A_Algoritms' -->
Объясни алгоритм быстрой сортировки::


Алгоритм быстрой сортировки (QuickSort) — это один из наиболее эффективных алгоритмов сортировки, который использует принцип "разделяй и властвуй". Он выбирает один элемент в качестве опорного (pivot), а затем разделяет остальные элементы массива на две части: те, которые меньше опорного, и те, которые больше. После этого эти две части сортируются рекурсивно.

### Основная идея QuickSort:
1. Выбрать опорный элемент (pivot).
2. Разделить массив на две части: элементы, меньшие опорного, и элементы, большие опорного.
3. Рекурсивно применить QuickSort к каждой части.
4. Объединить отсортированные части.

### Псевдокод алгоритма быстрой сортировки

```
function quicksort(arr, low, high)
    if low < high
        // Определяем индекс опорного элемента
        pivotIndex = partition(arr, low, high)

        // Рекурсивно сортируем левую часть
        quicksort(arr, low, pivotIndex - 1)

        // Рекурсивно сортируем правую часть
        quicksort(arr, pivotIndex + 1, high)
```

Функция `partition` отвечает за выбор опорного элемента и перестановку элементов так, чтобы все элементы, меньшие опорного, оказались слева от него, а все большие — справа.

### Псевдокод функции `partition`

```
function partition(arr, low, high)
    // Выбираем последний элемент как опорный
    pivot = arr[high]

    // Индекс для разделения меньших элементов
    i = low - 1

    for j = low to high - 1
        if arr[j] <= pivot
            // Перемещаем элемент меньше опорного в левую часть
            i = i + 1
            swap(arr[i], arr[j])

    // Размещаем опорный элемент в правильную позицию
    swap(arr[i + 1], arr[high])
    
    return i + 1
```

### Пояснение:

1. **Выбор опорного элемента**: В данной реализации опорным элементом является последний элемент массива (`arr[high]`).
   
2. **Разделение массива**: Цикл `for` проходит по массиву и перемещает все элементы, которые меньше или равны опорному, в левую часть массива. Это делается с помощью индекса `i`, который отслеживает место для перемещения таких элементов.

3. **Размещение опорного элемента на правильное место**: После прохода по массиву опорный элемент перемещается в свою правильную позицию (в место `i + 1`).

4. **Рекурсия**: После разделения массива на две части рекурсивно вызывается `quicksort` для каждой из частей до тех пор, пока массив не будет отсортирован.

### Пример работы

Пусть массив: `[10, 80, 30, 90, 40, 50, 70]`

1. Выбираем последний элемент в качестве опорного: `pivot = 70`.
2. Переставляем элементы:
   - `10`, `30`, `40`, `50` перемещаются влево, так как они меньше `70`.
3. Массив становится: `[10, 30, 40, 50, 70, 90, 80]`.
4. Затем рекурсивно сортируем подмассивы `[10, 30, 40, 50]` и `[90, 80]`.

Этот процесс продолжается до полной сортировки массива.

### Время работы алгоритма:
- **Среднее время работы**: O(n log n), где `n` — количество элементов.
- **Худшее время работы**: O(n²), когда каждый раз выбирается наихудший опорный элемент (например, если массив уже отсортирован).

# Чтобы преобразовать строку, записанную в инфиксной нотации (например, `1 + 2.2 * 2.2 / 3.1`), в постфиксную нотацию (обратную польскую нотацию), можно воспользоваться алгоритмом "сортировочной станции" (Shunting-yard algorithm), разработанным Эдсгером Дейкстрой.
<!-- basicblock-start oid="Obsm3tdI8lxLTZA8K1dEDmPP"  deck='A_Algoritms' -->
Чтобы преобразовать строку, записанную в инфиксной нотации (например, `1 + 2.2 * 2.2 / 3.1`), в постфиксную нотацию (обратную польскую нотацию), можно воспользоваться алгоритмом "сортировочной станции" (Shunting-yard algorithm), разработанным Эдсгером Дейкстрой.::


Вот как это можно реализовать на PHP:

```
<?php
function toPolishNotation(string $expression): string {
    // Убираем лишние пробелы
    $expression = preg_replace('/\s+/', '', $expression);
    // Разбиваем строку на операнды и операторы
    $tokens = preg_split('((\d+\.?\d*)|([\+\-\*\/\(\)]))', $expression, -1, PREG_SPLIT_NO_EMPTY | PREG_SPLIT_DELIM_CAPTURE);

    // Операторы с их приоритетами
    $precedence = [
        '+' => 1,
        '-' => 1,
        '*' => 2,
        '/' => 2
    ];

    $output = []; // Выходной массив
    $operators = []; // Стек операторов

    foreach ($tokens as $token) {
        if (is_numeric($token)) {
            // Если токен - число, добавляем его в выходной массив
            $output[] = $token;
        } elseif (isset($precedence[$token])) {
            // Если токен - оператор
            while (!empty($operators) && end($operators) !== '(' && $precedence[end($operators)] >= $precedence[$token]) {
                $output[] = array_pop($operators);
            }
            $operators[] = $token;
        } elseif ($token === '(') {
            // Если токен - открывающая скобка, добавляем ее в стек операторов
            $operators[] = $token;
        } elseif ($token === ')') {
            // Если токен - закрывающая скобка, выталкиваем все операторы до открывающей скобки
            while (end($operators) !== '(') {
                $output[] = array_pop($operators);
            }
            array_pop($operators); // Удаляем открывающую скобку
        }
    }

    // Выталкиваем оставшиеся операторы в стек
    while (!empty($operators)) {
        $output[] = array_pop($operators);
    }

    // Возвращаем результат в виде строки
    return implode(' ', $output);
}

// Пример использования
$expression = "1 + 2.2 * 2.2 / 3.1";
$polishNotation = toPolishNotation($expression);
echo $polishNotation; // Вывод: 1 2.2 2.2 * 3.1 / +
?>
```

### Объяснение работы функции:

1. **Удаление пробелов**: Все лишние пробелы удаляются из выражения для упрощения дальнейшей обработки.

2. **Разбиение строки на токены**: Выражение разбивается на токены, которые могут быть числами, операторами или скобками.

3. **Алгоритм сортировочной станции**:
    - Числа сразу добавляются в выходной массив.
    - Операторы помещаются в стек, причём операторы с более высоким приоритетом (например, умножение и деление) вытесняют менее приоритетные операторы из стека.
    - Скобки обрабатываются так, чтобы содержимое в них вычислялось сначала.

4. **Формирование результата**: После обработки всех токенов оставшиеся в стеке операторы добавляются к выходному массиву.

5. **Результат**: Возвращается строка с выражением в постфиксной нотации.

### Пример работы:

Для выражения `"1 + 2.2 * 2.2 / 3.1"` результатом будет строка в польской нотации:

```
1 2.2 2.2 * 3.1 / +
```

Эту строку можно дальше использовать для вычислений в польской нотации.
