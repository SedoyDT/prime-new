1.1 Вопрос: "Чем отличается тип `void` от `undefined` в TypeScript?" ::  
1.2 Ответ: "Тип `void` используется для описания функций, которые не возвращают значения. Хотя в JavaScript такие функции возвращают `undefined`, в TypeScript `void` и `undefined` — это разные типы."  
Пример кода:
```typescript
function noop(): void {
  return; // Возвращает 'undefined', но тип всё равно 'void'
}

const result = noop(); // result имеет тип void
```

2.1 Вопрос: "Чем отличается тип `object` от глобального типа `Object` в TypeScript?" ::  
2.2 Ответ: "Тип `object` относится ко всем значениям, которые не являются примитивами (например, строки, числа, булевы значения). Глобальный тип `Object` охватывает все объекты, включая примитивные значения. Тип `object` должен использоваться вместо `Object`."  
Пример кода:
```typescript
const obj: object = { key: "value" }; // Допустимо
const obj2: Object = "string"; // Также допустимо, но лучше избегать использования Object

function handleObject(input: object) {
  // input должен быть объектом, нельзя передать примитив
}
```

3.1 Вопрос: "Почему использование типа `unknown` безопаснее, чем `any`?" ::  
3.2 Ответ: "Тип `unknown` более безопасен, чем `any`, потому что перед выполнением каких-либо операций с переменной необходимо явно проверить её тип. Это предотвращает ошибки, связанные с неопределёнными типами."  
Пример кода:
```typescript
function processUnknown(value: unknown) {
  if (typeof value === "string") {
    console.log(value.toUpperCase()); // Допустимо только после проверки типа
  }
}

processUnknown("Hello"); // Корректно
processUnknown(123); // Ничего не происходит, так как тип не string
```

4.1 Вопрос: "Что представляет собой тип `never` и когда он используется в TypeScript?" ::  
4.2 Ответ: "Тип `never` обозначает значение, которое никогда не наблюдается. Он используется в функциях, которые либо выбрасывают исключение, либо приводят к завершению программы. Также `never` используется TypeScript, когда в объединении больше не остаётся значений."  
Пример кода:
```typescript
function fail(message: string): never {
  throw new Error(message); // Функция никогда не завершится корректно
}

function checkType(x: string | number) {
  if (typeof x === "string") {
    console.log("It's a string");
  } else if (typeof x === "number") {
    console.log("It's a number");
  } else {
    x; // Здесь x имеет тип 'never', так как другие типы исключены
  }
}
```

5.1 Вопрос: "Почему тип `Function` считается небезопасным и как можно ограничить функцию более безопасно?" ::  
5.2 Ответ: "Тип `Function` позволяет вызывать функцию без строгой типизации аргументов и возвращаемого значения, что может привести к ошибкам. Вместо этого лучше использовать более строгие типы, такие как `() => void`."  
Пример кода:
```typescript
function executeFunction(f: Function) {
  return f(1, 2, 3); // Неизвестно, что вернёт эта функция, тип any
}

function saferFunction(f: () => void) {
  f(); // Безопасно, так как ожидается функция без аргументов и без возвращаемого значения
}

const logMessage = () => console.log("Hello");
saferFunction(logMessage); // Корректный вызов
```
