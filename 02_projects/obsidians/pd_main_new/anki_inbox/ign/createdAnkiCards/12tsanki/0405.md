1.1 Вопрос: "В чем разница между интерфейсами и типами в TypeScript?" ::  
1.2 Ответ: "Интерфейсы в TypeScript используются для определения структуры объектов и могут быть расширены другими интерфейсами. Типы же могут представлять более сложные структуры, такие как объединения и пересечения."  
Пример кода:
```typescript
interface Person {
  name: string;
  age: number;
}

type Employee = Person & {
  position: string;
};

const employee: Employee = {
  name: "Alice",
  age: 30,
  position: "Developer",
};
```

2.1 Вопрос: "Что такое обобщенные типы (generics) и когда их следует использовать?" ::  
2.2 Ответ: "Обобщенные типы позволяют создавать компоненты, которые работают с различными типами данных, обеспечивая гибкость и повторное использование кода. Их следует использовать, когда необходимо создать функцию или класс, которые могут работать с несколькими типами."  
Пример кода:
```typescript
function identity<T>(arg: T): T {
  return arg;
}

const num = identity(10); // num имеет тип number
const str = identity("Hello"); // str имеет тип string
```

3.1 Вопрос: "Что такое `unknown` и как он отличается от `any`?" ::  
3.2 Ответ: "Тип `unknown` представляет значение любого типа, но требует проверки типа перед использованием. `any` также представляет значение любого типа, но отключает проверку типов, что может привести к ошибкам."  
Пример кода:
```typescript
let value: unknown;
value = 42; // OK
value = "Hello"; // OK

// Нужно проверять тип перед использованием
if (typeof value === "string") {
  console.log(value.toUpperCase()); // OK
}

let anyValue: any;
anyValue = 42;
console.log(anyValue.toUpperCase()); // Ошибка времени выполнения
```

4.1 Вопрос: "Как работают декораторы в TypeScript?" ::  
4.2 Ответ: "Декораторы в TypeScript — это специальные аннотации, которые можно применять к классам, методам, свойствам и параметрам. Они позволяют добавлять дополнительные функции, такие как логирование или валидация."  
Пример кода:
```typescript
function Log(target: any, propertyName: string, descriptor: PropertyDescriptor) {
  const originalMethod = descriptor.value;
  descriptor.value = function (...args: any[]) {
    console.log(`Calling ${propertyName} with arguments: ${args}`);
    return originalMethod.apply(this, args);
  };
}

class MathOperations {
  @Log
  add(a: number, b: number): number {
    return a + b;
  }
}

const math = new MathOperations();
math.add(5, 10); // В консоли будет вывод вызова метода
```

5.1 Вопрос: "Что такое `readonly` и как он используется?" ::  
5.2 Ответ: "Модификатор `readonly` используется для определения свойств, которые не могут быть изменены после инициализации. Это помогает предотвратить случайные изменения значений."  
Пример кода:
```typescript
class Point {
  readonly x: number;
  readonly y: number;

  constructor(x: number, y: number) {
    this.x = x;
    this.y = y;
  }
}

const point = new Point(10, 20);
console.log(point.x); // 10
// point.x = 15; // Ошибка: Cannot assign to 'x' because it is a read-only property.
```
