1.1 Вопрос: "Что такое интерфейсы в TypeScript и как они отличаются от типов?" ::  
1.2 Ответ: "Интерфейсы в TypeScript определяют структуру объектов, позволяя описывать типы свойств и методов. В отличие от типов, интерфейсы могут быть расширены и реализованы классами."  
Пример кода:
```typescript
interface User {
    name: string;
    age: number;
}

const user: User = {
    name: "Alice",
    age: 30
};
```
<!-- basicblock-end -->

2.1 Вопрос: "Какова разница между `unknown` и `any`?" ::  
2.2 Ответ: "`any` позволяет отключить проверку типов, что может привести к ошибкам, в то время как `unknown` требует явной проверки типа перед использованием."  
Пример кода:
```typescript
let value: any = 5;
value = "now I'm a string"; // все в порядке

let unknownValue: unknown = 5;
// unknownValue.toString(); // Ошибка: объект 'unknown' не может быть использован без проверки типа
if (typeof unknownValue === "string") {
    console.log(unknownValue.toString());
}
```
<!-- basicblock-end -->

3.1 Вопрос: "Что такое дженерики и как они используются в TypeScript?" ::  
3.2 Ответ: "Дженерики позволяют создавать функции и классы, которые работают с любыми типами, сохраняя информацию о типах во время выполнения."  
Пример кода:
```typescript
function identity<T>(arg: T): T {
    return arg;
}

let output = identity<string>("Hello World");
let numberOutput = identity<number>(100);
```

4.1 Вопрос: "В чем разница между `public`, `private` и `protected` модификаторами доступа?" ::  
4.2 Ответ: "`public` доступен везде, `private` доступен только в пределах класса, а `protected` доступен в классе и его подклассах."  
Пример кода:
```typescript
class Person {
    public name: string;
    private age: number;
    protected address: string;

    constructor(name: string, age: number, address: string) {
        this.name = name;
        this.age = age;
        this.address = address;
    }
}

class Employee extends Person {
    constructor(name: string, age: number, address: string) {
        super(name, age, address);
        console.log(this.address); // доступно
    }
}

const person = new Person("Alice", 30, "Main St"); 
// console.log(person.age); // Ошибка: 'age' является приватным свойством
```

5.1 Вопрос: "Как работать с кортежами в TypeScript?" ::  
5.2 Ответ: "Кортежи позволяют создавать массивы с фиксированным количеством элементов, где каждый элемент может иметь свой тип."  
Пример кода:
```typescript
let tuple: [string, number];
tuple = ["Alice", 30]; // Верно
// tuple = [30, "Alice"]; // Ошибка: элементы не соответствуют типам
```
