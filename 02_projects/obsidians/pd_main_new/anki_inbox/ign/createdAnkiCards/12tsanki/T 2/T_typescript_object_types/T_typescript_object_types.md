# - **Используйте `interface`, когда**:
<!-- basicblock-start oid="ObsF71N7NZVWT36yYjs7MkeW"  deck='T_typescript_object_types' -->
- **Используйте `interface`, когда**:::

  - Вам нужно описать форму объекта.
  - Вы хотите воспользоваться преимуществами слияния деклараций (например, расширение или модификация интерфейсов позже).
  - Вы предпочитаете синтаксис `extends` для наследования.

- **Используйте `type`, когда**:
  - Вам нужна большая гибкость, например, для определения объединений, пересечений или сложных типов, таких как кортежи.
  - Вы хотите определить примитивные типы, функциональные типы или другие необъектные типы.
  - Вы не планируете модифицировать или расширять тип после его определения.

---

### Заключение:

И `interface`, и `type` — мощные инструменты в TypeScript, и выбор между ними часто зависит от конкретных потребностей вашего проекта. Если вы работаете в основном с формами объектов и хотите иметь возможность расширять или объединять типы, то `interface` — хороший выбор. Если вам нужна большая гибкость или вы хотите определить сложные типы, такие как объединения или кортежи, то `type` будет лучшим вариантом.

# Чем типы отличаются от интерфейсов?
<!-- basicblock-start oid="Obs8b5bB7o0v3kDdBFV8qjDb"  deck='T_typescript_object_types' -->
Чем типы отличаются от интерфейсов?::


Давайте подробнее разберем различия между `interface` и `type` в TypeScript. Эти две конструкции используются для определения пользовательских типов, но между ними есть важные различия, которые могут повлиять на выбор той или иной конструкции в зависимости от ситуации.

---

### 1. **Расширение (Extensibility)**

#### **`interface`**
- **Поддерживает `extends`**:
  - Интерфейсы в TypeScript могут быть расширены с помощью ключевого слова `extends`. Это позволяет создавать новые интерфейсы, которые наследуют свойства и методы существующих.
  - Пример:
    ```
    interface Person {
      name: string;
    }

    interface Employee extends Person {
      employeeId: number;
    }

    const employee: Employee = { name: "Alice", employeeId: 123 };
    
```
  - Здесь `Employee` наследует все свойства из `Person` и добавляет новое свойство `employeeId`.

#### **`type`**
- **Поддерживает объединение (`&`)**:
  - Типы могут быть расширены с помощью пересечения (`&`) для объединения нескольких типов в один.
  - Пример:
    ```
    type Person = {
      name: string;
    };

    type Employee = Person & {
      employeeId: number;
    };

    const employee: Employee = { name: "Alice", employeeId: 123 };
    
```
  - Здесь `Employee` создается путем объединения `Person` с другим типом, который имеет свойство `employeeId`.

---

### 2. **Гибкость (Flexibility)**

#### **`interface`**
- **Только для объектов**:
  - Интерфейсы предназначены для описания структуры объектов. Их нельзя использовать для определения примитивных типов, объединений или других сложных типов, таких как кортежи.
  - Пример:
    ```
    interface User {
      name: string;
      age: number;
    }
    
```
  - Вы не можете использовать интерфейс для определения чего-то вроде объединения типов (`string | number`), кортежа (`[string, number]`) или примитивного типа (`number`).

#### **`type`**
- **Может использоваться для любых типов**:
  - Псевдоним типа (`type`) более гибкий, потому что он может представлять не только формы объектов, но также объединения, пересечения, примитивы, кортежи и многое другое.
  - Пример:
    ```
    type ID = string | number; // Объединение типов
    type Coordinates = [number, number]; // Кортеж
    type Name = string; // Примитивный тип
    
```

---

### 3. **Повторное объявление (Re-declaration)**

#### **`interface`**
- **Поддерживает слияние**:
  - Одна из ключевых особенностей `interface` заключается в том, что если вы несколько раз объявите один и тот же интерфейс, TypeScript автоматически объединит их в один интерфейс. Это называется **объединением деклараций**.
  - Пример:
    ```
    interface User {
      name: string;
    }

    interface User {
      age: number;
    }

    const user: User = { name: "Alice", age: 25 };
    
```
  - В этом случае два интерфейса `User` объединяются, в результате чего получается единый интерфейс `User` с обоими свойствами `name` и `age`.

#### **`type`**
- **Не поддерживает повторное объявление**:
  - В отличие от интерфейсов, псевдонимы типов (`type`) не могут быть переопределены. Если вы попытаетесь дважды объявить один и тот же псевдоним типа, TypeScript выдаст ошибку.
  - Пример:
    ```
    type User = {
      name: string;
    };

    // Ошибка: Дублирующий идентификатор 'User'
    type User = {
      age: number;
    };
    
```
  - Это делает `type` менее гибким, когда речь идет о расширении или модификации существующих типов после их определения.

---

### Сводка ключевых различий:

| Характеристика       | `interface`                                | `type`                                      |
|----------------------|--------------------------------------------|---------------------------------------------|
| **Расширение**       | Поддерживает `extends`                    | Поддерживает пересечение (`&`)              |
| **Гибкость**         | Только для объектов                       | Может использоваться для любых типов (объекты, объединения, кортежи и т. д.) |
| **Повторное объявление** | Поддерживает слияние                    | Не поддерживает повторное объявление        |
