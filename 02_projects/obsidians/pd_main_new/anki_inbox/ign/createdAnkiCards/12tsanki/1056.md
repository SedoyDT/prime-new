10.1 Вопрос: "Что такое условные типы в TypeScript?" ::  
10.2 Ответ: "Условные типы позволяют создавать типы на основе условий, используя синтаксис `T extends U ? X : Y`."  
Пример кода:
```typescript
type IsString<T> = T extends string ? "Yes" : "No";

type Test1 = IsString<string>; // "Yes"
type Test2 = IsString<number>; // "No"
```

11.1 Вопрос: "Как использовать оператор `keyof` в TypeScript?" ::  
11.2 Ответ: "Оператор `keyof` позволяет получить все ключи типа как строковый литерал."  
Пример кода:
```typescript
interface Person {
    name: string;
    age: number;
}

type PersonKeys = keyof Person; // "name" | "age"

function getValue<T, K extends keyof T>(obj: T, key: K) {
    return obj[key];
}

const person: Person = { name: "Alice", age: 30 };
const name = getValue(person, "name"); // "Alice"
```

12.1 Вопрос: "Что такое пересечение типов в TypeScript?" ::  
12.2 Ответ: "Пересечение типов позволяет объединять несколько типов в один, создавая новый тип с свойствами всех исходных типов."  
Пример кода:
```typescript
interface User {
    name: string;
}

interface Admin {
    privileges: string[];
}

type AdminUser = User & Admin;

const admin: AdminUser = {
    name: "Alice",
    privileges: ["manage-users", "edit-settings"]
};
```

13.1 Вопрос: "Что такое обобщенные типы (Mapped Types)?" ::  
13.2 Ответ: "Обобщенные типы позволяют создавать новые типы на основе существующих, изменяя свойства."  
Пример кода:
```typescript
type ReadOnly<T> = {
    readonly [K in keyof T]: T[K];
};

interface User {
    name: string;
    age: number;
}

const readonlyUser: ReadOnly<User> = {
    name: "Alice",
    age: 30
};
// readonlyUser.age = 31; // Ошибка: свойство 'age' только для чтения
```

14.1 Вопрос: "Как работает `this` в стрелочных функциях по сравнению с обычными?" ::  
14.2 Ответ: "Стрелочные функции захватывают контекст `this` из окружающей области видимости, тогда как обычные функции создают новый контекст."  
Пример кода:
```typescript
class Counter {
    count = 0;

    increment() {
        setTimeout(function() {
            this.count++; // 'this' здесь не ссылается на экземпляр Counter
            console.log(this.count); // NaN
        }, 1000);
    }

    incrementWithArrow() {
        setTimeout(() => {
            this.count++; // 'this' ссылается на экземпляр Counter
            console.log(this.count); // 1
        }, 1000);
    }
}

const counter = new Counter();
counter.increment(); // NaN
counter.incrementWithArrow(); // 1
```
