# Напиши регулярное выражение для всех строк кроме bak
<!-- basicblock-start oid="ObsB957tVXk6wQq6VYxAW8rl"  deck='1_PD_regexp' -->
Напиши регулярное выражение для всех строк кроме bak::


Чтобы создать регулярное выражение, которое соответствует всем строкам, кроме тех, которые содержат слово "bak", можно использовать отрицательную последовательность.

Вот пример регулярного выражения:

```
^(?!.*\bbak\b).*
```

### Разбор регулярного выражения:

1. `^` — начало строки.
2. `(?!)` — негативный просмотр вперед (negative lookahead), который гарантирует, что следующее условие не выполнено.
3. `.*\bbak\b` — любые символы перед и после слова "bak", где `\b` указывает на границы слова.
4. `.*` — оставшаяся часть строки, если условие `(?!)` не выполнено.

Таким образом, это регулярное выражение будет соответствовать любой строке, которая **не содержит** слово "bak".
