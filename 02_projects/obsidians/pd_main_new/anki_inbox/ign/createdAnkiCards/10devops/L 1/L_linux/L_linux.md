# 🤔 **<u>Чем юниксовая система отличается от линуксовой?</u>** 
<!-- basicblock-start oid="ObssOmwBmjzhE93QyHY6L6uL"  deck='L_linux' -->
🤔 **<u>Чем юниксовая система отличается от линуксовой?</u>** ::


Unix и Linux — это две операционные системы, которые часто сравнивают из-за их схожести и общего происхождения. Однако у них есть значительные различия, касающиеся их истории, лицензирования, архитектуры и использования.

🚩**Основные отличия между Unix и Linux**

🟠**Лицензирование**
**Unix**: Большинство версий Unix являются коммерческими и проприетарными. Для их использования требуется лицензия. Некоторые версии, такие как BSD (Berkeley Software Distribution), являются открытыми и лицензируются по лицензии BSD.
**Linux**: Распространяется по лицензии GNU General Public License (GPL), что означает, что он бесплатен и открыт для использования, модификации и распространения. Исходный код доступен всем, что позволяет пользователям вносить изменения и улучшения.

🟠**Архитектура и компоненты**
**Unix**: Часто имеют монолитное ядро, где основные системные службы интегрированы в одно ядро. Обеспечивает многозадачность, многопользовательский режим и защищенную память. Включает стандартные утилиты и шеллы, такие как Bourne Shell (sh).
**Linux**: Также имеет монолитное ядро, но с модульной архитектурой, что позволяет загружать и выгружать модули в ядро без перезагрузки системы. Включает широкий набор утилит и инструментов GNU, таких как Bash (Bourne Again Shell).

🟠**Совместимость и стандарты**
**Unix**: Следуют стандартам POSIX (Portable Operating System Interface), что обеспечивает совместимость между различными версиями Unix. Существует несколько проприетарных версий Unix.
**Linux**: Также совместим с POSIX, что обеспечивает высокую степень совместимости с Unix-системами. Существует множество дистрибутивов Linux (Debian, Ubuntu, CentOS, Fedora и т.д.), каждый из которых имеет свои особенности и наборы пакетов, но все они основаны на общем ядре Linux.

🟠**Применение и популярность**
**Unix**: Используется в крупных корпоративных и научных средах. Часто применяется в критически важных системах благодаря своей надежности и стабильности.
**Linux**: Широко используется в серверах, суперкомпьютерах, встраиваемых системах, настольных ПК и мобильных устройствах (например, Android). Популярен среди разработчиков и энтузиастов благодаря своей открытости, гибкости и сообществу.

# Как создать группу в macos
<!-- basicblock-start oid="ObsOOTrrMhI8dKRb8dDWNPMf"  deck='L_linux' -->
Как создать группу в macos::


В macOS, как и в других Unix-подобных системах, можно создать новую группу с помощью команды `dscl`. Вот как это сделать:

1. **Открыть терминал**:
   Запустите приложение "Терминал" на вашем Mac.

2. **Создать новую группу**:
   Чтобы создать группу, используйте следующую команду:
   ```
   sudo dscl . -create /Groups/groupname
   
```

   Здесь `groupname` — это имя группы, которую вы хотите создать.

3. **Установить GID для группы (по желанию)**:
   Чтобы назначить группе определенный идентификатор GID, используйте следующую команду:
   ```
   sudo dscl . -create /Groups/groupname PrimaryGroupID gid
   
```

   Замените `gid` на уникальный числовой идентификатор для группы (например, 500 или выше).

4. **Добавление описания (опционально)**:
   Вы можете добавить описание для группы:
   ```
   sudo dscl . -create /Groups/groupname RealName "Group Description"
   
```

5. **Добавление пользователей в группу**:
   Чтобы добавить пользователей в созданную группу, выполните следующую команду:
   ```
   sudo dscl . -append /Groups/groupname GroupMembership username
   
```

   Здесь `username` — это имя пользователя, которого нужно добавить в группу.

6. **Проверка созданной группы**:
   Чтобы проверить, что группа успешно создана, используйте команду:
   ```
   dscl . -read /Groups/groupname
   
```

Теперь вы создали новую группу и можете добавлять в неё пользователей.

# Как создать группу ?
<!-- basicblock-start oid="ObsPbz4SudYH0qchIBzzkxcj"  deck='L_linux' -->
Как создать группу ?::


Чтобы создать новую группу в Linux, используется команда `groupadd`. Вот несколько примеров:

1. **Создание новой группы**:
   Чтобы создать группу с именем `groupname`, используйте команду:
   ```
   sudo groupadd groupname
   
```

2. **Создание группы с конкретным GID (Group ID)**:
   Если вы хотите указать идентификатор группы (GID) при создании, используйте параметр `-g`:
   ```
   sudo groupadd -g 1001 groupname
   
```

3. **Создание системной группы**:
   Системные группы обычно используются для внутренних целей и имеют GID ниже 1000 (по умолчанию). Чтобы создать системную группу, используйте флаг `-r`:
   ```
   sudo groupadd -r groupname
   
```

После создания группы можно добавить пользователей в нее с помощью команды `usermod`.

# linux как получить список групп?
<!-- basicblock-start oid="Obs7SW0dwpZ3ZKiqynDCaoko"  deck='L_linux' -->
linux как получить список групп?::


Чтобы получить список всех групп в Linux, можно использовать одну из следующих команд:

1. **Просмотр всех групп в системе**:
   ```
   cat /etc/group
   
```

   Эта команда выведет содержимое файла `/etc/group`, где хранится информация о группах.

2. **Список групп пользователя**:
   Чтобы увидеть группы, к которым принадлежит конкретный пользователь (например, текущий), используйте:
   ```
   groups
   
```

   Для вывода групп другого пользователя:
   ```
   groups имя_пользователя
   
```

3. **Команда getent**:
   Вывести все группы через `getent`:
   ```
   getent group
   
```

   Эта команда удобна тем, что работает не только с локальными группами, но и с группами, если используется удаленная аутентификация, такая как LDAP.
