# Что такое header?
<!-- basicblock-start oid="Obs7b2x1l1gu7xED4h5uXlAi"  deck='H_HTTP' -->
Что такое header?::


**Header запроса** (заголовок HTTP-запроса) — это часть HTTP-запроса, которая содержит дополнительную информацию о запросе или о клиенте, который его отправляет. Он передаётся вместе с HTTP-запросом на сервер и служит для передачи метаданных, управляющих инструкций и специфичных параметров для успешной обработки запроса.

### Основные функции header'ов запроса:
1. **Аутентификация и авторизация**: Например, передача токена доступа (JWT) через заголовок `Authorization`.
2. **Указание формата данных**: Например, заголовок `Content-Type` указывает тип данных в запросе (например, `application/json`, `text/html` и т.д.).
3. **Информация о клиенте**: Заголовок `User-Agent` содержит информацию о браузере или другом клиенте, который отправляет запрос.
4. **Кэширование**: Заголовки, такие как `Cache-Control` или `If-Modified-Since`, используются для управления кэшированием на стороне сервера и клиента.
5. **Язык и локализация**: Заголовок `Accept-Language` указывает предпочтительный язык для ответа сервера.

### Пример запроса с заголовками:
```
GET /index.html HTTP/1.1
Host: example.com
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)
Accept-Language: en-US,en;q=0.9
Accept-Encoding: gzip, deflate
Connection: keep-alive
```

### Некоторые часто используемые заголовки:
- **`Host`**: Указывает домен (например, `example.com`), на который отправляется запрос.
- **`User-Agent`**: Описывает клиента, например, тип браузера или операционную систему.
- **`Accept`**: Указывает, какие форматы ответов предпочтительны (например, `text/html` или `application/json`).
- **`Authorization`**: Используется для передачи токенов или данных авторизации.
- **`Content-Type`**: Определяет тип содержимого в запросе (например, `application/json`).

Заголовки позволяют серверу и клиенту взаимодействовать с учётом различных условий и конфигураций.
