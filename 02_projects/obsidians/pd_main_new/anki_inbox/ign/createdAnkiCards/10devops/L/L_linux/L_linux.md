# ripgrep поиск папки
<!-- basicblock-start oid="ObsGvssxdPCWo29dKQ89kEx8"  deck='L_linux' -->
ripgrep поиск папки::


Чтобы найти папку с помощью `ripgrep` (или `rg`), вы можете использовать различные варианты команд в зависимости от того, что именно вы ищете. Однако `ripgrep` в основном предназначен для поиска по содержимому файлов, а не по имени файлов или папок. Для поиска по именам файлов и папок обычно используется `find` или `fd`.

Тем не менее, если вам нужно найти папку с использованием `ripgrep`, вы можете сделать это следующим образом:

1. **Искать по имени директории**: Если вам нужно найти папку с конкретным именем, вы можете использовать `rg` вместе с фильтром для имен файлов и папок. Например, чтобы найти все папки с именем "example" в текущем каталоге и подкаталогах, вы можете использовать следующую команду:

    ```
    rg --files --glob '!*/' | grep '/example$'
    
```

   Здесь `--files` сообщает `ripgrep` искать только имена файлов (и папок), а `--glob '!*/'` исключает файлы (чтобы искать только папки). Затем `grep '/example$'` фильтрует результаты, оставляя только те, которые заканчиваются на "/example".

2. **Искать по содержимому файлов внутри папок**: Если вам нужно найти папку по содержимому файлов внутри этой папки, вы можете использовать `rg` для поиска по содержимому файлов и затем вручную определить, в каких папках находятся искомые файлы.

    ```
    rg "search_term"
    
```

   После выполнения этой команды, `ripgrep` выведет список файлов и строк, содержащих "search_term". Вы можете затем определить, в каких папках находятся эти файлы.

Для поиска папок по имени и пути более удобно использовать команду `find` или `fd`. Например:

- С `find`:

    ```
    find . -type d -name "example"
    
```

- С `fd` (если установлен):

    ```
    fd --type d "example"
    
```

Обе команды выполнит поиск директории с именем "example" в текущем каталоге и подкаталогах.
