# название текущей ветки git через консоль
<!-- basicblock-start oid="ObsuAC3s7FZH29qByGrWxQJE"  deck='G_git' -->
название текущей ветки git через консоль::


Чтобы узнать название текущей ветки в Git через консоль, используйте следующую команду:

```
git branch --show-current
```

Эта команда отобразит имя текущей ветки.

### Альтернативный способ:
Вы также можете использовать команду:

```
git rev-parse --abbrev-ref HEAD
```

Оба способа вернут название активной ветки, на которой вы находитесь в данный момент.
