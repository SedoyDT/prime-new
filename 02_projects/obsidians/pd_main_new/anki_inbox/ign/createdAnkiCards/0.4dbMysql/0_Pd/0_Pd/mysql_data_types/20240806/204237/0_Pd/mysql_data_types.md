**Unsigned** типы данных в MySQL отличаются от **signed** тем, что они могут хранить только неотрицательные значения. Это расширяет диапазон положительных значений, которые может хранить тип данных, за счет того, что не требуется выделять пространство для хранения отрицательных значений.

### Примеры Unsigned Integer Types в MySQL

Вот как выглядит диапазон значений для целочисленных типов данных с флагом `UNSIGNED`:

- **TINYINT UNSIGNED**: Целое число от 0 до 255.
- **SMALLINT UNSIGNED**: Целое число от 0 до 65,535.
- **MEDIUMINT UNSIGNED**: Целое число от 0 до 16,777,215.
- **INT UNSIGNED**: Целое число от 0 до 4,294,967,295.
- **BIGINT UNSIGNED**: Целое число от 0 до 18,446,744,073,709,551,615.

### Примеры использования

#### Создание таблицы с unsigned типами данных

```

CREATE TABLE example_unsigned (
    id INT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
    quantity SMALLINT UNSIGNED,
    total BIGINT UNSIGNED
);

```

В этом примере:

- `id` — `INT UNSIGNED`, что означает, что значение этого поля будет в диапазоне от 0 до 4,294,967,295.
- `quantity` — `SMALLINT UNSIGNED`, что означает, что значение этого поля будет в диапазоне от 0 до 65,535.
- `total` — `BIGINT UNSIGNED`, что означает, что значение этого поля будет в диапазоне от 0 до 18,446,744,073,709,551,615.

### Зачем использовать `UNSIGNED`?

1. **Увеличение диапазона положительных значений**: Если вам не нужно хранить отрицательные значения, использование `UNSIGNED` позволяет увеличить максимальное положительное значение, которое можно хранить в поле.
2. **Экономия пространства**: Хотя это не всегда применимо, использование `UNSIGNED` может в некоторых случаях помочь в оптимизации хранения данных, особенно если отрицательные значения не требуются.

### Как использовать `UNSIGNED`?

Вы можете использовать `UNSIGNED`, добавляя его как модификатор при определении типа данных в SQL-командах. Примеры создания таблиц и столбцов с `UNSIGNED` приведены выше.

Таким образом, `UNSIGNED` и `SIGNED` определяют, могут ли числовые типы данных содержать отрицательные значения и какой диапазон значений они могут принимать.
