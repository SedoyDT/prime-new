Что такое триггер в mysql?::


В MySQL триггер (trigger) — это специальная процедура, которая автоматически выполняется в ответ на определенные события в таблице базы данных. Триггеры позволяют автоматически выполнять дополнительные действия, такие как проверка данных, обновление связанных таблиц или запись информации в лог, когда происходят изменения в данных (вставка, обновление или удаление).

### Основные характеристики триггеров

**1. Автоматическое выполнен**ие: Триггеры выполняются автоматически в ответ на определенные действия в базе данных, такие как вставка (`INSERT`), обновление (`UPDATE`) или удаление (`DELETE`) строк.

**2. Свойст**ва:
  ** - Перед действием (BEFOR**E): Триггер выполняется перед основным действием (например, перед вставкой строки в таблицу). Это позволяет изменить данные перед тем, как они будут сохранены в таблице.
  ** - После действия (AFTE**R): Триггер выполняется после основного действия. Это позволяет выполнить дополнительные действия, например, обновить связанные таблицы или записать информацию в журнал.

**3. Связь с таблиц**ей: Триггер привязан к конкретной таблице и срабатывает при изменении данных в этой таблице.

**4. Ограничения: Триггеры не могут вызывать другие триггеры напрямую, но могут вызывать хранимые процедуры. Они также могут влиять на производительность, если неправильно настроены или выполняются слишком часто.

### Примеры использования триггеров

**1. Создание тригге**ра:
   Для создания триггера используется команда CREATE TRIGGER. Например, создадим триггер, который автоматически обновляет поле last_modified в таблице employees при обновлении записи:

```

   CREATE TRIGGER update_last_modified
   BEFORE UPDATE ON employees
   FOR EACH ROW
   SET NEW.last_modified = NOW();

```

Этот триггер будет выполняться перед каждым обновлением строки в таблице employees и обновлять поле last_modified на текущее время.

2. **Триггер для вставки данных:**
   Пример триггера, который автоматически записывает данные о новых записях в таблицу audit_log при вставке в таблицу employees:

```SQL
   CREATE TRIGGER log_employee_insert
   AFTER INSERT ON employees
   FOR EACH ROW
   INSERT INTO audit_log (action, employee_id, action_time)
   VALUES ('INSERT', NEW.employee_id, NOW());
```

Этот триггер будет записывать информацию о каждой вставке в таблицу employees в таблицу audit_log.

3. **Триггер для удаления данных:**

   Пример триггера, который автоматически удаляет связанные записи из таблицы employee_history при удалении записи из таблицы employees:

```SQL
   CREATE TRIGGER delete_employee_history
   AFTER DELETE ON employees
   FOR EACH ROW
   DELETE FROM employee_history WHERE employee_id = OLD.employee_id;
```
