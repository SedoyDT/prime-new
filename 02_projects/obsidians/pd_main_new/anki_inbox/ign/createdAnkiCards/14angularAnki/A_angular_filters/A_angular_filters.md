# что такое stateful фильтр
<!-- basicblock-start  deck='A_angular_filters' -->
что такое stateful фильтр::


**Stateful фильтр** в AngularJS — это фильтр, который **сохраняет внутреннее состояние** между вызовами и может изменяться с каждым циклом **$digest**. Это означает, что такие фильтры выполняются каждый раз на каждом цикле **$digest**, даже если входные данные не изменились.

В отличие от **stateless** фильтров, которые всегда дают тот же результат при одинаковых входных данных и не изменяют внешние состояния, **stateful фильтры** могут изменять поведение в зависимости от предыдущих вызовов или содержать внутреннее состояние, которое не зависит напрямую от передаваемых в фильтр значений.

### Проблемы с производительностью
Stateful фильтры могут привести к проблемам с производительностью, так как AngularJS не может оптимизировать их выполнение. Обычно такие фильтры выполняются на каждом цикле **$digest**, даже если входные данные не изменились. Это делает их менее эффективными, поскольку каждый цикл **$digest** обрабатывает фильтр независимо от того, произошли ли изменения во входных данных или нет.

### Когда использовать stateful фильтры?
В идеале, лучше избегать использования **stateful** фильтров, если это возможно. Если же вам все-таки нужно использовать такой фильтр, вы должны четко понимать, что он будет выполняться каждый раз, когда Angular выполняет цикл **$digest**, что может повлиять на производительность, особенно в приложениях с большими объемами данных.

### Как пометить фильтр как **stateful**?
Чтобы создать **stateful фильтр**, его нужно явно пометить в AngularJS. Это означает, что фильтр будет выполняться на каждом цикле **$digest**, независимо от изменений входных данных.

Пример **stateful фильтра**:

```
angular.module('myApp', [])
  .filter('decorate', function() {
    return function(input, symbol) {
      if (!input) return input;
      // Сохраняем состояние, например, символ, который нужно добавить
      return symbol + input + symbol;
    };
  });
```

В этом примере фильтр **decorate** добавляет символ в начало и в конец строки. Хотя сам фильтр может выглядеть простым, он сохраняет состояние внутри (например, символ, который добавляется к строке) и будет выполняться на каждом цикле **$digest**.

### Как избежать использования stateful фильтров?
Если вам нужно сохранить некоторое состояние, лучше передавать его как аргумент в фильтр, а не хранить его внутри фильтра. Это помогает сделать фильтр **stateless**, что повышает производительность приложения.

Пример более эффективного решения:

```
angular.module('myApp', [])
  .controller('MyController', function($scope) {
    $scope.symbol = '*'; // состояние хранится в модели, а не внутри фильтра
  })
  .filter('decorate', function() {
    return function(input, symbol) {
      if (!input) return input;
      return symbol + input + symbol;
    };
  });
```

Теперь состояние (символ) хранится в модели **$scope.symbol**, и фильтр становится **stateless**, поскольку он просто принимает значение символа как аргумент и не сохраняет никакого состояния. Это помогает избежать проблем с производительностью.

# **Фильтры в AngularJS**
<!-- basicblock-start  deck='A_angular_filters' -->
**Фильтры в AngularJS**::


Фильтры форматируют значения выражений для отображения пользователю. Они могут использоваться как в шаблонах представлений, так и в контроллерах или сервисах. AngularJS предоставляет коллекцию встроенных фильтров, но также легко можно создать свои собственные.

Основной API для работы с фильтрами — это **$filterProvider**.

### Использование фильтров в шаблонах представлений

Фильтры применяются к выражениям в шаблонах с помощью следующего синтаксиса:

```
{{ expression | filter }}
```

Например, разметка `{{ 12 | currency }}` форматирует число 12 как валюту с использованием фильтра **currency**. Результатом будет значение `$12.00`.

Фильтры можно комбинировать (цепочка фильтров), что называется «цепочечным применением» (chaining), с использованием следующего синтаксиса:

```
{{ expression | filter1 | filter2 | ... }}
```

Фильтры могут принимать аргументы. Синтаксис для этого:

```
{{ expression | filter:argument1:argument2:... }}
```

Например, разметка `{{ 1234 | number:2 }}` форматирует число 1234 с двумя знаками после запятой с использованием фильтра **number**. Результатом будет значение `1,234.00`.

### Когда фильтры выполняются

В шаблонах фильтры выполняются только тогда, когда их входные данные изменяются. Это более эффективно, чем выполнение фильтра на каждом цикле **$digest**, как это происходит с выражениями.

Есть два исключения из этого правила:

1. Обычно это правило применяется только к фильтрам, которые принимают примитивные значения. Фильтры, которые получают объекты в качестве входных данных, выполняются на каждом цикле **$digest**, поскольку отслеживать изменения этих объектов слишком затратно.

2. Фильтры, которые помечены как **$stateful**, также выполняются на каждом цикле **$digest**. Подробнее об этом см. в разделе **Stateful filters**. Обратите внимание, что ни один из фильтров, встроенных в AngularJS, не является **$stateful**.

### Использование фильтров в контроллерах, сервисах и директивах

Фильтры можно использовать не только в шаблонах представлений, но и в контроллерах, сервисах и директивах. Для этого необходимо внедрить зависимость с именем `<filterName>Filter` в ваш контроллер/сервис/директиву. Например, фильтр с именем **number** внедряется с помощью зависимости **numberFilter**. Внедренный аргумент — это функция, которая принимает значение для форматирования в качестве первого аргумента и параметры фильтра начиная с второго.

Пример ниже использует фильтр **filter**, который разделяет массив на подмассивы на основе условий. Фильтр можно применить в шаблоне следующим образом: `{{ctrl.array | filter:'a'}}`, что выполняет поиск по тексту для буквы "a". Однако использование фильтра в шаблоне вызывает его повторную оценку на каждом цикле **$digest**, что может быть дорогостоящим для больших массивов.

В приведенном примере фильтр вызывается напрямую в контроллере, чтобы вызвать его только тогда, когда это необходимо (например, когда данные загружаются с сервера или изменяется выражение фильтра).

```
<div ng-controller="FilterController as ctrl">
  <div>
    Все записи:
    <span ng-repeat="entry in ctrl.array">{{entry.name}} </span>
  </div>
  <div>
    Записи, содержащие "a":
    <span ng-repeat="entry in ctrl.filteredArray">{{entry.name}} </span>
  </div>
</div>
```

### Создание собственных фильтров

Создание собственного фильтра — это очень простой процесс: нужно зарегистрировать новую фабричную функцию фильтра в вашем модуле. Внутри этой функции создается новый фильтр, который принимает входное значение как первый аргумент. Все дополнительные аргументы фильтра передаются в фильтрующую функцию.

Фильтрующая функция должна быть **чистой функцией**, что означает, что она всегда должна возвращать одинаковый результат для одинаковых входных данных и не должна изменять внешний состояние, например, другие сервисы AngularJS. AngularJS полагается на этот контракт и по умолчанию будет выполнять фильтр только тогда, когда входные данные изменятся. Stateful фильтры возможны, но менее производительны.

# Примечание: Названия фильтров должны быть действительными идентификаторами выражений AngularJS, такими как **uppercase** или **orderBy**. Нельзя использовать специальные символы, такие как дефисы или точки. Если вы хотите сделать пространство имен для фильтров, вы можете использовать заглавные буквы (например, **myappSubsectionFilterx**) или подчеркивания (например, **myapp_subsection_filterx**).

Пример фильтра, который переворачивает текстовую строку и при необходимости делает ее заглавными буквами:

```
<div ng-controller="MyController">
  <input ng-model="greeting" type="text"><br>
  Без фильтра: {{greeting}}<br>
  Перевернуть: {{greeting | reverse}}<br>
  Перевернуть + заглавные: {{greeting | reverse:true}}<br>
  Перевернутое, отфильтрованное в контроллере: {{filteredGreeting}}<br>
</div>
```

### Stateful фильтры

Очень не рекомендуется писать stateful фильтры, потому что их выполнение не может быть оптимизировано AngularJS, что часто приводит к проблемам с производительностью. Многие stateful фильтры можно преобразовать в stateless фильтры, просто сделав скрытое состояние моделью и передав его в фильтр как аргумент.

Тем не менее, если вам нужно создать stateful фильтр, вы должны пометить его как **$stateful**, что означает, что он будет выполняться один или несколько раз на каждом цикле **$digest**.

```
<div ng-controller="MyController">
  Ввод: <input ng-model="greeting" type="text"><br>
  Украшение: <input ng-model="decoration.symbol" type="text"><br>
  Без фильтра: {{greeting}}<br>
  Украшенное: {{greeting | decorate}}<br>
</div>
```
