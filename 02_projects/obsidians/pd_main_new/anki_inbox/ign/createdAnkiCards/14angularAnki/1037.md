1.1 Вопрос: "Что такое директивы в AngularJS 1.8 и как они отличаются от компонентов?" ::  
1.2 Ответ: "Директивы в AngularJS 1.8 позволяют расширять HTML с помощью пользовательских тегов или атрибутов, а компоненты являются более структурированным способом организации логики и представления, обеспечивая более простую повторяемость."  
Пример кода:
```javascript
angular.module('app', [])
  .directive('myDirective', function() {
    return {
      restrict: 'E',
      template: '<h1>Hello, {{name}}!</h1>',
      scope: {
        name: '='
      }
    };
  });
```

2.1 Вопрос: "Как работает двунаправленное связывание данных в AngularJS 1.8?" ::  
2.2 Ответ: "Двунаправленное связывание данных в AngularJS позволяет автоматически обновлять представление при изменении модели и наоборот. Это достигается с помощью директивы `ng-model`."  
Пример кода:
```html
<div ng-app="app" ng-controller="MainCtrl">
  <input ng-model="name" />
  <p>Hello, {{name}}!</p>
</div>

<script>
  angular.module('app', [])
    .controller('MainCtrl', function($scope) {
      $scope.name = 'AngularJS';
    });
</script>
```

3.1 Вопрос: "Как реализовать сервисы в AngularJS 1.8?" ::  
3.2 Ответ: "Сервисы в AngularJS 1.8 используются для организации логики и предоставления функционала, доступного во всех частях приложения. Они создаются с помощью функции `factory`, `service` или `provider`."  
Пример кода:
```javascript
angular.module('app', [])
  .factory('DataService', function() {
    var data = 'Some data';
    return {
      getData: function() {
        return data;
      }
    };
  })
  .controller('MainCtrl', function($scope, DataService) {
    $scope.data = DataService.getData();
  });
```

4.1 Вопрос: "Что такое `$scope` и как он работает в AngularJS 1.8?" ::  
4.2 Ответ: "$scope в AngularJS 1.8 представляет собой объект, который связывает контроллеры и представления. Он используется для хранения данных и функций, доступных в представлении."  
Пример кода:
```javascript
angular.module('app', [])
  .controller('MainCtrl', function($scope) {
    $scope.greeting = 'Hello, AngularJS!';
    $scope.updateGreeting = function(newGreeting) {
      $scope.greeting = newGreeting;
    };
  });
```

5.1 Вопрос: "Как работает фильтрация данных в AngularJS 1.8?" ::  
5.2 Ответ: "Фильтры в AngularJS 1.8 позволяют преобразовывать данные в представлении, например, форматировать даты или фильтровать массивы. Фильтры могут использоваться в выражениях Angular."  
Пример кода:
```html
<div ng-app="app" ng-controller="MainCtrl">
  <p>{{ dateValue | date:'medium' }}</p>
  <ul>
    <li ng-repeat="item in items | filter:searchText">{{ item }}</li>
  </ul>
  <input ng-model="searchText" placeholder="Search..." />
</div>

<script>
  angular.module('app', [])
    .controller('MainCtrl', function($scope) {
      $scope.dateValue = new Date();
      $scope.items = ['Apple', 'Banana', 'Cherry'];
    });
</script>
```
