Как работает @Output в angular?::


В Angular декоратор `@Output` используется для организации **событийной связи между компонентами**. Он позволяет дочернему компоненту отправлять события родительскому компоненту, что позволяет передавать данные из дочернего компонента в родительский.

Основной механизм работы `@Output` базируется на **событиях**. В дочернем компоненте создается **событие** с помощью `EventEmitter`, и при необходимости это событие вызывается (испускается). Родительский компонент может подписаться на это событие в шаблоне и выполнить соответствующую реакцию.

### Как работает `@Output`:

1. **В дочернем компоненте** создается свойство с декоратором `@Output`, которое представляет собой объект `EventEmitter`. Это событие испускается, когда необходимо передать данные в родительский компонент.
2. **В родительском компоненте** это событие перехватывается в шаблоне через привязку `(имя_события)="обработчик"`, где `обработчик` — это функция в родительском компоненте, которая выполняется при срабатывании события.

### Пример использования `@Output`

#### 1. Дочерний компонент (child.component.ts)

```
import { Component, EventEmitter, Output } from '@angular/core';

@Component({
  selector: 'app-child',
  template: `
    <button (click)="sendData()">Отправить данные</button>
  `
})
export class ChildComponent {
  // Создаем событие для передачи данных в родительский компонент
  @Output() dataEmitter: EventEmitter<string> = new EventEmitter();

  // Метод для передачи данных через событие
  sendData() {
    const data = 'Данные от дочернего компонента';
    this.dataEmitter.emit(data); // Генерируем событие и передаем данные
  }
}
```

- В этом примере мы создаем событие `dataEmitter` с помощью `EventEmitter`. Когда вызывается метод `sendData()`, происходит испускание (emit) события, передавая строку данных родительскому компоненту.

#### 2. Родительский компонент (parent.component.html)

```
<app-child (dataEmitter)="receiveData($event)"></app-child>
<p>Полученные данные: {{ receivedData }}</p>
```

- В шаблоне родительского компонента мы подписываемся на событие `(dataEmitter)`, которое генерирует дочерний компонент. Когда это событие срабатывает, вызывается метод `receiveData()`, который получает данные из события.

#### 3. Родительский компонент (parent.component.ts)

```
import { Component } from '@angular/core';

@Component({
  selector: 'app-parent',
  templateUrl: './parent.component.html'
})
export class ParentComponent {
  receivedData: string = '';

  // Метод, который вызывается при срабатывании события
  receiveData(data: string) {
    this.receivedData = data;
  }
}
```

- В родительском компоненте метод `receiveData()` принимает данные, которые передал дочерний компонент, и обновляет переменную `receivedData`.

### Подробное описание

- **`****@Output****`** — это декоратор, который маркирует свойство как исходящее событие. Это событие может быть связано с обработчиком событий в родительском компоненте.
- **`EventEmitter`** — это объект, который используется для создания и отправки событий. У него есть методы:
  - `emit(value)` — для отправки события с данными.
- **`$event`** — специальная переменная в Angular, которая содержит данные, переданные событием.

### Итог
- `@Output` используется для передачи данных из дочернего компонента в родительский с помощью механизма событий.
- Дочерний компонент испускает событие через `EventEmitter`, а родительский компонент подписывается на это событие и обрабатывает переданные данные.

Это удобный способ поддерживать **одностороннюю связь** от дочернего компонента к родительскому.
