Here are some questions based on implementing REST and custom services in AngularJS:

<!-- basicblock-start oid="ObsU1dGtKUISsHxHHX6Cpdpb" deck='angular-phone-cat' --> 

1.1 Вопрос: "Как добавить поддержку ngResource в проект AngularJS?" :: 
1.2 Ответ: "Добавьте зависимость 'angular-resource' в package.json и установите её с помощью npm."  
Пример:
```json
"dependencies": {
  "angular-resource": "1.8.x"
}
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="Obsco9UYEbHoPzgqrmyJgrTz" deck='angular-phone-cat' --> 

2.1 Вопрос: "Как создать сервис для работы с REST API в AngularJS?" :: 
2.2 Ответ: "Используйте $resource для создания сервиса, который упрощает взаимодействие с RESTful ресурсами."  
Пример:
```javascript
angular.module('core.phone').factory('Phone', ['$resource', function($resource) {
  return $resource('phones/:phoneId.json', {}, {
    query: {
      method: 'GET',
      params: {phoneId: 'phones'},
      isArray: true
    }
  });
}]);
```

<!-- basicblock-end -->

3.1 Вопрос: "Как обновить контроллер для использования нового Phone сервиса?" :: 
3.2 Ответ: "Замените вызовы $http на методы Phone сервиса для упрощения кода."  
Пример:
```javascript
this.phones = Phone.query();
```
