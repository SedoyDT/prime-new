Here's a new set of questions based on creating custom filters in AngularJS:

<!-- basicblock-start oid="Obs62PGjrr86RCiZHHab0vne" deck='angular-phone-cat' --> 

1.1 Вопрос: "Как создать пользовательский фильтр в AngularJS?" :: 
1.2 Ответ: "Зарегистрируйте фильтр в модуле, используя функцию filter."  
Пример кода:
```javascript
angular.module('core').filter('checkmark', function() {
  return function(input) {
    return input ? '\u2713' : '\u2718'; // ✓ или ✘
  };
});
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsXGV7vPgd02FC1cqHuIQrf" deck='angular-phone-cat' --> 

2.1 Вопрос: "Где регистрировать пользовательские фильтры?" :: 
2.2 Ответ: "Фильтры лучше регистрировать в ядре приложения, чтобы они были доступны в любом месте."  
Пример:
```javascript
angular.module('core', []);
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsIGAMTaqRWBABgNmi54MQZ" deck='angular-phone-cat' --> 

3.1 Вопрос: "Как использовать фильтр в шаблонах AngularJS?" :: 
3.2 Ответ: "Используйте синтаксис {{expression | filter}} для применения фильтра."  
Пример:
```html
<dd>{{$ctrl.phone.connectivity.gps | checkmark}}</dd>
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="Obsso8S36ySXRT011EjBIJtT" deck='angular-phone-cat' --> 

4.1 Вопрос: "Как протестировать пользовательский фильтр?" :: 
4.2 Ответ: "Создайте юнит-тест, который проверяет, возвращает ли фильтр правильные значения."  
Пример кода:
```javascript
it('should convert boolean values to unicode checkmark or cross',
  inject(function(checkmarkFilter) {
    expect(checkmarkFilter(true)).toBe('\u2713');
    expect(checkmarkFilter(false)).toBe('\u2718');
  })
);
```

<!-- basicblock-end -->

5.1 Вопрос: "Что такое unicode символы для галочек и крестиков?" :: 
5.2 Ответ: "Используйте \u2713 для галочки (✓) и \u2718 для крестика (✘)."
