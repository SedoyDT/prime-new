1.1 Вопрос: "Как реализовать полнотекстовый поиск в AngularJS?" :: 
1.2 Ответ: "Полнозначный поиск можно реализовать с помощью директивы `ngModel` и фильтра `filter` в `ngRepeat`." 
Пример кода:
```html
<input ng-model="$ctrl.query" />
<ul>
  <li ng-repeat="phone in $ctrl.phones | filter:$ctrl.query">
    <span>{{phone.name}}</span>
  </li>
</ul>
```

2.1 Вопрос: "Что такое директива `ngModel`?" ::
2.2 Ответ: "Директива `ngModel` связывает значение элемента управления с переменной в области видимости контроллера." 
Пример кода:
```html
<input ng-model="$ctrl.query" />
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsQEkJHieouC8RniHWLA9fB" deck='angular-phone-cat' --> 

3.1 Вопрос: "Как работает фильтр `filter` в AngularJS?" :: 
3.2 Ответ: "Фильтр `filter` создает новый массив, содержащий только элементы, соответствующие заданному критерию." 
Пример кода:
```html
<li ng-repeat="phone in $ctrl.phones | filter:$ctrl.query">
  <span>{{phone.name}}</span>
</li>
```

<!-- basicblock-end -->

5.1 Вопрос: "Что делает метод `sendKeys` в E2E тестах?" :: 
5.2 Ответ: "Метод `sendKeys` отправляет текст в элемент управления, имитируя ввод пользователя." 
Пример кода:
```javascript
var query = element(by.model('$ctrl.query'));
query.sendKeys('motorola');
```
