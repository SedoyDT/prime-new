Вот новый набор вопросов по теме маршрутизации и нескольких представлений в AngularJS:

<!-- basicblock-start oid="Obs1hTid4knJUaCqDeTYxSFJ" deck='angular-phone-cat' --> 

1.1 Вопрос: "Как добавить маршрутизацию в приложение AngularJS?" :: 
1.2 Ответ: "Используйте модуль ngRoute и объявите маршруты с помощью $routeProvider."  
Пример кода:
```javascript
$routeProvider.when('/phones', {
  template: '<phone-list></phone-list>'
});
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="Obs08hDvrgyzgsJ1pkAJQ3E0" deck='angular-phone-cat' --> 

2.1 Вопрос: "Что такое layout template в AngularJS?" :: 
2.2 Ответ: "Это общий шаблон для всех представлений, который включает другие шаблоны в зависимости от текущего маршрута."  
Пример кода:
```html
<div ng-view></div>
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="Obs9PnVVYLyF0POt670oM0tz" deck='angular-phone-cat' --> 

3.1 Вопрос: "Как используется ngView в AngularJS?" :: 
3.2 Ответ: "ngView включает шаблон представления для текущего маршрута в layout template."  
Пример кода:
```html
<body>
  <div ng-view></div>
</body>
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsxZFW7Z8qUQ89G3gMWh7tq" deck='angular-phone-cat' --> 

4.1 Вопрос: "Как настроить маршруты в AngularJS?" :: 
4.2 Ответ: "Используйте метод .config() для настройки $routeProvider в вашем модуле."  
Пример кода:
```javascript
angular.module('phonecatApp').config(['$routeProvider', function($routeProvider) {
  $routeProvider.when('/phones/:phoneId', {
    template: '<phone-detail></phone-detail>'
  });
}]);
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsWR4aJTUFfa9znXdZDIU30" deck='angular-phone-cat' --> 

5.1 Вопрос: "Как передать параметры в маршрутах?" :: 
5.2 Ответ: "Используйте двоеточие (:) в определении маршрута, чтобы создать параметр."  
Пример кода:
```javascript
when('/phones/:phoneId', {
  template: '<phone-detail></phone-detail>'
});
```
