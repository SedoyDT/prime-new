1.1 Вопрос: "Как реализовать двустороннюю привязку данных в AngularJS?" :: 
1.2 Ответ: "Двусторонняя привязка данных связывает модель и представление, позволяя изменения в одном автоматически обновлять другое." 
Пример кода:
```html
<select ng-model="$ctrl.orderProp">
  <option value="name">Alphabetical</option>
  <option value="age">Newest</option>
</select>
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsCyGROJ7pf6E5sVRynjw73" deck='angular-phone-cat' --> 

2.1 Вопрос: "Как сортировать список с помощью AngularJS?" :: 
2.2 Ответ: "Сортировку можно реализовать с использованием фильтра `orderBy` в `ngRepeat`." 
Пример кода:
```html
<li ng-repeat="phone in $ctrl.phones | filter:$ctrl.query | orderBy:$ctrl.orderProp">
  <span>{{phone.name}}</span>
</li>
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="Obs53tHtLq5IaQwWt5oiOEq5" deck='angular-phone-cat' --> 

3.1 Вопрос: "Как задать значение по умолчанию для `orderProp`?" :: 
3.2 Ответ: "Значение по умолчанию для `orderProp` устанавливается в контроллере." 
Пример кода:
```javascript
this.orderProp = 'age'; // Установка значения по умолчанию
```

<!-- basicblock-end -->

4.1 Вопрос: "Как написать E2E тест для проверки сортировки?" :: 
4.2 Ответ: "E2E тест можно написать с использованием Protractor, чтобы проверить сортировку по выбранному критерию." 
Пример кода:
```javascript
it('should be possible to control phone order via the drop-down menu', function() {
  orderSelect.click();
  nameOption.click();
  expect(getNames()).toEqual(['MOTOROLA XOOM™', 'Motorola XOOM™ with Wi-Fi']);
});
```

5.1 Вопрос: "Что делает фильтр `orderBy`?" :: 
5.2 Ответ: "Фильтр `orderBy` создает новый отсортированный массив на основе указанного свойства." 
Пример кода:
```html
<li ng-repeat="phone in $ctrl.phones | filter:$ctrl.query | orderBy:$ctrl.orderProp">
```
