1.1 Вопрос: "Как подключить модуль ngAnimate в AngularJS?" ::  
1.2 Ответ: "Для подключения ngAnimate необходимо добавить его в зависимости основного модуля приложения."  
Пример кода:
```javascript
angular.
  module('phonecatApp', [
    'ngAnimate',
    ...
  ]);
```

2.1 Вопрос: "Как создать CSS-анимации для ngRepeat?" ::  
2.2 Ответ: "Добавьте необходимые CSS классы в файл стилей и используйте директиву ng-repeat с соответствующими классами."  
Пример кода:
```css
.phone-list-item.ng-enter,
.phone-list-item.ng-leave,
.phone-list-item.ng-move {
  transition: 0.5s linear all;
}
```

<!-- basicblock-end -->

3.1 Вопрос: "В чем разница между ng-enter и ng-leave классами?" ::  
3.2 Ответ: "ng-enter применяется к элементу, который добавляется в DOM, а ng-leave — к элементу, который удаляется."  
Пример кода:
```css
.phone-list-item.ng-enter {
  opacity: 0;
}
.phone-list-item.ng-leave {
  opacity: 1;
}
```

<!-- basicblock-end -->

4.1 Вопрос: "Как анимировать переходы между маршрутами с помощью ngView?" ::  
4.2 Ответ: "Используйте обертку для ng-view и примените классы анимации в CSS для управления эффектами входа и выхода."  
Пример кода:
```html
<div class="view-container">
  <div ng-view class="view-frame"></div>
</div>
```

5.1 Вопрос: "Что такое JavaScript-анимации в AngularJS и как они создаются?" ::  
5.2 Ответ: "JavaScript-анимации создаются с использованием метода .animation(), который позволяет настраивать анимации для конкретных классов."  
Пример кода:
```javascript
angular.
  module('phonecatApp').
  animation('.phone', function phoneAnimationFactory() {
    return {
      addClass: animateIn,
      removeClass: animateOut
    };
  });
```

6.1 Вопрос: "Как настроить анимацию с использованием jQuery?" ::  
6.2 Ответ: "Вы можете использовать jQuery для выполнения анимаций, например, изменяя CSS-свойства через метод animate()."  
Пример кода:
```javascript
element.animate({
  top: 0
}, done);
```
