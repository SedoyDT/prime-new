1.1 Вопрос: "Почему важно разделять код на модули в AngularJS?" :: 
1.2 Ответ: "Разделение кода на модули упрощает его повторное использование и поддержку, а также позволяет избежать конфликтов имен." 
Пример кода:
```javascript
// Определение модуля phoneList
angular.module('phoneList', []);

// Регистрация компонента phoneList в модуле
angular.module('phoneList').component('phoneList', {
  // определение компонента
});
```

2.1 Вопрос: "Как организовать структуру папок в проекте AngularJS?" ::
2.2 Ответ: "Рекомендуется организовывать файлы по функциональным областям, создавая отдельные папки для каждой функции или компонента." 
Пример кода: 
```plaintext
app/
  phone-list/
    phone-list.component.js
    phone-list.component.spec.js
    phone-list.module.js
    phone-list.template.html
  app.module.js
```

3.1 Вопрос: "Что такое templateUrl и почему его стоит использовать?" :: 
3.2 Ответ: "templateUrl позволяет загружать HTML-шаблоны из внешних файлов, что улучшает читаемость кода и облегчает его поддержку." 
Пример кода:
```javascript
angular.module('phoneList').component('phoneList', {
  templateUrl: 'phone-list/phone-list.template.html',
  controller: function() {
    // контроллер
  }
});
```

4.1 Вопрос: "Чем отличается компонент от директивы в AngularJS?" ::
4.2 Ответ: "Компоненты являются более упрощенной и инкапсулированной формой директив, предназначенной для создания UI." 
Пример кода:
```javascript
// Компонент
angular.module('myApp').component('myComponent', {
  template: '<div>Hello, World!</div>',
  controller: function() {}
});

// Директива
angular.module('myApp').directive('myDirective', function() {
  return {
    restrict: 'E',
    template: '<div>Hello, World!</div>',
    link: function(scope, element) {}
  };
});
```

5.1 Вопрос: "Почему стоит использовать внешние шаблоны вместо инлайн-шаблонов?" :: 
5.2 Ответ: "Внешние шаблоны упрощают поддержку и позволяют использовать функции редактора для работы с HTML." 
Пример кода:
```javascript
angular.module('myApp').component('myComponent', {
  templateUrl: 'templates/my-template.html',
  controller: function() {}
});
```
