Here are some questions based on adding event handlers in AngularJS:

<!-- basicblock-start oid="ObsnKN7KUt5iKb9dK9EifKOR" deck='angular-phone-cat' --> 

1.1 Вопрос: "Как добавить обработчик событий для изображения в AngularJS?" :: 
1.2 Ответ: "Используйте директиву ng-click, чтобы связать событие клика с функцией контроллера."  
Пример кода:
```javascript
self.setImage = function setImage(imageUrl) {
  self.mainImageUrl = imageUrl;
};
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObskisImAwVVHPLKVviBYNAv" deck='angular-phone-cat' --> 

2.1 Вопрос: "Как связать основное изображение с выбранной миниатюрой?" :: 
2.2 Ответ: "Обновите свойство mainImageUrl в контроллере при клике на миниатюру."  
Пример:
```html
<img ng-src="{{$ctrl.mainImageUrl}}" class="phone" />
<ul class="phone-thumbs">
  <li ng-repeat="img in $ctrl.phone.images">
    <img ng-src="{{img}}" ng-click="$ctrl.setImage(img)" />
  </li>
</ul>
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsR8DXwBFc078rjJX57vh1g" deck='angular-phone-cat' --> 

3.1 Вопрос: "Как протестировать обработку кликов по миниатюрам?" :: 
3.2 Ответ: "Добавьте E2E тесты, чтобы проверить изменение основного изображения."  
Пример теста:
```javascript
it('should swap the main image when clicking on a thumbnail image', function() {
  var mainImage = element(by.css('img.phone'));
  var thumbnails = element.all(by.css('.phone-thumbs img'));

  thumbnails.get(2).click();
  expect(mainImage.getAttribute('src')).toMatch(/img\/phones\/nexus-s.2.jpg/);
});
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsPZHiDayBMhTBMuXzJTZx7" deck='angular-phone-cat' --> 

4.1 Вопрос: "Как использовать другие события в AngularJS?" :: 
4.2 Ответ: "Вы можете использовать встроенные директивы для различных событий, таких как dblclick, focus, blur и т.д."  
Пример:
```javascript
self.onDblclick = function onDblclick(imageUrl) {
  alert('You double-clicked image: ' + imageUrl);
};
```
