Вот новый набор вопросов по теме шаблонов и изображений в AngularJS:

<!-- basicblock-start oid="ObsAupHZ2305QjP7Sv6d8xy6" deck='angular-phone-cat' --> 

1.1 Вопрос: "Как динамически генерировать ссылки на страницы телефонов в AngularJS?" :: 
1.2 Ответ: "Используйте привязку в атрибутах href с помощью двойных фигурных скобок."  
Пример кода:
```html
<a href="#!/phones/{{phone.id}}">{{phone.name}}</a>
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsEBAwp4qz8PZ4zjvNscVWV" deck='angular-phone-cat' --> 

2.1 Вопрос: "Почему стоит использовать ngSrc вместо src для изображений?" :: 
2.2 Ответ: "ngSrc предотвращает ошибочные запросы к недоступным URL, пока AngularJS не обработает выражение."  
Пример кода:
```html
<img ng-src="{{phone.imageUrl}}" alt="{{phone.name}}" />
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="Obsn6wPo13qUmG0VEBgIbg2F" deck='angular-phone-cat' --> 

3.1 Вопрос: "Как протестировать правильность генерируемых ссылок?" :: 
3.2 Ответ: "Напишите E2E тест, который проверяет корректность URL при клике на ссылку."  
Пример кода:
```javascript
it('should render phone specific links', function() {
  query.sendKeys('nexus');
  element.all(by.css('.phones li a')).first().click();
  expect(browser.getCurrentUrl()).toContain('index.html#!/phones/nexus-s');
});
```

<!-- basicblock-end --> 

<!-- basicblock-start oid="ObsRd6eyiD4nPJrRwnECq2MG" deck='angular-phone-cat' --> 

4.1 Вопрос: "Что произойдет, если использовать обычный атрибут src вместо ngSrc?" :: 
4.2 Ответ: "Браузер сразу отправит запрос к недоступному URL, что приведет к ошибке."  
Пример кода:
```html
<!-- Это приведет к ошибке -->
<img src="{{phone.imageUrl}}" alt="{{phone.name}}" />
```
