1.1 Вопрос: "Что такое компоненты в Angular и как они отличаются от директив?" ::  
1.2 Ответ: "Компоненты являются основными строительными блоками приложений Angular, состоящими из шаблона, стилей и логики. Директивы же изменяют поведение элементов DOM, но не могут иметь собственные шаблоны."  
Пример кода:
```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-hello',
  template: `<h1>Hello, {{name}}!</h1>`,
})
export class HelloComponent {
  name: string = 'Angular';
}
```

2.1 Вопрос: "Как работает механизм связывания данных (data binding) в Angular?" ::  
2.2 Ответ: "Связывание данных в Angular позволяет автоматически синхронизировать данные между компонентом и представлением. Существует однонаправленное и двунаправленное связывание."  
Пример кода:
```typescript
@Component({
  selector: 'app-example',
  template: `<input [(ngModel)]="name" /> <p>Hello, {{name}}!</p>`,
})
export class ExampleComponent {
  name: string = '';
}
```

3.1 Вопрос: "Что такое сервисы в Angular и как их использовать?" ::  
3.2 Ответ: "Сервисы в Angular позволяют организовывать бизнес-логику и делиться данными между компонентами. Они обычно создаются с помощью декоратора `@Injectable`."  
Пример кода:
```typescript
import { Injectable } from '@angular/core';

@Injectable({
  providedIn: 'root',
})
export class DataService {
  private data: string = 'Some data';

  getData() {
    return this.data;
  }
}

@Component({
  selector: 'app-data',
  template: `<p>{{data}}</p>`,
})
export class DataComponent {
  data: string;

  constructor(private dataService: DataService) {
    this.data = this.dataService.getData();
  }
}
```

4.1 Вопрос: "Как работает маршрутизация в Angular?" ::  
4.2 Ответ: "Маршрутизация в Angular позволяет навигировать между разными компонентами, используя модуль `RouterModule`. Определяются маршруты с помощью `Routes`."  
Пример кода:
```typescript
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';
import { AboutComponent } from './about/about.component';

const routes: Routes = [
  { path: '', component: HomeComponent },
  { path: 'about', component: AboutComponent },
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],
  exports: [RouterModule],
})
export class AppRoutingModule {}
```

5.1 Вопрос: "Что такое Pipe в Angular и как его использовать?" ::  
5.2 Ответ: "Pipe в Angular позволяет преобразовывать данные в шаблонах. Пользовательские Pipe могут быть созданы с помощью декоратора `@Pipe`."  
Пример кода:
```typescript
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({ name: 'exponential' })
export class ExponentialPipe implements PipeTransform {
  transform(value: number, exponent: string): number {
    return Math.pow(value, Number(exponent));
  }
}

@Component({
  template: `{{ 2 | exponential: 3 }}` // Выводит: 8
})
export class ExampleComponent {}
```
