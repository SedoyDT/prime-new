# Что делает $broadcast?
<!-- basicblock-start  deck='A_angular_methods' -->
Что делает $broadcast?::


В AngularJS `$broadcast` — это метод, который используется для отправки (или "рассылки") события на все дочерние элементы в иерархии контроллеров, начиная с текущего контроллера и распространяясь вниз по цепочке. Это позволяет одному контроллеру или сервису "оповещать" другие контроллеры, которые находятся ниже в иерархии (например, в дочерних компонентах или контроллерах).

### Что делает `$broadcast`?

Метод `$broadcast` создает событие, которое будет отправлено всем дочерним контроллерам в текущем `$scope` и дальше вниз по иерархии. Он вызывает `$on` в дочерних контроллерах, которые могут подписаться на это событие.

**Синтаксис:**

```
$scope.$broadcast(eventName, [args...]);
```

- `eventName`: строка, которая представляет имя события, на которое подписываются дочерние контроллеры.
- `[args...]`: необязательные аргументы, которые передаются в обработчики событий, подписанные на это событие.

### Как это работает?

Когда вы вызываете `$broadcast`, событие передается всем дочерним элементам текущего `$scope`, и они могут обработать это событие с помощью метода `$on`.

### Пример использования `$broadcast`

Предположим, у нас есть два контроллера: родительский контроллер и дочерний контроллер. Родительский контроллер генерирует событие, которое будет передано дочернему контроллеру.

#### Родительский контроллер (ParentController):

```
myApp.controller('ParentController', ['$scope', function($scope) {
    $scope.sendMessage = function() {
        // Отправляем событие с именем "messageSent" в дочерние контроллеры
        $scope.$broadcast('messageSent', 'Hello from Parent!');
    };
}]);
```

#### Дочерний контроллер (ChildController):

```
myApp.controller('ChildController', ['$scope', function($scope) {
    // Подписываемся на событие "messageSent"
    $scope.$on('messageSent', function(event, message) {
        console.log('Message received in child:', message);
    });
}]);
```

#### HTML:

```
<div ng-app="myApp">
    <div ng-controller="ParentController">
        <button ng-click="sendMessage()">Send Message</button>
    </div>
    <div ng-controller="ChildController">
        <!-- Дочерний контроллер будет слушать события -->
    </div>
</div>
```

### Пояснение:

1. Когда пользователь нажимает кнопку "Send Message" в родительском контроллере, вызывается метод `sendMessage`.
2. Метод `sendMessage` вызывает `$broadcast`, отправляя событие с именем `messageSent` и передавая сообщение.
3. Дочерний контроллер подписан на это событие с помощью `$on('messageSent', ...)`. Когда событие поступает, обработчик событий получает сообщение и выводит его в консоль.

### Важные моменты:

1. **Вверх по иерархии событий не распространяются** — это важно, так как `$broadcast` распространяет событие только вниз, к дочерним контроллерам. Для отправки событий наверх по иерархии контроллеров используется `$emit`, а для отправки событий между контроллерами одного уровня — `$dispatch`.

2. **Обработка событий** — после вызова `$broadcast`, обработчики, подписанные на это событие, выполняются в том порядке, в котором они были зарегистрированы (сначала у дочерних контроллеров, затем у их дочерних элементов).

3. **Performance Considerations** — так как `$broadcast` вызывает обработчики событий на всех дочерних контроллерах, это может повлиять на производительность, если у вас очень большая и глубокая иерархия контроллеров. В таких случаях стоит осторожно использовать `$broadcast`, особенно если события часто генерируются.

### Различие между `$broadcast` и `$emit`:

- **`$broadcast`** — отправляет событие вниз по иерархии контроллеров (к дочерним).
- **`$emit`** — отправляет событие вверх по иерархии контроллеров (к родительским).

### Пример с `$emit`:

```
// В родительском контроллере
$scope.$emit('parentEvent', 'Message from parent to root!');
```

Если вы используете `$emit`, событие будет передано родительскому контроллеру, который может обработать его с помощью `$on`.
