# Что такое fr?
<!-- basicblock-start oid="ObsFRlssGwy6es5LU4b51IAO"  deck='C_css' -->
Что такое fr?::


Единица измерения `fr` используется в CSS Grid Layout для задания гибких размеров колонок и строк. Она означает "fraction" (доля) и позволяет вам распределять доступное пространство в контейнере между элементами.

### Как работает `fr`

- **Контекст**: При использовании `fr`, доступное пространство в контейнере распределяется между колонками или строками, заданными с этой единицей.
- **Пример**: Если у вас есть контейнер с 3 колонками и вы задали их ширину как `1fr`, `2fr`, `1fr`, это значит, что доступное пространство будет разделено на 4 равные части: 1 часть для первой колонки, 2 части для второй и 1 часть для третьей.

### Пример использования

```
.grid-container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr; /* 1 часть, 2 части, 1 часть */
  grid-template-rows: auto 1fr auto; /* 1 строка авторазмера и 1 строка, занимающая все оставшееся пространство */
}

.grid-item {
  border: 1px solid black;
}
```

В этом примере:
- Первая колонка занимает 1/4 доступного пространства.
- Вторая колонка занимает 2/4 (или половину) доступного пространства.
- Третья колонка также занимает 1/4 доступного пространства.

Единица `fr` позволяет гибко управлять распределением пространства в сетке, что делает её особенно полезной для создания адаптивных макетов.

# Расскажи про все единицы измерения css?
<!-- basicblock-start oid="Obsfb4ppQ6kelPoqWBq6mSQN"  deck='C_css' -->
Расскажи про все единицы измерения css?::


CSS предлагает множество единиц измерения для различных нужд, таких как размеры, отступы и шрифты. Вот основные из них:

### Абсолютные единицы

1. **px (пиксели)**: 
   - Фиксированная единица измерения, обычно используется для точных размеров.
   - Пример: `width: 100px;`

2. **pt (пункты)**:
   - Используется в печати, 1 пункт = 1/72 дюйма.
   - Пример: `font-size: 12pt;`

3. **in (дюймы)**:
   - Абсолютная единица, 1 дюйм = 96 пикселей.
   - Пример: `width: 2in;`

4. **cm (сантиметры)**:
   - Абсолютная единица, 1 сантиметр = 37.795 пикселей.
   - Пример: `width: 5cm;`

5. **mm (миллиметры)**:
   - Абсолютная единица, 1 миллиметр = 3.779 пикселей.
   - Пример: `width: 50mm;`

### Относительные единицы

1. **% (проценты)**:
   - Относительная единица, вычисляется от размера родительского элемента.
   - Пример: `width: 50%;`

2. **em**:
   - Относительная единица, основана на размере шрифта родительского элемента.
   - Пример: `font-size: 2em;` (в 2 раза больше размера шрифта родителя)

3. **rem (корневой em)**:
   - Относительная единица, основана на размере шрифта корневого элемента (`<html>`).
   - Пример: `font-size: 1.5rem;`

4. **vw (viewport width)**:
   - Относительная единица, 1 vw = 1% от ширины области просмотра.
   - Пример: `width: 50vw;`

5. **vh (viewport height)**:
   - Относительная единица, 1 vh = 1% от высоты области просмотра.
   - Пример: `height: 50vh;`

6. **vmin**:
   - Относительная единица, равна меньшему из `vw` или `vh`.
   - Пример: `width: 10vmin;`

7. **vmax**:
   - Относительная единица, равна большему из `vw` или `vh`.
   - Пример: `width: 10vmax;`

8. **ch (character)**:
   - Относительная единица, основана на ширине символа "0" в текущем шрифте.
   - Пример: `width: 20ch;`

9. **ex**:
   - Относительная единица, основана на высоте строчной буквы "x" в текущем шрифте.
   - Пример: `margin-top: 2ex;`

### Другие единицы

1. **auto**:
   - Специальное значение, которое позволяет браузеру автоматически вычислить размер или отступ.
   - Пример: `margin: auto;`

2. **fit-content**:
   - Специальное значение, позволяющее элементу принимать размеры в зависимости от его содержимого.
   - Пример: `width: fit-content;`

Эти единицы дают гибкость в управлении макетом и стилями веб-страниц, позволяя создавать адаптивные и точные дизайны.

# Как будет выглядеть пример кода грида на две колонки по 10 элементов?
<!-- basicblock-start oid="Obsh9FsSsmPtvy0K39ILJelt"  deck='C_css' -->
Как будет выглядеть пример кода грида на две колонки по 10 элементов?::

```html

<div class="outer-grid">
  <div class="outer-item">
    <div class="inner-grid">
      <div class="inner-item">1</div>
      <div class="inner-item">2</div>
      <div class="inner-item">3</div>
      <div class="inner-item">4</div>
      <div class="inner-item">5</div>
      <div class="inner-item">6</div>
      <div class="inner-item">7</div>
      <div class="inner-item">8</div>
      <div class="inner-item">9</div>
      <div class="inner-item">10</div>
    </div>
    <div class="inner-grid">
      <div class="inner-item">11</div>
      <div class="inner-item">12</div>
      <div class="inner-item">13</div>
      <div class="inner-item">14</div>
      <div class="inner-item">15</div>
      <div class="inner-item">16</div>
      <div class="inner-item">17</div>
      <div class="inner-item">18</div>
      <div class="inner-item">19</div>
      <div class="inner-item">20</div>
    </div>
  </div>
</div>
```
```CSS
/* Внешний грид */
.outer-grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr); /* Две колонки для внутренних гридов */
  gap: 10px; /* Отступы между элементами */
}

/* Внешние элементы (содержат внутренние гриды) */
.outer-item {
  background-color: #ddd;
  padding: 10px;
  border: 1px solid #333;
  display: grid;
  grid-template-columns: 1fr 1fr; /* Две колонки для двух внутренних гридов */
}

/* Внутренний грид */
.inner-grid {
  display: grid;
  grid-template-columns: 1fr; /* Одноколоночный грид для размещения 10 элементов в столбик */
  gap: 5px; /* Отступы между элементами внутри внутреннего грида */
}

/* Внутренние элементы */
.inner-item {
  background-color: #bbb;
  padding: 5px;
  text-align: center;
  border: 1px solid #666;
}

```

# grid item text по центру вертикально и горизонтально
<!-- basicblock-start oid="Obs1kshWlCtL4ZRPu2vOv8Dt"  deck='C_css' -->
grid item text по центру вертикально и горизонтально::


Чтобы выровнять текст в элементе сетки по центру как по вертикали, так и по горизонтали, вы можете использовать CSS. Один из самых простых способов — это использование Flexbox. Вот пример:

```
.grid-item {
  display: flex;
  justify-content: center; /* Горизонтальное выравнивание */
  align-items: center; /* Вертикальное выравнивание */
  width: 100px; /* Ширина ячейки сетки */
  height: 100px; /* Высота ячейки сетки */
  border: 1px solid #ccc; /* Для визуализации границ */
}
```

Также можно использовать `text-align: center` вместе с `line-height` или CSS Grid:

### Пример с Flexbox
```
<div class="grid-item">A</div>
```

### Пример с CSS Grid
```
.grid-item {
  display: grid;
  place-items: center; /* Центрирование по обеим осям */
  width: 100px;
  height: 100px;
  border: 1px solid #ccc;
}
```

Оба варианта эффективно выравнивают текст в центре.
