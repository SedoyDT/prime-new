Что за единица измерения em?::


`em` — это относительная единица измерения, которая используется в веб-дизайне и типографике для задания размеров шрифта, отступов, интервалов и других элементов. Её значение зависит от текущего размера шрифта элемента, к которому она применяется.

Основные особенности и примеры использования `em`:

1. **Относительность**:
   - Значение `1em` эквивалентно текущему размеру шрифта элемента.
   - Если размер шрифта родительского элемента составляет 16 пикселей, то `1em` будет равен 16 пикселей для вложенных элементов.

2. **Наследование**:
   - Если для родительского элемента задан размер шрифта `16px`, и для дочернего элемента задано `1.5em`, то размер шрифта дочернего элемента будет 24 пикселя (1.5 * 16px).

3. **Вложенные элементы**:
   - При вложении элементов размеры могут суммироваться. Например, если родительский элемент имеет размер шрифта `2em`, а вложенный элемент — `1.5em`, то вложенный элемент будет иметь размер шрифта, равный 3em от начального размера шрифта.

4. **Примеры использования**:
   ```

   .parent {
     font-size: 16px;
   }

   .child {
     font-size: 1.5em; /* 24px, т.к. 1.5 * 16px */
   }

   .nested-child {
     font-size: 2em; /* 48px, т.к. 2 * 24px */
   }
   
```

`em` часто используется в случаях, когда требуется обеспечить гибкость и адаптивность дизайна, поскольку размеры, заданные в `em`, легко масштабируются относительно базового размера шрифта.
