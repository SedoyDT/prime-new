Что можно сказать про селекторы элементов одного уровня(сестринские) sibling?::


https://codepen.io/sedoydt/pen/poXEKYX

```

<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title>Селекторы в CSS3</title>
        <style>
            h2+div { color: red; }
        </style>
    </head>
    <body>
        <h2>Заголовок</h2>
        <div>
            <p>Текст первого блока</p>
        </div>
        <div>
            <p>Текст второго блока</p>
        </div>
    </body>
</html>

```
Селектор h2+div позволяет определить стиль (в данном случае красный цвет текста) для блока div, который идет непосредственно после заголовка h2:
