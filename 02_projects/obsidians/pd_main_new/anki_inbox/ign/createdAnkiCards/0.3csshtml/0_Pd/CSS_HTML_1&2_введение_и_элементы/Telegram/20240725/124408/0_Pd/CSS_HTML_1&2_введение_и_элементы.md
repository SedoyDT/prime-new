Что можно сказть про элемент pre?::


Элемент pre выводит предварительно отформатированный текст так, как он определен:

```

<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title>Документ HTML5</title>
    </head>
    <body>
        <pre>
            Первая строка
            Вторая строка
            Третья строка
        </pre>
    </body>
</html>
```
