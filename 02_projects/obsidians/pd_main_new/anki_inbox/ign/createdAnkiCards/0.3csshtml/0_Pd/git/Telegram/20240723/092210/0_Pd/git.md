Как с в git посмотреть все коммиты оставленные определенным пользователем?::


Чтобы посмотреть все коммиты, оставленные определенным пользователем в Git, можно использовать команду `git log` с опцией `--author`. Вот как это можно сделать:

```

git log --author="Имя пользователя"

```

Замените `"Имя пользователя"` на имя или email пользователя, чьи коммиты вы хотите просмотреть. Git будет искать коммиты, где поле "Author" соответствует указанному имени или email.

Примеры использования:

1. Если вы хотите найти все коммиты, сделанные пользователем с именем "John Doe", выполните:

   ```

   git log --author="John Doe"
   
```

2. Если вы знаете email пользователя, вы также можете использовать его:

   ```

   git log --author="john.doe@example.com"
   
```

Эта команда `git log` отобразит список всех коммитов, сделанных указанным пользователем, включая информацию о каждом коммите, такую как хеш коммита, автор, дата и сообщение коммита.
