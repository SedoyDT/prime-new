Относительное позиционирование::


Относительное позиционирование также задается с помощью значения relative. Для указания конкретной позиции, на которую сдвигается элемент, применяются те же свойства top, left, right, bottom:

https://codepen.io/sedoydt/pen/eYwBOJb

```

<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title>Позиционирование в HTML5</title>
        <style>
            .outer {
                position: relative;
                left: 80px;
                top: 40px;
                width: 300px;
                height: 100px;
                border: 1px solid #ccc;
            }
            .inner{
                position: absolute;
                left: 80px;
                top: 40px;
                width: 50px;
                height: 50px;
                background-color: rgba(128, 0, 0, 0.5);
            }
        </style>
    </head>
    <body>
        <div class="outer"><div class="inner"></div></div>
    </body>
</html>
```
