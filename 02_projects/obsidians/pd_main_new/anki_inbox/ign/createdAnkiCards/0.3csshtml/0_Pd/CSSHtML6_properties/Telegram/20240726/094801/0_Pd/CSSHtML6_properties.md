Сокрытие элемента::


Значение none позволяет скрыть элемент, которого как-будто нет на веб-странице:

```

<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title>Свойство display в CSS3</title>
        <style>
            .invisible{
                display: none;
            }
        </style>
    </head>
    <body>
        <p>Первый параграф</p>
        <p class="invisible">Второй параграф</p>
        <p>Третий параграф</p>
    </body>
</html>
```
