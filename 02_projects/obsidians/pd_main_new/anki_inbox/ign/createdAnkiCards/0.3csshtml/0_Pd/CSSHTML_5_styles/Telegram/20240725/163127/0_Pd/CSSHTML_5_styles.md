Что можно сказать про Псевдокласс last-child::


:last-child: представляет элемент, который является последним дочерним элементом
https://codepen.io/sedoydt/pen/BagLPNv

```

<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title>Селекторы в CSS3</title>
        <style>
            a:last-child{
             
                color: blue;
            }
        </style>
    </head>
    <body>
        <h3>Смартфоны</h3>
```
