Радиус границы::


Свойство border-radius позволяет округлить границу. Это свойство принимает значение радиуса в пикселях или единицах em.

```

<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title>Блочная модель в CSS3</title>
        <style>
            div{
                width: 100px;
                height:100px;
                border: 2px solid red;
                border-radius: 30px;
            }
        </style>
    </head>
    <body>
        <div></div>
    </body>
</html>
```
