# Как выполнить эту команду в консоли с mv чтобы перенести все файлы кроме bak?
<!-- basicblock-start  deck='ign_linux' -->
Как выполнить эту команду в консоли с mv чтобы перенести все файлы кроме bak?::


Для перемещения всех файлов, кроме тех, которые содержат "bak" в имени, можно использовать комбинацию команды `find` с `mv`. Вот пример команды, которую можно выполнить в консоли:

```
find . -type f ! -name '*bak*' -exec mv {} /путь/к/целевой/директории/ \;
```

### Разбор команды:

1. `find .` — выполняет поиск в текущей директории.
2. `-type f` — ищет только файлы (не директории).
3. `! -name '*bak*'` — исключает файлы, содержащие "bak" в имени.
4. `-exec mv {} /путь/к/целевой/директории/ \;` — выполняет команду `mv` для каждого найденного файла (`{}` заменяется на имя файла).

Эта команда переместит все файлы, кроме тех, которые содержат "bak" в имени, в указанную целевую директорию.

Замените `/путь/к/целевой/директории/` на реальный путь к нужной вам директории.

# Добавление пользователя в Linux можно выполнить с помощью команды `useradd`. Вот основные шаги для добавления нового пользователя:
<!-- basicblock-start  deck='ign_linux' -->
Добавление пользователя в Linux можно выполнить с помощью команды `useradd`. Вот основные шаги для добавления нового пользователя:::


1. **Открыть терминал**: Запустите терминал на вашем Linux-сервере или компьютере. 

2. **Выполнить команду `useradd`**: Самый простой способ добавить пользователя:

   ```
   sudo useradd username
   
```

   Здесь `username` - это имя пользователя, которое вы хотите создать.

3. **Настройка пароля пользователя**: Чтобы задать пароль для нового пользователя, используйте команду `passwd`:

   ```
   sudo passwd username
   
```

   Следуйте инструкциям на экране для ввода нового пароля.

4. **Опциональные параметры**: Команда `useradd` поддерживает множество опций для настройки создаваемого пользователя. Например:

   - `-m`: Создать домашний каталог для пользователя, если его ещё нет.
   - `-s shell`: Указать командную оболочку для пользователя (по умолчанию `/bin/bash`).
   - `-g group`: Добавить пользователя в указанную группу.
   - `-G groups`: Добавить пользователя в дополнительные группы.
   - `-c comment`: Добавить комментарий о пользователе.

   Например, чтобы создать пользователя `john` с домашним каталогом и указать его комментарий, можно выполнить такую команду:

   ```
   sudo useradd -m -c "John Doe" john
   
```

5. **Проверка**: Чтобы убедиться, что пользователь успешно добавлен, можно выполнить команду `id`:

   ```
   id username
   
```

   Это покажет информацию о пользователе, включая его UID (идентификатор пользователя) и группы.

6. **Вход в систему**: После создания пользователя можно войти под его учётной записью. Для этого используйте команду `su` или выходите из текущей учётной записи и войдите заново под новым пользователем.

Важно помнить, что для выполнения команд `useradd` и `passwd` часто требуется использование привилегий суперпользователя, поэтому используйте `sudo` или выполните эти команды от имени пользователя с соответствующими правами.
