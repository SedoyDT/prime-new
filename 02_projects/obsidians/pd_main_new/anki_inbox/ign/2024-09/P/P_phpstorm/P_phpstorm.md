# Как экспортировать все настройки из phpstrom?
<!-- basicblock-start  deck='P_phpstorm' -->
Как экспортировать все настройки из phpstrom?::


Для экспорта всех настроек из PHPStorm вы можете воспользоваться встроенной функцией, которая позволяет сохранить ваши настройки в виде файла, который потом можно импортировать на другом компьютере или восстановить при необходимости. Вот пошаговая инструкция:

### Шаги для экспорта всех настроек:

1. **Открытие диалога настроек**:
   - Откройте PHPStorm.
   - Перейдите в меню: `File` → `Manage IDE Settings` → `Export Settings...`.

2. **Выбор настроек для экспорта**:
   - В появившемся окне выберите, какие именно настройки вы хотите экспортировать. Вы можете выбрать все настройки (по умолчанию), включая:
     - Keymaps (раскладки клавиш)
     - Code style (стили кода)
     - Plugins (установленные плагины)
     - UI settings (настройки интерфейса)
     - Templates (шаблоны кода и Live Templates)
     - И другие настройки.
   
   - Если хотите экспортировать всё, просто оставьте все галочки.

3. **Выбор места сохранения**:
   - Укажите путь, куда будет сохранён ZIP-файл с настройками. Этот файл будет содержать все ваши настройки.

4. **Нажмите "OK"**:
   - После этого PHPStorm создаст ZIP-файл с вашими настройками, который можно использовать для резервного копирования или переноса настроек на другой компьютер.

### Шаги для импорта настроек:

1. Перейдите в меню: `File` → `Manage IDE Settings` → `Import Settings...`.

2. Выберите ZIP-файл, который был экспортирован ранее, и нажмите "OK".

3. PHPStorm предложит перезаписать текущие настройки или добавить их к существующим.

### Альтернативный метод — использование **JetBrains Account**:

- Если вы используете JetBrains Account, вы можете синхронизировать ваши настройки с облаком. Для этого перейдите в `File` → `Manage IDE Settings` → `Sync Settings...` и подключите ваш JetBrains аккаунт.

Этот способ особенно удобен, если вам нужно использовать одни и те же настройки на нескольких компьютерах.

# В PhpStorm можно создавать и использовать live templates, которые значительно ускоряют процесс написания кода. Вот основные возможности и инструкции по созданию live templates с использованием точки ввода и переключения между ними:
<!-- basicblock-start  deck='P_phpstorm' -->
В PhpStorm можно создавать и использовать live templates, которые значительно ускоряют процесс написания кода. Вот основные возможности и инструкции по созданию live templates с использованием точки ввода и переключения между ними:::


### Основные шаги создания live template:
1. **Открытие настроек Live Templates:**
   - Перейдите в `File` > `Settings` (или `PhpStorm` > `Preferences` на macOS).
   - Найдите раздел `Editor` > `Live Templates`.

2. **Создание нового шаблона:**
   - Нажмите кнопку `+` и выберите `Live Template`.
   - Введите `Abbreviation` (сокращение), которое вы будете использовать для вставки шаблона.
   - Введите `Description` для описания шаблона.
   - Введите код шаблона в поле `Template Text`.

3. **Добавление точек ввода (variables):**
   - Чтобы добавить точки ввода, используйте `$VariableName$` в шаблоне.
   - Переключаться между точками ввода можно с помощью клавиши `Tab`.

4. **Настройка значений по умолчанию и поведения точек ввода:**
   - Нажмите кнопку `Edit Variables` в окне шаблона.
   - Введите значение по умолчанию для переменной или выберите функцию (например, `capitalize`, `lowercase`, `uppercase` и другие) для автоматического изменения текста.
   - Можно установить значение по умолчанию, если не хотите, чтобы переменная требовала ввода пользователем.

### Пример:
Предположим, вы хотите создать шаблон для функции в PHP:

```
function $FUNCTION_NAME$($PARAMETER$) {
    $END$
}
```

- `$FUNCTION_NAME$` и `$PARAMETER$` – это точки ввода, между которыми можно переключаться с помощью `Tab`.
- `$END$` – это точка завершения, куда курсор переместится после заполнения всех точек ввода.

### Применение шаблона:
1. Введите сокращение, которое вы назначили шаблону (например, `func`).
2. Нажмите `Tab`, чтобы развернуть шаблон.
3. Используйте `Tab` для переключения между точками ввода.

### Дополнительные возможности:
- **Context:** Вы можете настроить, в каком контексте шаблон будет доступен, например, только в PHP-файлах, в комментариях, в HTML и т.д.
- **Predefined templates:** PhpStorm уже содержит множество предустановленных шаблонов, которые можно модифицировать под свои нужды.

Эти возможности позволяют настраивать шаблоны для работы с кодом именно так, как вам удобно, повышая продуктивность и улучшая процесс разработки.

# В PhpStorm live templates поддерживают специальные маркеры (метки), которые помогают управлять поведением шаблона, включая окончательное положение курсора, автоматическое форматирование кода и многое другое. Вот подробное описание самых важных из них:
<!-- basicblock-start  deck='P_phpstorm' -->
В PhpStorm live templates поддерживают специальные маркеры (метки), которые помогают управлять поведением шаблона, включая окончательное положение курсора, автоматическое форматирование кода и многое другое. Вот подробное описание самых важных из них:::


### 1. `$END$`
- **Назначение:** Эта метка указывает на финальную позицию курсора после завершения всех действий в шаблоне.
- **Пример:**
  ```
  function $FUNCTION_NAME$($PARAMETERS$) {
      $END$
  }
  
```
  После того как все переменные (такие как `$FUNCTION_NAME$` и `$PARAMETERS$`) заполнены, курсор автоматически переместится на место `$END$`.

### 2. `$SELECTION$`
- **Назначение:** Эта метка используется для указания, куда будет помещен выделенный текст при развертывании шаблона.
- **Пример:**
  ```
  <strong>$SELECTION$</strong>
  
```
  Если вы выделите текст и примените шаблон, выделенный текст будет обернут тегом `<strong>`.

### 3. `$VAR$` и `$DEFAULT$`
- **Назначение:** `$VAR$` используется для определения точки ввода, где можно ввести данные. `$DEFAULT$` задает значение по умолчанию или выражение для переменной.
- **Пример:**
  ```
  function $FUNCTION_NAME$($PARAMETER$ = $DEFAULT$) {
      $END$
  }
  
```
  В этом примере `PARAMETER` будет иметь значение по умолчанию, которое вы определите через меню `Edit Variables`.

### 4. `$EXPR$`
- **Назначение:** Используется для выполнения выражения или функции во время развертывания шаблона.
- **Пример:**
  ```
  $VAR$ = $EXPR:date()$
  
```
  В этом случае переменная будет заполнена текущей датой.

### 5. `$DATE$`
- **Назначение:** Вставляет текущую дату. Можно настроить формат через `Edit Variables`.
- **Пример:**
  ```
  // Created on $DATE$
  
```
  При развертывании шаблона вставится текущая дата.

### 6. `$TIME$`
- **Назначение:** Вставляет текущее время.
- **Пример:**
  ```
  // Current time: $TIME$
  
```

### 7. `$USER$`
- **Назначение:** Вставляет имя текущего пользователя IDE.
- **Пример:**
  ```
  // Edited by $USER$
  
```

### 8. `$UUID$`
- **Назначение:** Вставляет уникальный идентификатор UUID.
- **Пример:**
  ```
  const UUID = '$UUID$';
  
```

### 9. `$FILE_NAME$`
- **Назначение:** Вставляет имя текущего файла.
- **Пример:**
  ```
  // File: $FILE_NAME$
  
```

### 10. `$CLIPBOARD$`
- **Назначение:** Вставляет содержимое буфера обмена.
- **Пример:**
  ```
  $CLIPBOARD$
  
```

### 11. `$LINE_NUMBER$`
- **Назначение:** Вставляет номер текущей строки.
- **Пример:**
  ```
  // Line: $LINE_NUMBER$
  
```

### Пример шаблона с несколькими метками:
```
/**
 * Class $CLASS_NAME$
 *
 * Created by $USER$ on $DATE$ at $TIME$
 */
class $CLASS_NAME$ {
    private $VAR$;

    function $FUNCTION_NAME$($PARAMETERS$) {
        $END$
    }
}
```
В этом шаблоне заполняются данные, такие как имя класса, имя функции, пользователь, дата и время, после чего курсор устанавливается в конец функции.

Эти метки позволяют гибко управлять шаблонами и автоматизировать процесс написания кода в PhpStorm, делая работу более эффективной и удобной.
