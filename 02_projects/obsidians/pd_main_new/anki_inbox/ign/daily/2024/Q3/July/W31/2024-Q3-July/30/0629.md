3.1 Вопрос: "В чем разница между `elseif` и `else if` в PHP?" ::
3.2 Ответ: "Конструкция `elseif` используется как часть одного блока `if`, в то время как `else if` трактуется как последовательность независимых блоков. Они функционально эквивалентны."
Пример кода 
```PHP
$score = 85;

if ($score >= 90) {
    echo 'Отлично';
} elseif ($score >= 75) {
    echo 'Хорошо'; // Это сообщение будет выведено, так как $score >= 75
} else {
    echo 'Удовлетворительно';
}
```

15.1 Вопрос: "Чем отличается `require` от `include` в PHP?" ::
15.2 Ответ: "Оба оператора включают файл, но `require` вызывает фатальную ошибку при отсутствии файла, тогда как `include` только предупреждение."
