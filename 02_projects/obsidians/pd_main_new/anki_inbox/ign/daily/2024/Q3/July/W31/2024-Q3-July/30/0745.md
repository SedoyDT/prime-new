Конечно! Вот вопрос-задача про передачу аргумента по ссылке:

<!-- basicblock-start oid="ObseT5zrRNtOVlqkIIO6fqHz" deck='0_Pd_php_docs_functions_6' --> 

9.1 Задача: "Создайте функцию, которая принимает массив и добавляет новое значение в этот массив. Продемонстрируйте, как изменения, внесенные в массив внутри функции, влияют на исходный массив, переданный в функцию по ссылке." ::  
9.2 Решение: "Определите функцию, которая изменяет массив, добавляя в него новый элемент. Используйте передачу аргумента по ссылке, чтобы изменения в массиве были видны за пределами функции."  
Пример кода:
```PHP
// Определение функции, которая добавляет элемент в массив
function addElement(&$array, $element) {
    $array[] = $element;
}

// Создание массива
$myArray = [1, 2, 3];

// Вызов функции для добавления элемента
addElement($myArray, 4);

// Вывод измененного массива
print_r($myArray); // Вывод: Array ( [0] => 1 [1] => 2 [2] => 3 [3] => 4 )
```

<!-- basicblock-end --> 

Этот пример демонстрирует, как изменения, внесенные в массив внутри функции, сохраняются и видны за пределами функции благодаря передаче массива по ссылке.
