Что означает термин "hoisting" в JavaScript?:: 

Hoisting («поднятие») — это внутренний механизм JavaScript, при котором **объявления переменных** (через `var`) и **функций** поднимаются (перемещаются вверх) в начало их области видимости на этапе компиляции, до выполнения кода.  
⚠️ Однако, **инициализация переменных** (присвоение значения) не поднимается.

Пример:
```js
console.log(x); // undefined
var x = 5;
```
Будет интерпретировано как:
```js
var x;
console.log(x); // undefined
x = 5;
``` 
<!-- basicblock-end -->


<!-- basicblock-start oid="Obs5iPWDHgSLDRJbmA3BnEei" deck='JavaScript' -->

Какой тип данных возвращается из функции `setTimeout()` в JavaScript?:: 

Функция `setTimeout()` возвращает **числовой идентификатор таймера** (`number`), который можно использовать для отмены таймера с помощью `clearTimeout()`.  

Пример:
```js
const timerId = setTimeout(() => {
  console.log('Привет');
}, 1000);

clearTimeout(timerId); // Отменяет выполнение
```

В браузерах идентификатор обычно представляет собой целое число, начиная с `1`, тогда как в Node.js это объект типа `Timeout`. 
<!-- basicblock-end -->


<!-- basicblock-start oid="ObsM3NsKrSJp0PZa1xZxl0Sl" deck='JavaScript' -->

В чём разница между операторами `==` и `===` в JavaScript?:: 

Разница между `==` и `===` заключается в том, как они сравнивают значения:

| Оператор | Проверяет значение | Приводит типы | Проверяет тип |
|----------|--------------------|----------------|---------------|
| `==`     | ✅                 | ✅             | ❌            |
| `===`    | ✅                 | ❌             | ✅            |

- `==` — **нестрогий** оператор сравнения, пытается привести типы перед сравнением.
- `===` — **строгий** оператор, проверяет и значение, и тип.

Примеры:
```js
0 == false;   // true (оба приводятся к числу)
0 === false;  // false (разные типы: number vs boolean)

'5' == 5;     // true (автоматическое преобразование)
'5' === 5;    // false
```

Рекомендуется всегда использовать `===` для избежания неочевидного поведения. 
<!-- basicblock-end -->

- **Конкретика вместо общих фраз**: говорить «Я сделаю это завтра» вместо «Постараюсь сделать».
- **Уверенные формулировки**: избегать слов-смягчителей вроде «может быть», «наверное», «я думаю».
- **Изменение темпа и громкости**: замедление речи добавляет вес словам, паузы делают акценты.
- **Модуляция голоса**: использование разных тонов в зависимости от контекста — от мягкого до решительного.

Харизматичная речь — это **чёткая, целенаправленная и эмоционально окрашенная** коммуникация.

Как можно использовать "позу силы" для повышения уверенности перед важным событием?:: 

Поза силы — это открытая, пространственная позиция тела, которая усиливает ощущение власти и уверенности. Например:
- Стоя с расправленными плечами, руками на бёдрах («поза победителя»).
- Сидя с прямой спиной и ногами чуть пошире плеч.

Автор советует **уделить 2–3 минуты этим позам** перед важной встречей или выступлением. Это снижает уровень кортизола (гормона стресса) и повышает тестостерон — физиологически готовит к уверенному поведению.  
Важно: не нужно «играть роль», важно просто **занять пространство уверенно**.

Как применять принцип "внимание к другим" в деловом общении?:: 

Принцип внимания к другим — ключевой элемент архетипа щедрости. Вот как его использовать в профессиональной среде:
- Задавать **открытые вопросы**, показывающие интерес к мнению собеседника.
- Использовать **имена** при обращении — это создаёт личный контакт.
- Давать **конкретную обратную связь**, подчёркивая сильные стороны коллег.
- Уделять полное внимание во время разговора — например, отложить телефон и не перебивать.

Этот подход формирует доверие, укрепляет отношения и делает вас более заметным и влиятельным в рабочей среде.

Какой практический приём помогает создать "эффект значимости" у собеседника?:: 

Чтобы вызвать чувство значимости у другого человека, используйте технику **"триггер внимания"**:
1. **Слушайте активно** — без внутреннего диалога, полностью фокусируясь на человеке.
2. **Задавайте уточняющие вопросы**, показывая, что вам важно понять его точку зрения.
3. **Отмечайте уникальность** — например: *«То, как ты это решил, действительно необычно»*.
4. **Благодарите за вклад**, даже если он кажется небольшим.

Этот приём активирует эмоциональную связь и делает общение более харизматичным и глубоким.

Как использовать дыхание для усиления харизмы в стрессовых ситуациях?:: 

Дыхание — мощный инструмент управления эмоциональным состоянием. В стрессовых моментах применяйте следующую технику:
- **Медленный вдох через нос на 4 секунды**
- **Задержка дыхания на 4 секунды**
- **Медленный выдох через рот на 6 секунд**

Эта практика:
- Успокаливает нервную систему
- Повышает ясность мышления
- Позволяет говорить уверенно и спокойно

Харизматичные люди сохраняют контроль в сложных ситуациях — а дыхательная практика помогает этому научиться.

Как сделать своё выступление более харизматичным с помощью голоса?:: 

Голос — один из самых сильных инструментов воздействия. Вот как его использовать эффективно:
- **Разнообразьте темп**: замедляйтесь, чтобы подчеркнуть важность, и ускоряйтесь для динамики.
- **Контролируйте громкость**: говорите тише, чтобы создать эффект конфиденциальности, и громче — для акцентов.
- **Используйте паузы**: они усиливают смысл и дают аудитории время осмыслить.
- **Меняйте интонацию**: избегайте монотонности — добавляйте эмоции и акценты.

Практический совет: запишите себя на видео и проанализируйте, как звучит ваш голос. Со временем вы сможете целенаправленно усиливать харизму через голосовые нюансы.
