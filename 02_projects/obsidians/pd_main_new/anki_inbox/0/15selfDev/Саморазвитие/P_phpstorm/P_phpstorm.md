# Как сравнить два удаленных репозитория git?
<!-- basicblock-start oid="ObsbtupScdpxmnjzl2TSCWCo"  deck='P_phpstorm' -->
Как сравнить два удаленных репозитория git?::


Для сравнения двух веток из разных репозиториев в PHPStorm вы можете использовать функцию Remote Repository Comparison (Сравнение удалённых репозиториев). Вот как это сделать:

1. **Добавление удалённых репозиториев:**
   - Убедитесь, что вы добавили оба репозитория как удалённые в PHPStorm. Это можно сделать через меню `VCS` -> `Git` -> `Remotes...`.

2. **Выбор веток для сравнения:**
   - Откройте окно сравнения репозиториев. Это можно сделать через меню `VCS` -> `Git` -> `Compare Remote...`.

3. **Настройка сравнения:**
   - В открывшемся окне выберите первый репозиторий и ветку, которую хотите сравнить.
   - Затем выберите второй репозиторий и ветку для сравнения.

4. **Просмотр изменений:**
   - После выбора веток вы увидите окно сравнения, где будут показаны различия между выбранными ветками из разных репозиториев.

Этот подход позволяет удобно сравнивать изменения между ветками, даже если они расположены в разных репозиториях.

# Что делает ng-view?
<!-- basicblock-start oid="ObsPJguqyoLVXX3C0RMFfWy5"  deck='P_phpstorm' -->
Что делает ng-view?::


`ng-view` — это директива в AngularJS, которая используется для внедрения шаблонов и реализации роутинга в одностраничных приложениях (SPA). Она является частью модуля `ngRoute`, который отвечает за маршрутизацию в AngularJS.

### Как работает `ng-view`:

1. **Роутинг и отображение страниц**:
   - `ng-view` выступает как контейнер для отображения HTML-шаблонов, которые загружаются динамически в зависимости от текущего URL.
   - При изменении маршрута (URL) AngularJS загружает соответствующий шаблон и контроллер, привязывая их к элементу `ng-view`.

2. **Связь с маршрутизацией**:
   - Для работы с `ng-view` вам нужно настроить маршрутизацию в приложении через сервис `$routeProvider`.
   - `$routeProvider` настраивает URL-маршруты и связывает их с конкретными шаблонами и контроллерами.
   
### Пример использования `ng-view`:

#### 1. HTML (где размещен `ng-view`):
```
<div ng-app="myApp">
  <ng-view></ng-view>
</div>
```

#### 2. Настройка маршрутизации в JavaScript:

```
var app = angular.module('myApp', ['ngRoute']);

app.config(function($routeProvider) {
  $routeProvider
    .when('/home', {
      templateUrl: 'home.html',
      controller: 'HomeController'
    })
    .when('/about', {
      templateUrl: 'about.html',
      controller: 'AboutController'
    })
    .otherwise({
      redirectTo: '/home'
    });
});
```

#### 3. Контроллеры:

```
app.controller('HomeController', function($scope) {
  $scope.message = 'Welcome to the Home Page!';
});

app.controller('AboutController', function($scope) {
  $scope.message = 'Learn more about us on this page.';
});
```

#### 4. Шаблоны (например, `home.html`):

```
<h1>Home</h1>
<p>{{ message }}</p>
```

#### Как это работает:
- Когда пользователь переходит на `/home`, AngularJS загружает шаблон `home.html` и связывает его с контроллером `HomeController`. Шаблон будет отображен внутри элемента с директивой `ng-view`.
- Если пользователь переходит на `/about`, аналогичным образом подгружается другой шаблон и контроллер.

### Основные моменты:
- `ng-view` используется для создания "области", куда динамически загружаются страницы (шаблоны) в зависимости от маршрута.
- Он помогает реализовать одностраничные приложения (SPA), где страницы не перезагружаются, а контент обновляется асинхронно в пределах текущего окна.

# Проблемы с поиском в PhpStorm могут возникать по разным причинам. Вот несколько шагов, которые могут помочь улучшить его работу на вашем Mac:
<!-- basicblock-start oid="ObsnIkvo7lYkOeXMpVBVTEnE"  deck='P_phpstorm' -->
Проблемы с поиском в PhpStorm могут возникать по разным причинам. Вот несколько шагов, которые могут помочь улучшить его работу на вашем Mac:::


### 1. **Проверьте индексирование**
   PhpStorm использует индексирование для быстрого поиска. Иногда индексация может быть повреждена или не завершена.

   - Перейдите в меню: `File` → `Invalidate Caches / Restart`.
   - Выберите `Invalidate and Restart`. Это очистит кэши и пересоберет индексы проекта.

### 2. **Увеличьте ресурсы для PhpStorm**
   PhpStorm может потреблять много памяти. Попробуйте увеличить объем выделенной памяти:

   - Откройте файл настроек памяти: `Help` → `Edit Custom VM Options...`.
   - Увеличьте параметры `-Xms` (начальная память) и `-Xmx` (максимальная память). Например:
     ```

     -Xms1024m
     -Xmx4096m
     
```
   Это даст больше памяти для индексации и поиска.

### 3. **Проверьте плагины**
   Некоторые плагины могут замедлять работу PhpStorm. Попробуйте временно отключить сторонние плагины:

   - Перейдите в: `Preferences` → `Plugins`.
   - Отключите плагины, которые вы не используете.

### 4. **Используйте поиск в пределах контекста**
   Если у вас очень большой проект, общая функция поиска может работать медленно. Попробуйте использовать более узкие варианты поиска:

   - `Ctrl + Shift + F` (поиск в файлах) и установите фильтры, например, ограничив поиск по папкам или типам файлов.
   - `Ctrl + N` или `Cmd + O` (на Mac) для поиска классов.
   - `Ctrl + Shift + N` или `Cmd + Shift + O` для поиска файлов.

### 5. **Проверьте обновления**
   Убедитесь, что вы используете последнюю версию PhpStorm. Иногда обновления содержат улучшения производительности и исправления ошибок.

### 6. **Переустановка IDE**
   Если ничего не помогает, попробуйте полностью переустановить PhpStorm, предварительно сохранив ваши настройки.

Эти шаги должны помочь улучшить производительность поиска в PhpStorm на вашем Mac.
