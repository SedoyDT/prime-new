На какие уровни делится приложение?::

1. Уровень представления - Представление данных генерирует направленный запрос на уровень управления 
2. Уровень команд и управления - Интерпретирует запрос и запрашивает уровень приложения 
3. Уровень логики приложения - Оценивает результаты и выбирает правильное представление 
4. Данные - Управляет получением и сохранением данных
