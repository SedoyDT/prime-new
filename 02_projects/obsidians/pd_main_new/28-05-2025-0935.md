## ⏱️ Pomodoro статистика

| №   | Время работы      | Ништяк | Хапочка |
| --- | ----------------- | ------ | ------- |
| 1   | [например, 2 мин] | ✅      | ✅       |
| 2   |                   |        |         |
| 3   |                   |        |         |
| 4   |                   |        |         |

> 💡 **Ништяк** = за попытку начать  
> 🌟 **Хапочка** = за 20+ минут сфокусированной работы  
> 🔥 **Бонус хапочка** = за 90+ минут без перерывов
