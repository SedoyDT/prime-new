Для локализации даты на русский язык, вы можете использовать функции `setlocale()` и `strftime()`, чтобы отобразить месяц на русском языке.

Вот как это сделать:

```php
// Установить локаль на русский
setlocale(LC_TIME, 'ru_RU.UTF-8');

// Преобразовать строку даты в timestamp
$dateString = $rowData->plan_period;
$timestamp = strtotime($dateString);

// Форматирование даты с локализацией на русский язык
$rowData->plan_period = strftime("%B %Y", $timestamp);

// Альтернатива с DateTime
// $date = new DateTime($dateString);
// $rowData->plan_period = strftime("%B %Y", $date->getTimestamp());
```

### Объяснение:

- `setlocale(LC_TIME, 'ru_RU.UTF-8')`: Устанавливает локаль для отображения дат и времени на русский язык.
- `strftime("%B %Y", $timestamp)`: Форматирует дату, выводя месяц (`%B`) и год (`%Y`) с учётом установленной локали.

### Пример вывода:

Если `$rowData->plan_period` изначально равно `"2024-09-04"`, то после обработки оно будет содержать строку `"сентябрь 2024"`.

### Примечание:

Убедитесь, что локаль `ru_RU.UTF-8` установлена на сервере. Если она отсутствует, ее нужно добавить, иначе `strftime()` может вернуть дату на английском языке.
