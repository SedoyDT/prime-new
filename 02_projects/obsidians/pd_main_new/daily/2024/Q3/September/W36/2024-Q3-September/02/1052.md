Функция в PHP, которая находит символы в строке и заменяет их на значения из массива, переданного вторым параметром, — это `strtr`.

Пример использования функции `strtr`:

```php
$string = "Hello World!";
$replace_pairs = array(
    'H' => 'J',
    'e' => 'a',
    'l' => 'm',
    'o' => 'u'
);

$new_string = strtr($string, $replace_pairs);

echo $new_string;  // Выведет "Jammu Wurmd!"
```

В этом примере:
- Функция `strtr` принимает два параметра: строку `$string` и массив замен `$replace_pairs`.
- Ключи массива соответствуют символам, которые нужно заменить.
- Значения массива соответствуют тем, на что эти символы будут заменены.

Функция `strtr` заменяет каждый символ из строки на соответствующее значение из массива, если такой ключ присутствует в массиве.
