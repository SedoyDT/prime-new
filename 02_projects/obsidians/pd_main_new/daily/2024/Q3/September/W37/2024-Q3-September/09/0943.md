Чтобы преобразовать строку, записанную в инфиксной нотации (например, `1 + 2.2 * 2.2 / 3.1`), в постфиксную нотацию (обратную польскую нотацию), можно воспользоваться алгоритмом "сортировочной станции" (Shunting-yard algorithm), разработанным Эдсгером Дейкстрой.

Вот как это можно реализовать на PHP:

```php
<?php
function toPolishNotation(string $expression): string {
    // Убираем лишние пробелы
    $expression = preg_replace('/\s+/', '', $expression);
    // Разбиваем строку на операнды и операторы
    $tokens = preg_split('((\d+\.?\d*)|([\+\-\*\/\(\)]))', $expression, -1, PREG_SPLIT_NO_EMPTY | PREG_SPLIT_DELIM_CAPTURE);

    // Операторы с их приоритетами
    $precedence = [
        '+' => 1,
        '-' => 1,
        '*' => 2,
        '/' => 2
    ];

    $output = []; // Выходной массив
    $operators = []; // Стек операторов

    foreach ($tokens as $token) {
        if (is_numeric($token)) {
            // Если токен - число, добавляем его в выходной массив
            $output[] = $token;
        } elseif (isset($precedence[$token])) {
            // Если токен - оператор
            while (!empty($operators) && end($operators) !== '(' && $precedence[end($operators)] >= $precedence[$token]) {
                $output[] = array_pop($operators);
            }
            $operators[] = $token;
        } elseif ($token === '(') {
            // Если токен - открывающая скобка, добавляем ее в стек операторов
            $operators[] = $token;
        } elseif ($token === ')') {
            // Если токен - закрывающая скобка, выталкиваем все операторы до открывающей скобки
            while (end($operators) !== '(') {
                $output[] = array_pop($operators);
            }
            array_pop($operators); // Удаляем открывающую скобку
        }
    }

    // Выталкиваем оставшиеся операторы в стек
    while (!empty($operators)) {
        $output[] = array_pop($operators);
    }

    // Возвращаем результат в виде строки
    return implode(' ', $output);
}

// Пример использования
$expression = "1 + 2.2 * 2.2 / 3.1";
$polishNotation = toPolishNotation($expression);
echo $polishNotation; // Вывод: 1 2.2 2.2 * 3.1 / +
?>
```

### Объяснение работы функции:

1. **Удаление пробелов**: Все лишние пробелы удаляются из выражения для упрощения дальнейшей обработки.

2. **Разбиение строки на токены**: Выражение разбивается на токены, которые могут быть числами, операторами или скобками.

3. **Алгоритм сортировочной станции**:
    - Числа сразу добавляются в выходной массив.
    - Операторы помещаются в стек, причём операторы с более высоким приоритетом (например, умножение и деление) вытесняют менее приоритетные операторы из стека.
    - Скобки обрабатываются так, чтобы содержимое в них вычислялось сначала.

4. **Формирование результата**: После обработки всех токенов оставшиеся в стеке операторы добавляются к выходному массиву.

5. **Результат**: Возвращается строка с выражением в постфиксной нотации.

### Пример работы:

Для выражения `"1 + 2.2 * 2.2 / 3.1"` результатом будет строка в польской нотации:

```
1 2.2 2.2 * 3.1 / +
```

Эту строку можно дальше использовать для вычислений в польской нотации.
