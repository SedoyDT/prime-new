Чтобы разбить строку вида `-1 +     2,2   / 2.2 * 3.1` на массив в формате `["-1","+","2,2","/","*","3.1"]` в PHP, можно воспользоваться регулярными выражениями с функцией `preg_split()`. Нам нужно разделить строку на числа (целые и с десятичными разделителями), операторы и при этом учитывать возможные пробелы.

Вот пример кода для этого:

```php
<?php
$input = '-1 +     2,2   / 2.2 * 3.1';

// Регулярное выражение для разделения строки на числа и операторы
$pattern = '/\s*([+\-*/])\s*/';

// Разбиваем строку
$result = preg_split($pattern, $input, -1, PREG_SPLIT_DELIM_CAPTURE);

// Убираем лишние пробелы вокруг элементов массива
$result = array_map('trim', $result);

print_r($result);
?>
```

### Объяснение:
- **Регулярное выражение** `\s*([+\-*/])\s*`:
  - `\s*` — игнорируем любые пробелы до и после операторов.
  - `([+\-*/])` — группа для захвата операторов `+`, `-`, `*`, `/`.
  
  Это выражение ищет операторы, окруженные пробелами, и использует их как разделители.
  
- **preg_split()** — разделяет строку по регулярному выражению и включает захваченные символы (операторы) в массив.
- **array_map('trim', ...)** — удаляет лишние пробелы вокруг каждого элемента массива.

### Вывод:
```php
Array
(
    [0] => -1
    [1] => +
    [2] => 2,2
    [3] => /
    [4] => 2.2
    [5] => *
    [6] => 3.1
)
```

Этот код разбивает строку на массив, где числа и операторы будут отдельными элементами массива, и при этом игнорируются лишние пробелы.
