Для того чтобы разбить строки вида `-1 + 2,2 / 2.2 * 3.1` и `1/2` на массивы в PHP, можно использовать функцию `preg_match_all()` с правильным регулярным выражением. Регулярное выражение должно учитывать числа с точкой или запятой, а также операторы арифметических действий.

Вот решение:

```php
<?php
function splitString($input) {
    // Регулярное выражение для чисел (целые и дробные) и операторов
    $pattern = '/-?\d+(?:[.,]\d+)?|[+\-*/]/';

    // Ищем все соответствия
    preg_match_all($pattern, $input, $matches);

    // Возвращаем результат
    return $matches[0];
}

$input1 = '-1 +     2,2   / 2.2 * 3.1';
$input2 = '1/2';

$result1 = splitString($input1);
$result2 = splitString($input2);

print_r($result1); // Вывод: ["-1", "+", "2,2", "/", "2.2", "*", "3.1"]
print_r($result2); // Вывод: ["1", "/", "2"]
?>
```

### Объяснение:
1. **Регулярное выражение** `/-?\d+(?:[.,]\d+)?|[+\-*/]/`:
   - `-?` — опциональный знак минуса перед числом.
   - `\d+` — одна или более цифр (целое число).
   - `(?:[.,]\d+)?` — не захватывающая группа для дробной части (например, `.2` или `,2`), где `.` или `,` выступают в качестве десятичного разделителя.
   - `[+\-*/]` — операторы `+`, `-`, `*`, `/`, которые также должны быть найдены.

2. **preg_match_all()** — находит все числа и операторы, соответствующие регулярному выражению, и возвращает массив этих значений.

3. **print_r()** — вывод результата в виде массива.

### Результат:

Для строки `'-1 + 2,2 / 2.2 * 3.1'`:

```php
Array
(
    [0] => -1
    [1] => +
    [2] => 2,2
    [3] => /
    [4] => 2.2
    [5] => *
    [6] => 3.1
)
```

Для строки `'1/2'`:

```php
Array
(
    [0] => 1
    [1] => /
    [2] => 2
)
```

Таким образом, строка успешно разбивается на массив с числами и операторами.
