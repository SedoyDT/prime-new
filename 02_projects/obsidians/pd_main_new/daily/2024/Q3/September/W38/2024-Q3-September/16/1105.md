Ошибка `Unknown modifier ']'` в PHP указывает на то, что регулярное выражение либо некорректное, либо разделители используются неправильно.

Ошибка возникает, потому что в регулярном выражении `preg_match_all()` присутствует неправильное или лишнее закрытие квадратной скобки `]`. Однако, в регулярном выражении, которое вы показали, таких проблем не должно быть, поэтому ошибка может быть вызвана каким-то другим контекстом, например, неверной передачей строки или ошибкой в другой части кода.

Давайте шаг за шагом попробуем исправить это:

1. Убедитесь, что строка, которую вы передаете в `preg_match_all()`, корректна и не содержит неожиданных символов или ошибок. Вы можете добавить вывод строки для проверки:

   ```php
   var_dump($operation);
   ```

2. Проверьте код, который вызывает функцию `splitBySpace()`, чтобы убедиться, что переменная `$operation` действительно содержит строку и передается корректно.

3. Попробуйте использовать регулярное выражение без изменений:

   ```php
   $pattern = '/-?\d+(?:[.,]\d+)?|[+\-*/]/';
   ```

4. Убедитесь, что не используются другие символы, которые могли бы вызвать ошибку в регулярном выражении. Например, проверьте, что символы `/` используются в качестве разделителей, и нет конфликтов с другим синтаксисом.

5. В качестве теста, можете попробовать использовать минимальный пример вне вашего проекта:

   ```php
   <?php
   function splitBySpace(string $operation)
   {
       $pattern = '/-?\d+(?:[.,]\d+)?|[+\-*/]/';

       preg_match_all($pattern, $operation, $matches);

       var_dump($matches[0]);
   }

   splitBySpace('-1 + 2,2 / 2.2 * 3.1');
   ?>
   ```

   Если этот код работает без ошибок, проблема может быть в том, как вы передаете строку в свою функцию.

### Если проблема сохраняется:
Попробуйте изолировать её, добавив проверку строки и регулярного выражения перед `preg_match_all()`.

```php
public function splitBySpace(string $operation)
{
    $pattern = '/-?\d+(?:[.,]\d+)?|[+\-*/]/';

    var_dump($operation); // Проверка, что строка корректная
    if (preg_match_all($pattern, $operation, $matches)) {
        var_dump($matches[0]);
    } else {
        echo "Ошибка в регулярном выражении или входных данных.";
    }

    exit();
}
``` 

Этот код проверит, правильно ли передаются данные в функцию. Если ошибка продолжает возникать, это может быть связано с контекстом или тем, как строка передается через командную строку.
