Чтобы разбить строки вида `-1 + 2,2 / 2.2 * 3.1` или `1/2` на массив с числами и операторами в PHP, можно использовать регулярное выражение, которое учитывает возможные десятичные числа, числа с запятой, а также операторы `+`, `-`, `*`, `/`.

Вот пример решения с использованием регулярного выражения и функции `preg_match_all()`:

```php
<?php
$input1 = '-1 +     2,2   / 2.2 * 3.1';
$input2 = '1/2';

// Регулярное выражение для чисел (с точкой или запятой) и операторов
$pattern = '/-?\d+(?:[\.,]\d+)?|[+\-*/]/';

// Ищем все соответствия
preg_match_all($pattern, $input1, $matches1);
preg_match_all($pattern, $input2, $matches2);

print_r($matches1[0]); // Результат для строки '-1 + 2,2 / 2.2 * 3.1'
print_r($matches2[0]); // Результат для строки '1/2'
?>
```

### Объяснение:
- **Регулярное выражение**:
  - `-?` — опциональный знак минуса перед числом.
  - `\d+` — одна или более цифр (целое число).
  - `(?:[\.,]\d+)?` — не захватывающая группа для дробной части с точкой или запятой (например, `.2` или `,2`).
  - `[+\-*/]` — любые из операторов `+`, `-`, `*`, `/`.
  
  Это регулярное выражение находит как целые числа, так и дробные (с запятой или точкой), а также операторы.

- **preg_match_all()** — находит все соответствия по регулярному выражению и возвращает их в виде массива.

### Результат:
Для строки `-1 + 2,2 / 2.2 * 3.1`:
```php
Array
(
    [0] => -1
    [1] => +
    [2] => 2,2
    [3] => /
    [4] => 2.2
    [5] => *
    [6] => 3.1
)
```

Для строки `1/2`:
```php
Array
(
    [0] => 1
    [1] => /
    [2] => 2
)
```

Это решение разбивает строки как с операторами и числами с запятой, так и с дробными числами, игнорируя пробелы.
