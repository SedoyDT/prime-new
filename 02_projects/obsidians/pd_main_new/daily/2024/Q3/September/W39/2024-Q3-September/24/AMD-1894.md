1. УИН - проект inventory, id = 10. Нужно проверить настройку network.ini
2. Копирование происходит через страницу “учёт сотрудников“.
3. Копирование происходит через вызов `\App_Network_Service_UserCopy_Sender::copy`. Обработка запроса на копирование происходит через `\App_Network_Service_UserCopy_Reciever::copy`
4. Требуется создать класс наблюдателя в папке `library/App/Network/Service/UserCopy/Component/Observer`. Наблюдатель будет подключаться только на проекте УИН. Отрабатывать наблюдатель будет после сохранения пользователя. В классе будет происходить вставка данных в таблицу `user_project`.

Пример наблюдателя в `\App\User\Component\Observer\Type\User\UpdateAccessData`
