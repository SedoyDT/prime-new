Для сравнения двух веток из разных репозиториев в PHPStorm вы можете использовать функцию Remote Repository Comparison (Сравнение удалённых репозиториев). Вот как это сделать:
1. **Добавление удалённых репозиториев:**
   - Убедитесь, что вы добавили оба репозитория как удалённые в PHPStorm. Это можно сделать через меню `VCS` -> `Git` -> `Remotes...`.
2. **Выбор веток для сравнения:**
   - Откройте окно сравнения репозиториев. Это можно сделать через меню `VCS` -> `Git` -> `Compare Remote...`.
3. **Настройка сравнения:**
   - В открывшемся окне выберите первый репозиторий и ветку, которую хотите сравнить.
   - Затем выберите второй репозиторий и ветку для сравнения.
4. **Просмотр изменений:**
   - После выбора веток вы увидите окно сравнения, где будут показаны различия между выбранными ветками из разных репозиториев.
Этот подход позволяет удобно сравнивать изменения между ветками, даже если они расположены в разных репозиториях.
