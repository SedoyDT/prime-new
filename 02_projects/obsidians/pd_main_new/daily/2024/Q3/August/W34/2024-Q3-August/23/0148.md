В конструкции `switch` условия в `case` работают не так, как в обычных конструкциях `if` или `match`. Конструкция `switch` сравнивает значение, переданное в `switch ($value)`, с каждым из значений `case`. Важно понимать, что `switch` выполняет **строгое** сравнение (`===`) значения `$value` с результатом, указанным в `case`. В вашем примере `case (is_null($value))` не работает, потому что `is_null($value)` возвращает `true` или `false`, и это значение сравнивается с `$value`.

### Почему не работает ваш код?

В данном примере:

```php
switch ($value) {
    case (is_int($value)):  $sfx="Int"; break;
    case (is_float($value)): $sfx="Float"; break;
    case (is_bool($value)):  $sfx="Bool"; break;
    case (is_null($value)):  $sfx="Null"; break;
    case (is_string($value)): $sfx="String"; break;
    case (is_object($value)): $sfx="Object"; break;
}
```

В `switch ($value)`, значение `$value` сравнивается с результатом каждого условия в `case`. Например, `is_null($value)` возвращает `true` или `false`, и сравнивается с `$value`. В случае `true`/`false`, это обычно не соответствует значению `$value`, поэтому `case` не срабатывает.

### Как это исправить

Для проверки типа значения нужно использовать либо конструкцию `if-else`, либо использовать `switch (true)` для проверки условий, что позволит проверить логические выражения:

```php
switch (true) {
    case is_int($value):  
        $sfx = "Int"; 
        break;
    case is_float($value): 
        $sfx = "Float"; 
        break;
    case is_bool($value):  
        $sfx = "Bool"; 
        break;
    case is_null($value):  
        $sfx = "Null"; 
        break;
    case is_string($value): 
        $sfx = "String"; 
        break;
    case is_object($value): 
        $sfx = "Object"; 
        break;
    default:
        $sfx = "Unknown"; 
        break;
}
```

### Объяснение исправления

- **`switch (true)`:** В данном коде `switch` проверяет истинность (`true`) каждого выражения в `case`. Это позволяет использовать логические выражения в `case`.
  
- **`case is_int($value):`**: Теперь `is_int($value)` возвращает `true` или `false`, и этот результат сравнивается с `true`, переданным в `switch`. Если результат `is_int($value)` равен `true`, тогда соответствующий `case` выполняется.

### Заключение

Для проверки типа значения или выполнения логических выражений внутри `switch`, правильным подходом является использование `switch (true)`. Это позволяет выполнять условия и применять соответствующие действия на основе истинности этих условий.
