## Настройка DNS

Необходимо добавить адрес дополнительного DNS сервера 192.168.51.5 для этого установим утилиту resolvconf. _DNS адрес необходим для связи Docker контейнеров._

```
sudo apt install resolvconf
```

Добавляем новую DNS запись в /etc/resolvconf/resolv.conf.d/head

```
sudo vim /etc/resolvconf/resolv.conf.d/head
```

В конец файла добавляем строчку

```
nameserver 192.168.51.5
```

Перезагружаем машину

```
sudo reboot
```

Запускаем docker-compose

```
cd ~/amd-docker-dev && docker compose up
```

Проверяем настройку DNS выполняя команду

```
ping amdcoru.master.a.dev
```

## Установка и настройка Docker

В проекте используется новая версия docker. Compose должен быть частью docker и вызываться так: docker compose.

- Установить docker по [инструкции](https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository) и выполнить [post-installation-steps](https://docs.docker.com/engine/install/linux-postinstall/)
    
- Склонировать репозиторий с docker окружением (в домашнюю директорию)
    

```
git clone git@bitbucket.org:pikcher/amd-docker-dev.git
```

- Склонировать репозиторий с проектом
    

```
cd ~/amd-docker-dev/data/www/lp
```

```
git clone git@bitbucket.org:pikcher/amd-co.git master
```

Собираем и запускаем docker:

```
cd ~/amd-docker-dev && docker compose up
```

Следим чтобы все нормально собралось и не было ошибок. В результате запуска должны подняться сервисы:

- amd-docker-dev-amd-mysql
    
- amd-docker-dev-amd-dev-dns
    
- amd-docker-dev-amd-memcached
    
- amd-docker-dev-amd-apache

## Настройка проекта

Открываем код проекта, файлы с настройками проекта лежат в директории: application/configs. Файлы с названием в формате <CONFIG_NAME>.example.ini являются шаблонными файлами.

## Настройка утилиты для восстановления дампов

Создать директорию, в которой будут храниться скачанные дампы:

```
mkdir ~/dumps
```

Создать директорию для конфигураций. В этой директории будут храниться настройки для утилит разработчика.

```
mkdir -p ~/.config/amd
```

Создать конфигурационный файл и заполнить его данными:

```
vim ~/.config/amd/backup.cfg
```

Содержимое файла:

```
TARGET_DIR=~/dumps
# Здесь можно указать день, за который будет восстанавливаться дамп.
# По-умолчанию в backuprestore.sh стоит "yesterday", переопределить можно здесь
DEFAULT_DAY="today"
export MYSQL_PWD="root"
RESTORE_MYSQL_ARGS="-uroot -h192.168.51.3 -c"
# AUTH_EMAIL="" # Можно указать email используемый для авторизации на AMD-Report
```

Установить утилиту pv. Используется для отображения прогрессбара при восстановлении дампа.

```
sudo apt install pv
```

Создаем базу

```
amd-docker-dev/bin/amd-create-db.sh amdcoru
```

Восстанавливаем дамп:

```
backup/backuprestore.sh -p 1 -b amdcoru
```

Запускаем скрипт для обновления процедур, функций, триггеров MySQL. _Этот скрипт необходимо запускать после каждого восстановления дампа._

```
cd ~/amd-docker-dev/data/www/lp/master
```

```
amd-executor.sh php protected/scripts/dbmodel/update-stored-data.php stanok
```

## Авторизация в проекте

Для авторизация устанавливаем утилитку oathtool

```
sudo apt install oathtool
```

Переходим по адресу проекта

- Выбираем опцию “Войти с приложения“
    
- Вводим логин пароль
    

Далее необходимо ввести код подтверждения для входа. Генерируем его используя oathtool

```
oathtool -b --totp <secret>
```
