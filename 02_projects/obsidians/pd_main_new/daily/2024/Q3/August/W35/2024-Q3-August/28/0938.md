Этот код определяет функцию `spy`, которая "подглядывает" за вызовами другой функции, записывая аргументы каждого вызова. Рассмотрим его работу по частям.

### Общий обзор:
Функция `spy` предназначена для обертки другой функции с целью отслеживания всех вызовов этой функции и сохранения аргументов каждого вызова.

### Разбор кода:

```javascript
function spy(func) {
```
- `spy` — это функция, которая принимает в качестве аргумента другую функцию `func`. Эта функция, которую мы передаем, будет той, за вызовами которой мы будем "подглядывать".

```javascript
  function wrapper(...args) {
```
- Внутри `spy` создается новая функция `wrapper`, которая принимает любые аргументы с помощью синтаксиса `...args`. `...args` позволяет собрать все переданные аргументы в массив.

```javascript
    wrapper.calls.push(args);
```
- Этот код сохраняет переданные аргументы в массив `wrapper.calls`. Массив `wrapper.calls` создается в функции `spy` (см. ниже) и изначально пуст. После каждого вызова `wrapper` в него добавляется массив аргументов, с которыми была вызвана функция.

```javascript
    return func.apply(this, args);
```
- `func.apply(this, args)` вызывает оригинальную функцию `func`, передавая ей `this` (контекст) и аргументы `args`. Метод `apply` позволяет передать функции массив аргументов в качестве отдельного списка значений.

```javascript
  wrapper.calls = [];
```
- Здесь создается пустой массив `wrapper.calls`. Этот массив будет хранить все аргументы, с которыми `wrapper` будет вызван.

```javascript
  return wrapper;
```
- Функция `spy` возвращает функцию-обертку `wrapper`, которая сохраняет аргументы каждого вызова и затем вызывает оригинальную функцию `func`.

### Как это работает?

Допустим, у вас есть функция `sum`:

```javascript
function sum(a, b) {
  return a + b;
}
```

Вы хотите отслеживать вызовы этой функции. Вы можете обернуть ее с помощью `spy`:

```javascript
let spySum = spy(sum);
```

Теперь, когда вы вызываете `spySum`, она ведет себя как `sum`, но при этом записывает все аргументы вызова:

```javascript
spySum(1, 2); // Вернет 3, как и функция sum
spySum(3, 4); // Вернет 7, как и функция sum

console.log(spySum.calls); // Выведет [[1, 2], [3, 4]]
```

Таким образом, массив `spySum.calls` будет содержать списки аргументов для каждого вызова функции `spySum`.
