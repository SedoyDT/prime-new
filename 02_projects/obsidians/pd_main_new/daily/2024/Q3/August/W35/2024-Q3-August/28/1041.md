Переключение между версиями PHP зависит от операционной системы, которую вы используете. Рассмотрим, как это сделать в наиболее распространённых операционных системах: **Ubuntu/Debian** и **macOS**. Если у вас другая система, дайте знать, и я помогу вам с ней.

### Ubuntu/Debian

На Ubuntu/Debian можно использовать `update-alternatives` для переключения между версиями PHP.

#### 1. **Установка нескольких версий PHP:**
   Если у вас ещё не установлены несколько версий PHP, установите их:
   ```bash
   sudo apt-get install php7.4 php8.1
   ```

#### 2. **Настройка `update-alternatives`:**
   Сначала настройте `update-alternatives` для команд PHP, PHP-FPM и PHP-CLI:
   ```bash
   sudo update-alternatives --set php /usr/bin/php7.4
   sudo update-alternatives --set php /usr/bin/php8.1
   ```

   Если вы хотите, чтобы система спросила, какую версию PHP использовать:
   ```bash
   sudo update-alternatives --config php
   ```

   Вы увидите список всех установленных версий PHP, и сможете выбрать нужную, введя соответствующий номер.

#### 3. **Переключение версий PHP-FPM (для веб-серверов):**
   Если вы используете PHP-FPM с Nginx или Apache, вам нужно также переключить PHP-FPM:

   - Остановите текущую службу PHP-FPM:
     ```bash
     sudo systemctl stop php7.4-fpm
     sudo systemctl stop php8.1-fpm
     ```

   - Запустите нужную версию:
     ```bash
     sudo systemctl start php8.1-fpm
     ```

   - Перезапустите веб-сервер:
     ```bash
     sudo systemctl restart nginx
     ```
     или
     ```bash
     sudo systemctl restart apache2
     ```

### macOS

На macOS проще всего переключаться между версиями PHP, используя Homebrew.

#### 1. **Установка нескольких версий PHP:**
   Установите нужные версии PHP через Homebrew:
   ```bash
   brew install php@7.4
   brew install php@8.1
   ```

#### 2. **Переключение версий PHP:**
   Homebrew предоставляет команды для переключения активной версии PHP:
   ```bash
   brew unlink php@7.4
   brew link php@8.1
   ```

   Homebrew автоматически установит симлинки на `php` и `phpize` для выбранной версии.

#### 3. **Проверка активной версии PHP:**
   После переключения проверьте активную версию PHP:
   ```bash
   php -v
   ```

### Windows

На Windows переключение версий PHP зависит от способа установки. Если вы установили PHP вручную, то переключение происходит через изменение переменной `PATH`.

#### 1. **Переместите активную версию PHP в начало `PATH`:**
   - Откройте "Переменные среды" (как описано в предыдущих шагах).
   - Измените порядок записей в `PATH`, переместив путь к нужной версии PHP (например, `C:\php7.4`) наверх списка.

#### 2. **Проверьте версию:**
   Откройте командную строку и введите:
   ```bash
   php -v
   ```

Если у вас возникнут проблемы или вам нужны конкретные команды для вашей системы, дайте знать!
