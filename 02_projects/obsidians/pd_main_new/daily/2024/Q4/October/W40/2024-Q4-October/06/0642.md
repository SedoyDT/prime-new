Чтобы настроить Xdebug в PhpStorm с использованием Docker Compose, следуйте пошаговой инструкции. Этот процесс включает в себя настройку Docker Compose, конфигурацию PHP с Xdebug и установку PhpStorm для работы с удалённой отладкой.

### 1. Настройка Docker Compose с Xdebug

#### Шаг 1: Обновите `docker-compose.yml`

В файле `docker-compose.yml` добавьте Xdebug как часть PHP-контейнера. Пример:

```yaml
version: '3.7'

services:
  php:
    image: php:7.4-fpm  # Или другой образ PHP
    container_name: my_php_app
    build:
      context: .
      dockerfile: Dockerfile
    volumes:
      - ./src:/var/www/html
    environment:
      XDEBUG_MODE: debug
      XDEBUG_CONFIG: "client_host=host.docker.internal"  # Для Windows и Mac
      PHP_IDE_CONFIG: "serverName=Docker"

  web:
    image: nginx:latest
    container_name: my_nginx
    ports:
      - "8080:80"
    volumes:
      - ./src:/var/www/html
      - ./nginx.conf:/etc/nginx/nginx.conf

  db:
    image: mysql:5.7
    container_name: my_db
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: app
```

#### Шаг 2: Обновите Dockerfile

Добавьте Xdebug в `Dockerfile` PHP-контейнера:

```Dockerfile
FROM php:7.4-fpm

# Устанавливаем зависимости
RUN apt-get update && apt-get install -y \
    libfreetype6-dev \
    libjpeg62-turbo-dev \
    libpng-dev \
    && docker-php-ext-configure gd --with-freetype --with-jpeg \
    && docker-php-ext-install -j$(nproc) gd

# Устанавливаем Xdebug
RUN pecl install xdebug \
    && docker-php-ext-enable xdebug

# Настройка Xdebug
COPY ./xdebug.ini /usr/local/etc/php/conf.d/xdebug.ini
```

Создайте файл `xdebug.ini` с конфигурацией Xdebug:

```ini
zend_extension=xdebug.so
xdebug.mode=debug
xdebug.start_with_request=yes
xdebug.client_host=host.docker.internal  # Для Windows и Mac
xdebug.client_port=9003
xdebug.log=/tmp/xdebug.log
```

#### Шаг 3: Соберите и запустите контейнеры

Теперь выполните сборку и запуск контейнеров:

```bash
docker-compose up --build
```

### 2. Настройка PhpStorm для Xdebug

#### Шаг 1: Настройка интерпретатора

1. Откройте **PhpStorm** и перейдите в **File** → **Settings** (или **Preferences** на macOS).
2. Перейдите в **Languages & Frameworks** → **PHP**.
3. В разделе **CLI Interpreter** нажмите **...** → **Add** → **Docker**.
4. Выберите контейнер с PHP, который будет использоваться для отладки.
5. PhpStorm автоматически определит Xdebug.

#### Шаг 2: Настройка сервера

1. Перейдите в **Settings** → **Languages & Frameworks** → **PHP** → **Servers**.
2. Нажмите **+** для создания нового сервера.
   - В поле **Name** введите `Docker` (или любое другое имя).
   - Укажите **Host** (например, `localhost`).
   - Укажите **Port**: 8080 (если в Docker Compose у вас указан этот порт).
   - Установите галочку **Use path mappings** и сопоставьте корневую директорию на вашем хосте с `/var/www/html` в контейнере.

#### Шаг 3: Настройка конфигурации отладки

1. Нажмите на **Run** в правом верхнем углу → **Edit Configurations...**.
2. Нажмите **+** и выберите **PHP Remote Debug**.
3. Назовите конфигурацию, например, `Docker Xdebug`.
4. В поле **Server** выберите созданный ранее сервер `Docker`.
5. Установите **IDE key** как `PHPSTORM`.

#### Шаг 4: Включение прослушивания отладчика

1. В правом верхнем углу найдите значок телефона и убедитесь, что он активирован (**Start Listening for PHP Debug Connections**).

#### Шаг 5: Проверьте Xdebug

Чтобы убедиться, что Xdebug работает:

1. Поставьте точку останова в любом PHP-файле.
2. Перейдите в браузере по URL вашего проекта (например, `http://localhost:8080`).
3. Если все настроено верно, PhpStorm остановится на точке останова, и вы сможете начать отладку.

### Примечание:

Для Linux используйте `client_host` равный вашему IP-адресу (например, `172.17.0.1`) вместо `host.docker.internal`.

Теперь вы можете выполнять отладку вашего проекта с использованием Xdebug и Docker Compose в PhpStorm!
