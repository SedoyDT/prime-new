Если вам нужно применить стили к `nth-child` с учетом псевдоэлементов, можно использовать комбинацию селекторов. Псевдоэлементы, такие как `::before` и `::after`, не являются "дочерними" элементами, поэтому к ним нельзя напрямую применять `nth-child`.

Вот как можно это сделать:

### HTML

```html
<div class="grid-container">
    <div class="item">Колонка 1</div>
    <div class="item">Колонка 2</div>
    <div class="item">Колонка 3</div>
    <div class="item">Колонка 4</div>
</div>
```

### CSS

```css
.grid-container {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 10px;
}

.item {
    position: relative;
    background-color: lightblue;
    padding: 20px;
    text-align: center;
}

.item:nth-child(2)::after {
    content: '';
    display: block;
    margin-right: 20px; /* Промежуток после 2 колонки */
}

.item:nth-child(3)::before {
    content: '';
    display: block;
    margin-left: 20px; /* Промежуток перед 3 колонкой */
}
```

### Объяснение

1. **Селекторы**: Используются селекторы `nth-child` для выбора конкретных элементов.
2. **Псевдоэлементы**: `::after` и `::before` создают визуальные элементы, которые можно использовать для добавления пространства. Они добавляют `margin` только в визуальном представлении.
3. **Положение**: Важно, чтобы псевдоэлементы имели свойство `display: block`, чтобы можно было управлять их размерами и отступами.

Таким образом, с помощью псевдоэлементов можно визуально управлять промежутками, сохраняя семантику и структуру HTML.
