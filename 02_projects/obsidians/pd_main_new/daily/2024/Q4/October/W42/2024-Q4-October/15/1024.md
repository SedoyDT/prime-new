Чтобы найти элемент по атрибуту в JavaScript, можно использовать методы `querySelector` или `querySelectorAll`, применяя селекторы атрибутов.

### Пример:

1. **Найти первый элемент по атрибуту:**

```javascript
let element = document.querySelector('[attribute-name="value"]');
```

2. **Найти все элементы по атрибуту:**

```javascript
let elements = document.querySelectorAll('[attribute-name="value"]');
```

### Объяснение:
- **`[attribute-name="value"]`**: это селектор атрибута. Он ищет элементы, у которых есть атрибут `attribute-name` с определённым значением `value`.
- Можно искать элементы по частичному совпадению:
  - **`[attribute-name]`**: Найдет все элементы, у которых есть атрибут `attribute-name`, независимо от значения.
  - **`[attribute-name^="value"]`**: Найдет все элементы, у которых значение атрибута начинается с `value`.
  - **`[attribute-name$="value"]`**: Найдет все элементы, у которых значение атрибута заканчивается на `value`.
  - **`[attribute-name*="value"]`**: Найдет все элементы, у которых значение атрибута содержит `value`.

### Пример использования:

```html
<div data-id="123"></div>
<div data-id="456"></div>

<script>
  let element = document.querySelector('[data-id="123"]');
  console.log(element);  // Найдет первый <div data-id="123">
  
  let allElements = document.querySelectorAll('[data-id]');
  console.log(allElements);  // Найдет все <div> с атрибутом data-id
</script>
```

Таким образом, можно легко найти элемент по атрибутам с помощью CSS-селекторов.

Чтобы найти элемент по атрибуту, который содержит подстроку, можно использовать селектор атрибутов с символом `*`. Этот символ означает, что значение атрибута должно содержать указанную подстроку.

### Пример:

```javascript
let element = document.querySelector('[attribute-name*="substring"]');
```

### Объяснение:
- **`[attribute-name*="substring"]`**: Найдет все элементы, у которых атрибут `attribute-name` содержит подстроку `substring`.

### Пример использования:

```html
<div data-info="product-123"></div>
<div data-info="product-456"></div>
<div data-info="item-789"></div>

<script>
  // Найти элемент, у которого data-info содержит "product"
  let elements = document.querySelectorAll('[data-info*="product"]');
  
  elements.forEach(el => {
    console.log(el);  // Выведет оба div, где data-info содержит "product"
  });
</script>
```

Этот подход позволяет легко находить элементы, у которых значение атрибута содержит определённую подстроку.
