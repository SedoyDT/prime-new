Браузер добавляет горизонтальную прокрутку (overflow-x: auto), когда содержимое элемента выходит за пределы его видимой области (контейнера). Давайте разберёмся, как это работает.

### 1. Как браузер решает, нужна ли прокрутка?
Когда у элемента установлен overflow-x: auto, браузер автоматически проверяет:

- Ширину содержимого (`scrollWidth`) — это фактическая ширина всего контента внутри элемента, включая невидимые части, которые могут выходить за границы.
- Ширину контейнера (`clientWidth`) — это ширина элемента без полосы прокрутки.

Если scrollWidth > clientWidth, то браузер добавляет горизонтальную полосу прокрутки.

### 2. Пример работы `overflow-x: auto`
<div class="container">
  <div class="content">Очень длинный текст или большой элемент...</div>
</div>

.container {
  width: 300px;
  border: 1px solid black;
  overflow-x: auto;
  white-space: nowrap; /* Чтобы текст не переносился */
}

.content {
  width: 600px; /* Ширина больше контейнера */
  background: lightblue;
}

Что происходит?
- Контейнер (.container) имеет фиксированную ширину 300px.
- Внутренний элемент (.content) шире (600px).
- Браузер видит, что scrollWidth (600px) > clientWidth (300px), и добавляет горизонтальную прокрутку.

### 3. Когда прокрутка не появляется?
- Если содержимое полностью помещается в контейнер (scrollWidth <= clientWidth).
- Если white-space: normal (текст переносится, уменьшая scrollWidth).
- Если display: flex и контент не выходит за границы (гибкая верстка).

### 4. Как проверить в DevTools?
В Chrome DevTools можно посмотреть scrollWidth и clientWidth элемента:
1. Открыть Инструменты разработчика (F12).
2. Выбрать элемент в Elements.
3. В Computed найти scrollWidth и clientWidth.
