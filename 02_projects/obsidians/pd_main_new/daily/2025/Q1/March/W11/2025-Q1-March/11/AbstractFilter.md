# Обзор класса AbstractFilter

## Пространство имен
`App\Development\TypeScript`

## Описание
Класс `AbstractFilter` служит базовым классом для реализации различных фильтров в среде разработки TypeScript. Он предоставляет структурированный способ построения SQL-запросов с поддержкой масок, декораторов и различных условий фильтрации.

## Свойства
- **$configConditions**: Массив для хранения конфигурационных условий.
- **$_oldDecoratorsAdapter**: Адаптер для старых декораторов.
- **$_order**: Массив для параметров сортировки.
- **$_startRow**: Целое число для начальной строки результирующего набора.
- **$_rowCount**: Целое число для количества запрашиваемых строк.
- **$_db**: Экземпляр адаптера базы данных.
- **$_maskData**: Массив, содержащий данные масок.
- **$_masks**: Коллекция масок.
- **$_where**: Массив для условий WHERE.
- **$_having**: Массив для условий HAVING.
- **$_filterResult**: Экземпляр `FilterResultInterface`.
- **$_showSql**: Логический флаг, указывающий, нужно ли показывать SQL-запросы.
- **$_useMaskSql**: Логический флаг для использования отдельных SQL-запросов для масок.
- **$useResultSql**: Приватный флаг, указывающий, извлекаются ли результаты.

## Конструктор
```php
public function __construct(Zend_Db_Adapter_Abstract $db = null)
```
Инициализирует соединение с базой данных и коллекцию масок.

## Ключевые методы
- **getDb()**: Возвращает экземпляр адаптера базы данных.
- **setShowSql(bool $showSql)**: Устанавливает флаг для отображения SQL-запросов.
- **getFilterResult()**: Получает результат фильтра, инициализируя его при необходимости.
- **getResultSql()**: Абстрактный метод, который должен быть реализован подклассами для возврата строки SQL-запроса.
- **buildQuery()**: Конструирует SQL-запрос на основе примененных масок и условий.
- **getRows($fetchMode)**: Извлекает отфильтрованные строки из базы данных.
- **getTotalCount()**: Возвращает общее количество строк, соответствующих условиям фильтрации.
- **applyMask()**: Применяет данные масок к условиям фильтрации.
- **addMask($maskOrData)**: Добавляет маску к фильтру.

## Пример использования
Чтобы использовать класс `AbstractFilter`, обычно нужно расширить его и реализовать метод `getResultSql()`, чтобы определить конкретную логику SQL-запроса для вашего фильтра.

```php
class MyCustomFilter extends AbstractFilter {
    public function getResultSql(): string {
        // Реализуйте пользовательскую логику SQL здесь
    }
}
```

## Примечания
- Класс разработан для работы с компонентами базы данных Zend Framework.
- Он поддерживает сложную фильтрацию с помощью масок и декораторов.
- Класс предоставляет методы для отладки SQL-запросов и эффективного управления условиями фильтрации.

## Заключение
Класс `AbstractFilter` является мощным инструментом для построения динамических SQL-запросов структурированным образом, позволяя гибкость и повторное использование в реализации фильтров.
