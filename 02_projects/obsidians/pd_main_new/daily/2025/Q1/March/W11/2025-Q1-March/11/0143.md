# Обзор класса AbstractFilter

## Пространство имен
`App\Development\TypeScript`

## Описание
Класс `AbstractFilter` является абстрактным классом, который служит основой для реализации различных фильтров в среде разработки [[TypeScript]]. Он предоставляет структурированный подход к построению SQL-запросов с поддержкой масок, декораторов и различных условий фильтрации.

## Свойства класса
- **$configConditions**: 
  - Тип: `array`
  - Описание: Массив для хранения конфигурационных условий фильтрации.

- **$_oldDecoratorsAdapter**: 
  - Тип: `OldDecoratorsAdapter`
  - Описание: Адаптер для работы со старыми декораторами.

- **$_order**: 
  - Тип: `array`
  - Описание: Параметры сортировки.
  - Пример: 
    ```php
    field[]
    [[field => name, sort => direction]]
    ```

- **$_startRow**: 
  - Тип: `int`
  - Описание: Начальная строка для выборки данных.
  - Значение по умолчанию: `0`

- **$_rowCount**: 
  - Тип: `int`
  - Описание: Количество запрашиваемых строк.
  - Значение по умолчанию: `50`

- **$_db**: 
  - Тип: `App_Db_Abstract|Zend_Db_Adapter_Abstract`
  - Описание: Экземпляр адаптера базы данных.

- **$_maskData**: 
  - Тип: `array`
  - Описание: Данные масок, используемые в фильтре.

- **$_masks**: 
  - Тип: `MaskCollection`
  - Описание: Коллекция масок, применяемых к фильтру.

- **$_where**: 
  - Тип: `array`
  - Описание: Условия WHERE, сгруппированные по различным именам.
  - Пример:
    ```php
    WHERE  => ['a', 'b'],
    WHERE2 => ['a', 'c']
    ```

- **$_having**: 
  - Тип: `array`
  - Описание: Условия HAVING для фильтрации результатов.

- **$_filterResult**: 
  - Тип: `FilterResultInterface`
  - Описание: Результат фильтрации.

- **$_showSql**: 
  - Тип: `bool`
  - Описание: Флаг, указывающий, нужно ли показывать SQL-запросы.
  - Значение по умолчанию: `false`

- **$_useMaskSql**: 
  - Тип: `bool`
  - Описание: Флаг, указывающий на использование отдельного запроса для маски.
  - Значение по умолчанию: `false`

- **$useResultSql**: 
  - Тип: `bool`
  - Описание: Приватный флаг, указывающий, используется ли метод `getResult`.

## Конструктор
```php
public function __construct(Zend_Db_Adapter_Abstract $db = null)
```
### Описание
Инициализирует соединение с базой данных и создает коллекцию масок. Если база данных не передана, используется значение по умолчанию из `App_Db`.

## Ключевые методы

### 1. getDb()
```php
public function getDb()
```
- **Описание**: Возвращает экземпляр адаптера базы данных.

### 2. setShowSql(bool $showSql)
```php
public function setShowSql(bool $showSql): AbstractFilter
```
- **Описание**: Устанавливает флаг для отображения SQL-запросов.
- **Параметры**: 
  - `$showSql`: Логическое значение, указывающее, нужно ли показывать SQL.

### 3. getFilterResult()
```php
public function getFilterResult(): FilterResultInterface
```
- **Описание**: Получает результат фильтрации, инициализируя его при необходимости.

### 4. getResultSql()
```php
public abstract function getResultSql(): string;
```
- **Описание**: Абстрактный метод, который должен быть реализован подклассами для возврата строки SQL-запроса.

### 5. buildQuery()
```php
public function buildQuery()
```
- **Описание**: Конструирует SQL-запрос на основе примененных масок и условий.
- **Возвращает**: Строку SQL-запроса.

### 6. getRows($fetchMode)
```php
public function getRows($fetchMode = Zend_Db::FETCH_ASSOC)
```
- **Описание**: Извлекает отфильтрованные строки из базы данных.
- **Параметры**: 
  - `$fetchMode`: Режим выборки данных.
- **Возвращает**: Массив строк, соответствующих условиям фильтрации.

### 7. applyMask()
```php
public function applyMask()
```
- **Описание**: Применяет данные масок к условиям фильтрации.

### 8. addMask($maskOrData)
```php
public function addMask($maskOrData)
```
- **Описание**: Добавляет маску к фильтру.
- **Параметры**: 
  - `$maskOrData`: Маска или данные маски.

## Пример использования
Чтобы использовать класс `AbstractFilter`, обычно нужно расширить его и реализовать метод `getResultSql()`, чтобы определить конкретную логику SQL-запроса для вашего фильтра.

```php
class MyCustomFilter extends AbstractFilter {
    public function getResultSql(): string {
        // Реализуйте пользовательскую логику SQL здесь
    }
}
```

## Примечания
- Класс разработан для работы с компонентами базы данных [[Zend Framework]].
- Он поддерживает сложную фильтрацию с помощью масок и декораторов.
- Класс предоставляет методы для отладки SQL-запросов и эффективного управления условиями фильтрации.

## Заключение
Класс `AbstractFilter` является мощным инструментом для построения динамических SQL-запросов структурированным образом, позволяя гибкость и повторное использование в реализации фильтров.
