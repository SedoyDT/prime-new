# 🕐 Лучшие интервалы Pomodoro по типам задач

| Тип задачи                           | Рабочий блок | Отдых       | Когда использовать                             |
| ------------------------------------ | ------------ | ----------- | ---------------------------------------------- |
| **Простая/рутинная работа**          | 25–30 минут  | 5 минут     | Мало ментальной нагрузки, можно часто отдыхать |
| **Средняя сложность**                | 45–50 минут  | 7–10 минут  | Оптимально для устойчивого фокуса              |
| **Высокая сложность (творчество)**   | 60–90 минут  | 15–20 минут | Глубокая работа, требует входа в поток         |
| **Низкая концентрация / тренировка** | 15–20 минут  | 3–5 минут   | Для развития дисциплины и старта без давления  |
| **Глубокая фокусировка (эксперты)**  | 90–120 минут | 20–30 минут | Только при полном отсутствии отвлечений        |
