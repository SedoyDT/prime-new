# Создание структуры в БД  
- на основе выделенных сущностей необходимо спроектировать структуру таблиц  
- написать `SQL запросы` для создания и заполнения таблиц (можно использовать средства разработки)  
- в [директории](../../query) создать файл `amd-<JIRA_TASK_ID>.sql` и поместить в него ранее написанные запросы  
- если запросы ещё не были выполнены, выполнить их в локальной базе  
  
> Файл с [запросами](source/amd-1.sql) для создания и заполнения таблиц  
  
В итоге должны получить таблицы:  
- `counteragent` - для хранения данных контрагента  
- `counteragent_phone` - для хранения номеров контрагента  
- `counteragent_status` - заполненный каталог статусов контрагента  
- `counteragent_type` - заполненный каталог типов контрагентов  
  
### Создание сопутствующих таблице файлов  
Для генерации файлов необходимо выполнить команду (из корня проекта в контейнере Docker)  
```shell  
php bin/devconsole.php <APPLICATION_ENV> code-generator:generate-table counteragent counteragent_phone counteragent_status counteragent_type```  
  
Необходимо проверить:  
- в [application/configs/templatedb/tables](../../application/configs/templatedb/tables) должно добавиться четыре `.ini` файла, по одному на каждую таблицу  
- в [library/App/Db](../../library/App/Db) должно добавиться четыре `адаптера`, по одному на каждую таблицу  
- в файл [TableList.php](../../library/App/Constant/TableList.php) должно добавиться четыре константы, по одной на каждую таблицу  
  - необходимо проверить, что в файле нет изменений не связанных с задачей  
  
#### Таблицы с константами  
Необходимо доработать конфигурационные файлы каталожных таблиц  
[counteragent_status.ini](../../application/configs/templatedb/tables/counteragent_status.ini) и  
[counteragent_type.ini](../../application/configs/templatedb/tables/counteragent_type.ini):  
указать `catalog = 1` и заполнить раздел `[constant]` по примеру:  
  
```ini  
; Конфигурация для таблицы 0 - обычная, 1 = каталог  
[config]  
catalog = 1  
searchkey = "id"  
  
[constant]  
; Константы  
constant.key = 'alias'  
constant.value = 'id'  
constant.sort_field = 'alias'  
constant.comment_field = 'title'  
; Ключ = заголовок  
keyTitle.key = 'id'  
keyTitle.value = 'title'  
keyTitle.sort_field = 'title'  
keyTitle.comment_field = 'title'  
; Ключ = алиас  
keyAlias.key = 'id'  
keyAlias.value = 'alias'  
keyAlias.sort_field = 'title'  
keyAlias.comment_field = 'title'  
; Алиас = ключ  
aliasKey.key = 'alias'  
aliasKey.value = 'id'  
aliasKey.sort_field = 'title'  
aliasKey.comment_field = 'title'  
```  
  
Для создания файлов с константами выполнить команду:  
```shell  
php bin/devconsole.php <APPLICATION_ENV> code-generator:generate-catalog-table counteragent_status counteragent_type```  
  
Проверить что для каждой таблицы созданы файлы c константами:  
[TS константы](../../typescript/app/angular/generated/constant/table),  
[JS константы](../../public/js/constant/table),  
[PHP константы](../../library/App/Constant/Table).  
  
> Убедитесь, что для TS файлов сгенерированы JS файлы.  
  
> Выполните commit изменений, Вы должны находиться в ветке с задачей.
