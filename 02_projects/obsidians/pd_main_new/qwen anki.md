Что означает термин "hoisting" в JavaScript?:: 

Hoisting («поднятие») — это внутренний механизм JavaScript, при котором **объявления переменных** (через `var`) и **функций** поднимаются (перемещаются вверх) в начало их области видимости на этапе компиляции, до выполнения кода.  
⚠️ Однако, **инициализация переменных** (присвоение значения) не поднимается.

Пример:
```js
console.log(x); // undefined
var x = 5;
```
Будет интерпретировано как:
```js
var x;
console.log(x); // undefined
x = 5;
``` 
<!-- basicblock-end -->


<!-- basicblock-start oid="ObsigebJyQjIyqjjoPaS0gf6" deck='JavaScript' -->

Какой тип данных возвращается из функции `setTimeout()` в JavaScript?:: 

Функция `setTimeout()` возвращает **числовой идентификатор таймера** (`number`), который можно использовать для отмены таймера с помощью `clearTimeout()`.  

Пример:
```js
const timerId = setTimeout(() => {
  console.log('Привет');
}, 1000);

clearTimeout(timerId); // Отменяет выполнение
```

В браузерах идентификатор обычно представляет собой целое число, начиная с `1`, тогда как в Node.js это объект типа `Timeout`. 
<!-- basicblock-end -->


<!-- basicblock-start oid="ObsxM1QzGvoQzuiJAkPMBEF6" deck='JavaScript' -->

В чём разница между операторами `==` и `===` в JavaScript?:: 

Разница между `==` и `===` заключается в том, как они сравнивают значения:

| Оператор | Проверяет значение | Приводит типы | Проверяет тип |
|----------|--------------------|----------------|---------------|
| `==`     | ✅                 | ✅             | ❌            |
| `===`    | ✅                 | ❌             | ✅            |

- `==` — **нестрогий** оператор сравнения, пытается привести типы перед сравнением.
- `===` — **строгий** оператор, проверяет и значение, и тип.

Примеры:
```js
0 == false;   // true (оба приводятся к числу)
0 === false;  // false (разные типы: number vs boolean)

'5' == 5;     // true (автоматическое преобразование)
'5' === 5;    // false
```

Рекомендуется всегда использовать `===` для избежания неочевидного поведения. 
<!-- basicblock-end -->
