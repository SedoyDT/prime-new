# Анализ ТЗ  
  
## Выделение сущностей  
ТЗ содержит следующие сущности: `контрагент`, `номер телефона контрагента`.  
  
### Разбор сущности `Контрагент`  
`Контрагент` имеет следующие свойства:  
- наименование  
- ИНН  
- дата создания компании  
- номер счёта  
- возможность работы по ЭДО  
- тип контрагента  
- статус контрагента  
- номера телефонов  
  
`Тип контрагента` значение свойства ограниченно предопределенным набором, создадим для свойства  
каталожную таблицу со значениями: `Покупатель`, `Поставщик`.  
  
`Статус контрагента` значение свойства ограниченно предопределенным набором, создадим для свойства  
каталожную таблицу со значениями: `Действующий`, `Ликвидирован`, `В процессе ликвидации`.  
  
`Номера телефонов` это коллекция значений, для этого параметра будет создана сущность `Номер телефона контрагента`.  
  
### Разбор сущности `Номер телефона контрагента`  
`Номер телефона контрагента` имеет следующие свойства:  
- номер телефона  
- комментарий
