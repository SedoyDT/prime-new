Мне нужно для массива, содержащего все нужные элементы, которые должны быть отправлены на сервер проставить флаг is_active согласно элементам второго массива, содержащего только элементы, у которых is_active = 1 в первом массиве, то есть для остальных элементов первого массива значение is_active должно установиться в 0;


Вот **оптимальное и читаемое решение** на JavaScript для вашей задачи:

---

### ✅ Подход:
1. Создать **Set** из `field` (или другого уникального ключа) элементов второго массива — для O(1) поиска.
2. Пройтись по первому массиву и установить `is_active = 1`, только если элемент есть во втором массиве.

---

### 🧩 Код:
```js
// Первый массив — полный список всех полей (настройки по умолчанию)
const allFields = [
  { field: "name", field_title: "Название", is_active: 0 },
  { field: "stage", field_title: "Этап", is_active: 0 },
  { field: "planned_sum", field_title: "Планируемая сумма", is_active: 0 },
  { field: "actual_sum", field_title: "Фактическая сумма", is_active: 0 }
];

// Второй массив — только активные поля (is_active = 1)
const activeFields = [
  { field: "name", field_title: "Название", is_active: 1 },
  { field: "planned_sum", field_title: "Планируемая сумма", is_active: 1 }
];

// ✅ Решение:
const activeFieldSet = new Set(activeFields.map(item => item.field));

const fieldsToSend = allFields.map(item => ({
  ...item,
  is_active: activeFieldSet.has(item.field) ? 1 : 0
}));

console.log(fieldsToSend);
```

**Результат:**
```js
[
  { field: "name", field_title: "Название", is_active: 1 },
  { field: "stage", field_title: "Этап", is_active: 0 },
  { field: "planned_sum", field_title: "Планируемая сумма", is_active: 1 },
  { field: "actual_sum", field_title: "Фактическая сумма", is_active: 0 }
]
```

---

### 🔍 Почему так лучше:
- ⚡ **Производительно**: `Set.has()` работает за **O(1)**, в отличие от `.find()` или `.some()` в цикле (O(n²)).
- ✅ **Читаемо**: логика «включено, если есть в активных» — прозрачна.
- 🛡️ **Безопасно**: не мутирует исходные массивы (используем `.map()`).

---

### 💡 Альтернатива (если второй массив — просто список имён полей):
Если `activeFields` — это `[ "name", "planned_sum" ]`, то ещё проще:
```js
const activeFieldNames = ["name", "planned_sum"];
const fieldsToSend = allFields.map(item => ({
  ...item,
  is_active: activeFieldNames.includes(item.field) ? 1 : 0
}));
// Но лучше Set, если массив большой:
const activeSet = new Set(activeFieldNames);
// → .has(item.field)
```
