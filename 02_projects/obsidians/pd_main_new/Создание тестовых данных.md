Давайте разберем теоретическую основу и шаги для создания тестовых данных в вашем проекте.

### Цель создания тестовых данных

Создание тестовых данных — это важный шаг в разработке и тестировании программного обеспечения. Тестовые данные позволяют проверить, как система работает с различными сценариями и условиями, и выявить возможные ошибки или недочеты в логике приложения.

### Правила для тестовых данных

1. **Валидность данных:**
   - Данные должны соответствовать всем бизнес-правилам и ограничениям, определенным в системе. Это включает в себя корректные форматы, диапазоны значений и обязательные поля.

2. **Отсутствие дублирования:**
   - Данные не должны повторяться, чтобы избежать конфликтов и ошибок, связанных с уникальностью записей.

3. **Разнообразие типов и статусов:**
   - Контрагенты должны быть представлены всеми возможными типами и статусами, чтобы проверить, как система обрабатывает различные категории данных.

4. **Разное количество номеров:**
   - Контрагенты должны иметь от 1 до 3 номеров телефонов, чтобы проверить, как система обрабатывает коллекции связанных данных.

5. **Общее количество:**
   - В результате выполнения метода должно быть создано 100 контрагентов, что позволяет протестировать производительность и масштабируемость системы.

### Реализация метода `createTestDataAction`

1. **Генерация данных:**
   - Используйте циклы и случайные значения для генерации уникальных и разнообразных данных для каждого контрагента и его номеров телефонов.

2. **Создание контрагентов:**
   - Для каждого контрагента создайте объект модели, заполните его данными и добавьте номера телефонов.

3. **Сохранение данных:**
   - Используйте сервисы и репозитории для сохранения контрагентов и их номеров в базе данных.

4. **Проверка результатов:**
   - После выполнения метода проверьте, что данные корректно добавлены в таблицы `counteragent` и `counteragent_phone`.

### Пример кода для `createTestDataAction`

```php
public function createTestDataAction()
{
    for ($i = 0; $i < 100; $i++) {
        $counterAgent = new \App\Counteragent\Models\CounteragentModel();
        $counterAgent->setTitle('Контрагент ' . $i);
        $counterAgent->setInn(rand(100000000, 999999999));
        $counterAgent->setEstablishedAt(new DateTimeImmutable());
        $counterAgent->setAccountNumber(rand(100000000, 999999999));
        $counterAgent->setHasEdm(rand(0, 1));
        $counterAgent->setTypeId(rand(1, 2)); // Assuming 1 and 2 are valid type IDs
        $counterAgent->setStatusId(rand(1, 3)); // Assuming 1, 2, and 3 are valid status IDs
        $counterAgent->setComment('Тестовый комментарий');

        $phoneCount = rand(1, 3);
        for ($j = 0; $j < $phoneCount; $j++) {
            $phone = new \App\Counteragent\Models\CounteragentPhoneModel();
            $phone->setNumber(rand(70000000000, 79999999999));
            $phone->setComment('Тестовый номер ' . $j);
            $counterAgent->addPhone($phone);
        }

        $this->counteragentService->save($counterAgent);
    }

    echo "Создано 100 тестовых контрагентов"; exit;
}
```
