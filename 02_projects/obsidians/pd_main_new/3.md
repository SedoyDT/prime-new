Давайте перепишем ваш пример с паттерном "Стратегия" на TypeScript. Мы реализуем интерфейс, классы стратегий и калькулятор стоимости доставки в соответствии с концепцией, которую вы описали.

### 1. Интерфейс стратегии

Создадим интерфейс, который будет определять метод для расчета стоимости доставки:

```typescript
interface ShippingStrategy {
    calculateCost(weight: number, distance: number): number;
}
```

### 2. Реализация конкретных стратегий

Теперь создадим несколько классов, реализующих этот интерфейс. Каждый класс будет представлять конкретную стратегию расчета стоимости доставки:

```typescript
class RegularShipping implements ShippingStrategy {
    public calculateCost(weight: number, distance: number): number {
        return weight * 0.5 + distance * 1.2;
    }
}

class ExpressShipping implements ShippingStrategy {
    public calculateCost(weight: number, distance: number): number {
        return weight * 0.7 + distance * 1.5;
    }
}

class InternationalShipping implements ShippingStrategy {
    public calculateCost(weight: number, distance: number): number {
        return weight * 1.0 + distance * 2.5;
    }
}
```

### 3. Класс для расчета стоимости доставки

Создадим класс `ShippingCostCalculator`, который будет использовать одну из стратегий для расчета стоимости доставки:

```typescript
class ShippingCostCalculator {
    private strategy: ShippingStrategy;

    constructor(strategy: ShippingStrategy) {
        this.strategy = strategy;
    }

    public setStrategy(strategy: ShippingStrategy) {
        this.strategy = strategy;
    }

    public calculate(weight: number, distance: number): number {
        return this.strategy.calculateCost(weight, distance);
    }
}
```

### 4. Использование класса ShippingCostCalculator

Теперь мы можем использовать наш класс `ShippingCostCalculator` с различными стратегиями:

```typescript
const calculator = new ShippingCostCalculator(new RegularShipping());
console.log("Regular Shipping: " + calculator.calculate(10, 100));

calculator.setStrategy(new ExpressShipping());
console.log("Express Shipping: " + calculator.calculate(10, 100));

calculator.setStrategy(new InternationalShipping());
console.log("International Shipping: " + calculator.calculate(10, 100));
```

### Заключение

С помощью паттерна "Стратегия" вы можете легко менять алгоритмы во время выполнения программы, добавлять новые стратегии, не изменяя существующий код, и поддерживать структуру приложения. Этот подход хорошо подходит для приложений с изменяемыми алгоритмами, таких как бизнес-логика, игры и другие области, где требуется гибкость в выборе алгоритмов.
