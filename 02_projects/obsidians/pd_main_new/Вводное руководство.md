### Раздел 2: вводная задача  
В данном разделе необходимо выполнить `вводную задачу`.  
  
#### Требования раздела:  
- быть ознакомленным с `Разделом 1`  
- иметь настроенную [локальную среду](https://my-atlassian-site-131.atlassian.net/wiki/spaces/AMD/pages/970391558)  
  - должны быть настроены обработчики TS и SCSS  
- развернутый код из репозитория `amd-code-generator`, рекомендуется разместить на одном уровне с директорией локального проекта  
- иметь доступ к `Jira`, для доступа к задачам  
- иметь доступ к `Confluence`, для доступа к документации  
- иметь доступ к `AMD TimeTracker`, для доступа к дампам и ведения учёта времени  
- ознакомиться с [документацией](https://my-atlassian-site-131.atlassian.net/wiki/spaces/AMD/pages/1008238593)  
- создать новую ветку для задачи из `Jira` и выполнять задачу в этой ветке  
  
[Выполнение вводной задачи](OnboardTask/OnboardTask.md)
