Вот расширенная версия правил Декарта с дополнительными шагами и советами:

1. **Правило очевидности**
   - Исходите только из очевидного.
     - Выявите, что твердо установлено и отталкивайтесь от этого.
       * Проверяйте каждый факт независимо
       * Используйте только надежные источники информации
       * Задавайте вопросы "Что я знаю наверняка?" и "Как я это узнал?"
     - Догадки не являются хорошей стартовой точкой для логических рассуждений.
       * Отмечайте предположения как гипотезы
       * Проверяйте все предположения фактами
       * Избегайте привязанности к первоначальным гипотезам

2. **Правило анализа**
   - Разбивайте сложные вопросы на простые.
     - До тех пор, пока каждый простой вопрос не будет иметь очевидного решения.
       * Используйте метод "деления пополам"
       * Создавайте диаграммы разбиения проблемы
       * Ранжируйте подзадачи по сложности
     - Любое конечное число простых вопросов решается за конечное время; сложные вопросы могут показаться нерешаемыми вообще.
       * Устанавливайте временные рамки для каждого этапа
       * Фиксируйте промежуточные результаты
       * При необходимости возвращайтесь к предыдущим этапам

3. **Правило последовательности**
   - Переходите от известного к неизвестному.
     - Двигаться надо от простого (и уже известного) к сложному (пока еще не известному).
       * Создавайте карту зависимости элементов
       * Отмечайте решенные этапы
       * Документируйте процесс продвижения
     - Не сбиваться с последовательности, не забегать вперед.
       * Избегайте преждевременных выводов
       * Проверяйте соответствие текущего шага предыдущим
       * Используйте чек-листы для контроля последовательности

4. **Правило полноты**
   - Не оставляйте пробелов.
     - Если возникло несколько путей рассуждения – проверяйте все, а не только первый попавшийся.
       * Создавайте таблицы возможных вариантов
       * Оценивайте вероятность каждого пути
       * Документируйте отброшенные варианты
     - Любая промежуточная гипотеза должна быть закрыта, прежде чем перейти к окончательному выводу.
       * Проводите промежуточные проверки
       * Фиксируйте результаты тестирования гипотез
       * Создавайте отчеты по каждому этапу исследования

Дополнительные рекомендации:
- Ведите журнал рассуждений
- Используйте визуализацию (схемы, графики)
- Применяйте метод peer-review (проверка коллегами)
- Регулярно перепроверяйте сделанные выводы
- Документируйте все этапы исследования
- Используйте контрольные вопросы на каждом этапе
- Создавайте резервные планы на случай ошибок
- Проводите регулярные обзоры прогресса
