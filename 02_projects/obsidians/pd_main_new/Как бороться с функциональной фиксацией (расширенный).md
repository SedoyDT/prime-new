Вот расширенная версия в формате алгоритма с дополнительными шагами и советами:

**[[Как бороться с функциональной фиксацией]]**  
(Источник: Эдвард де Боно, Пол Слоун)

1. **Опишите задачу по-другому**
   - **Шаг 1:** Переформулируйте проблему своими словами.
     * Пример: "Как закрепить свечу на стене?" → "Как сделать, чтобы свеча не падала?"
   - **Шаг 2:** Используйте разные формулировки.
     * Задайте вопросы: "Что я действительно хочу достичь?", "Какие альтернативные цели можно поставить?"
   - **Шаг 3:** Упростите описание задачи.
     * Уберите лишние детали, оставьте только суть.
   - **Совет:** Попробуйте описать задачу как будто вы объясняете ее ребенку.

2. **Ищите аналогии, а не алгоритмы**
   - **Шаг 1:** Найдите похожие ситуации из других областей.
     * Пример: "Закрепление свечи" → "Как крепят картины на стене?"
   - **Шаг 2:** Проанализируйте, как решаются аналогичные задачи.
     * Используйте метод мозгового штурма для генерации идей.
   - **Шаг 3:** Примените найденные решения к своей задаче.
     * Адаптируйте идеи под текущую ситуацию.
   - **Совет:** Используйте технику SCAMPER для поиска аналогий.

3. **Играйте, а не сдавайте экзамен**
   - **Шаг 1:** Создайте расслабленную атмосферу.
     * Уберите давление времени и оценок.
   - **Шаг 2:** Экспериментируйте без страха ошибиться.
     * Попробуйте самые необычные идеи.
   - **Шаг 3:** Используйте игровые элементы.
     * Превратите задачу в игру или вызов.
   - **Совет:** Представьте, что вы помогаете любимому персонажу решить эту задачу.

4. **Переключайте режимы мышления**
   - **Шаг 1:** Определите текущий режим мышления.
     * Конвергентное (поиск одного решения) или дивергентное (генерация идей)?
   - **Шаг 2:** Сознательно меняйте режимы.
     * Если застряли на одном подходе, переключитесь на другой.
   - **Шаг 3:** Используйте техники латерального мышления.
     * Применяйте методы дерейлмента, фокусировки, сортировки.
   - **Совет:** Используйте "Шесть шляп мышления" для структурированного переключения.

### Дополнительные рекомендации:

1. **Практические упражнения:**
   - Решите задачу несколькими способами.
   - Попробуйте объяснить решение другому человеку.
   - Запишите все возможные варианты описания задачи.

2. **Примеры применения:**
   - **Тест Дункера:** Как закрепить свечу? → Используйте коробку как подставку.
   - **Задача с веревками:** Как достать до второй веревки? → Используйте груз для создания маятника.
   - **Календарь из кубиков:** Как разместить цифры? → Используйте 6/9 как универсальную грань.

3. **Частые ошибки:**
   - Привязка к первоначальной формулировке задачи.
   - Поиск только "правильных" решений.
   - Боязнь экспериментировать и делать ошибки.

4. **Чек-лист для проверки:**
   - Я переформулировал задачу хотя бы тремя способами?
   - Я нашел хотя бы одну аналогию из другой области?
   - Я создал расслабленную атмосферу для решения?
   - Я использовал разные режимы мышления?

Этот алгоритм помогает систематически преодолевать функциональную фиксацию, используя методы из книг Эдварда де Боно и Пола Слоуна.
