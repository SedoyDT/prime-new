Как работает декоратор метода ?::

Отлично! Этот код демонстрирует **декоратор метода в TypeScript**, который добавляет логирование вызовов метода. Давай разберём его по частям, с подробными комментариями и объяснениями.

---

## 🧠 Цель кода

Создать **декоратор метода `@logger`**, который будет:

- Логировать момент вызова метода
- Логировать аргументы, с которыми он вызван
- Логировать результат выполнения метода

---

## 🔍 Полный код с пояснениями

```ts
// 1. Определение декоратора метода `logger`
function logger(
    target: any,                 // целевой объект (prototype класса)
    propertyKey: string,        // имя метода, к которому применён декоратор
    descriptor: PropertyDescriptor  // дескриптор свойства (в данном случае — метода)
) {
    // Сохраняем оригинальный метод
    const originalMethod = descriptor.value;

    // Переопределяем метод на новую функцию, которая оборачивает оригинальный
    descriptor.value = function (...args: any[]) {
        // 1. Логируем вызов метода и его аргументы
        console.log(`Calling ${propertyKey} with args:`, args);

        // 2. Вызываем оригинальный метод с контекстом `this` и переданными аргументами
        const result = originalMethod.apply(this, args);

        // 3. Логируем результат работы метода
        console.log(`Result of ${propertyKey}:`, result);

        // 4. Возвращаем результат оригинального метода
        return result;
    };

    // Возвращаем изменённый дескриптор
    return descriptor;
}

// 2. Класс с методом, к которому применён декоратор
class Calculator {
    // Применяем декоратор @logger к методу add()
    @logger
    add(a: number, b: number): number {
        return a + b;
    }
}

// 3. Использование
const calc = new Calculator();
calc.add(2, 3);
```

---

## 📦 Что выведет этот код?

При вызове `calc.add(2, 3)` в консоль будет выведено:

```
Calling add with args: [2, 3]
Result of add: 5
```

## 🧱 Как это работает под капотом?

### 1. **Что такое декоратор метода?**

В TypeScript декоратор метода — это функция, которая получает три параметра:

| Параметр | Значение |
|----------|----------|
| `target` | Прототип класса (для экземплярных методов) или сам класс (для статических методов) |
| `propertyKey` | Имя метода (например `"add"`) |
| `descriptor` | Дескриптор свойства (объект типа `PropertyDescriptor`) |

### 2. **Как заменяется метод**

Декоратор изменяет `descriptor.value`, то есть тело функции метода. Он оборачивает его в другую функцию, которая:

- Логирует вызов
- Вызывает оригинальную реализацию (`originalMethod`)
- Логирует результат
- Возвращает результат

Таким образом, метод `add()` становится "умнее" — он не только складывает числа, но и пишет отладочную информацию.

## 🧪 Можно ли использовать с другими методами?

Конечно! Например:

```ts
class MathUtils {
    @logger
    multiply(a: number, b: number): number {
        return a * b;
    }
}

const utils = new MathUtils();
utils.multiply(5, 4);
```

Результат:
```
Calling multiply with args: [5, 4]
Result of multiply: 20
```

---

## ⚠️ Важные замечания

- Для использования декораторов в TypeScript нужно включить опцию в `tsconfig.json`:
  ```json
  {
    "experimentalDecorators": true
  }
  ```

- Декораторы методов **не работают в строгом режиме** без флага `"useDefineForClassFields": false` (по умолчанию в старых версиях TS).

## ✅ Преимущества такого подхода

- Упрощает логирование и трассировку вызовов
- Повторное использование поведения без дублирования кода
- Чистый синтаксис благодаря декораторам

---

## ❗ Возможные ограничения

- Может немного снижать производительность (из-за дополнительной обёртки)
- Сложно отлаживать при большом количестве декораторов
- Требует понимания контекста (`this`) и дескрипторов свойств
