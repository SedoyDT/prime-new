Для реализации паттерна проектирования, который позволит расширять функциональность без изменения существующего кода, можно использовать паттерн **Стратегия**. Этот паттерн позволяет создавать различные алгоритмы (стратегии) и выбирать одну из них во время выполнения, что делает код более гибким и расширяемым.

В вашем случае, можно создать несколько стратегий для отображения календаря (например, "месяц", "неделя", "день") и использовать их в классе `Calendar`. Это позволит вам легко добавлять новые режимы отображения, не изменяя существующий код.

### 1. Интерфейс стратегии

Создадим интерфейс для стратегий отображения календаря:

```typescript
interface IViewStrategy {
    render(state: TState): void;
}
```

### 2. Реализация конкретных стратегий

Теперь создадим конкретные стратегии для различных режимов отображения:

```typescript
class MonthViewStrategy implements IViewStrategy {
    render(state: TState) {
        console.log(`Rendering month view for ${state.months[state.currentMonth]} ${state.currentYear}`);
        // Логика рендеринга для месячного представления
    }
}

class WeekViewStrategy implements IViewStrategy {
    render(state: TState) {
        console.log(`Rendering week view for ${state.months[state.currentMonth]} ${state.currentYear}`);
        // Логика рендеринга для недельного представления
    }
}

class DayViewStrategy implements IViewStrategy {
    render(state: TState) {
        console.log(`Rendering day view for ${state.months[state.currentMonth]} ${state.currentYear}`);
        // Логика рендеринга для дневного представления
    }
}
```

### 3. Обновление класса Calendar

Теперь обновим класс `Calendar`, чтобы он использовал стратегию для рендеринга:

```typescript
class Calendar {
    private viewStrategy: IViewStrategy;

    constructor(private state: State) {
        this.state.subscribe(this.update.bind(this));
        this.viewStrategy = new MonthViewStrategy(); // Установка стратегии по умолчанию
    }

    // Установка стратегии отображения
    public setViewStrategy(strategy: IViewStrategy) {
        this.viewStrategy = strategy;
        this.update(this.state.getState()); // Обновление представления при смене стратегии
    }

    // Обновление представления
    public update(state: TState) {
        console.log("Current State:", state);
        this.viewStrategy.render(state); // Используем стратегию для рендеринга
    }

    // Пример методов для управления состоянием
    public changeMonth(month: number) {
        this.state.setCurrentMonth(month);
    }

    public changeYear(year: number) {
        this.state.setCurrentYear(year);
    }

    public createEvent(title: string, date: Date) {
        this.state.addEvent(title, date);
    }
}
```

### 4. Использование новых стратегий

Теперь вы можете легко менять стратегию отображения в вашем приложении:

```typescript
const initialState: TState = {
    currentYear: 2023,
    currentMonth: 10,
    months: {
        0: 'January',
        1: 'February',
        2: 'March',
        3: 'April',
        4: 'May',
        5: 'June',
        6: 'July',
        7: 'August',
        8: 'September',
        9: 'October',
        10: 'November',
        11: 'December',
    },
    viewMode: 'month',
    days: {
        0: 'Sunday',
        1: 'Monday',
        2: 'Tuesday',
        3: 'Wednesday',
        4: 'Thursday',
        5: 'Friday',
        6: 'Saturday',
    },
    link: '',
    systemLanguage: 'en',
    prevState: null,
    events: [],
};

const state = new State(initialState);
const calendar = new Calendar(state);

// Пример изменений
try {
    calendar.changeMonth(11);
    calendar.changeYear(2024);
    calendar.createEvent("Meeting on December 15", new Date(2024, 11, 15));
    
    // Меняем стратегию отображения
    calendar.setViewStrategy(new WeekViewStrategy());
    calendar.setViewStrategy(new DayViewStrategy()); // Меняем на дневное представление
} catch (error) {
    console.error(error);
}
```

### Заключение

С помощью паттерна **Стратегия** вы можете добавлять новые режимы отображения без изменения существующего кода, что соответствует принципу открытости/закрытости из SOLID. Теперь, если вам нужно добавить новый режим (например, "список событий"), вам просто нужно создать новый класс, реализующий интерфейс `IViewStrategy`, и установить его в `Calendar`. Это сделает ваш код более гибким и удобным для расширения.
