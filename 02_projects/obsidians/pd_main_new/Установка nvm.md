Для установки `nvm` (Node Version Manager) выполните следующие шаги:

### Установка `nvm`

1. **Откройте терминал**.

2. **Скачайте и установите `nvm`**. Вы можете использовать одну из следующих команд в зависимости от вашего инструмента загрузки:

   - С помощью `curl`:
     ```bash
     curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash
     ```

   - С помощью `wget`:
     ```bash
     wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash
     ```

3. **Перезагрузите терминал** или выполните следующую команду, чтобы загрузить `nvm` в текущую сессию:
   ```bash
   source ~/.bashrc
   ```
   (или `source ~/.zshrc`, если вы используете Zsh).

4. **Проверьте установку**. Убедитесь, что `nvm` установлен, выполнив:
   ```bash
   nvm --version
   ```

### Установка Node.js с помощью `nvm`

После установки `nvm` вы можете установить Node.js:

1. **Установите последнюю версию Node.js**:
   ```bash
   nvm install node
   ```

2. **Или установите конкретную версию** (например, 14.17.0):
   ```bash
   nvm install 14.17.0
   ```

3. **Переключитесь на установленную версию**:
   ```bash
   nvm use 14.17.0
   ```

Теперь `nvm` установлен, и вы можете управлять версиями Node.js!
