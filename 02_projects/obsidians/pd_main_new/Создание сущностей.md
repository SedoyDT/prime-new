# Создание сущностей  
  
## Создание классов  
  
### Контрагент  
  
Для создания класса `модели` выполните команду:   
```shell  
../amd-code-generator/bin/console mapping:table-to-model -a <APPLICATION_ENV> library/App/Counteragent/Models/CounteragentModel.php counteragent```  
В результате должен создаться класс модели [CounteragentModel.php](../../library/App/Counteragent/Models/CounteragentModel.php).  
  
> Создайте `геттеры` и `сеттеры` для всех свойств (используйте генератор IDE).  
  
#### Создание conditions, hydrator, mapper  
Для создания классов выполните команду:  
```shell  
../amd-code-generator/bin/console mapping:full library/App/Counteragent/Models/CounteragentModel.php```  
В результате должны быть созданы классы:  
- [CounteragentConditions.php](../../library/App/Counteragent/Repositories/Db/CounteragentModel/CounteragentConditions.php)  
- [CounteragentHydrator.php](../../library/App/Counteragent/Repositories/Db/CounteragentModel/CounteragentHydrator.php)  
- [CounteragentMapper.php](../../library/App/Counteragent/Repositories/Db/CounteragentModel/CounteragentMapper.php)  
  
#### Создание репозитория  
Для создания репозитория выполните команду:  
```shell  
../amd-code-generator/bin/console mapping:repository library/App/Counteragent/Models/CounteragentModel.php```  
В результате должен быть создан класс [CounteragentRepository.php](../../library/App/Counteragent/Repositories/CounteragentRepository.php).

## Применение созданных классов  
> Действия выполнять в [песочнице](../../application/modules/development/controllers/IndexController.php).  
> Ознакомьтесь с [правилами](../ProjectStructure/Development.md) работы в песочнице.   
  
> Необходимо знать как использовать [внедрение зависимостей](../ProjectStructure/DependencyInjection.md)  
  
#### Внедрите репозиторий [CounteragentRepository.php](../../library/App/Counteragent/Repositories/CounteragentRepository.php) в [контроллер](../../application/modules/development/controllers/IndexController.php):  
```php  
/**  
 * @var \App\Counteragent\Repositories\CounteragentRepository * @Inject */protected $counteragentRepository;  
```  
  
#### Напишите action для добавления контрагента в базу:  
```php  
public function createCounteragentAction(): \App\Counteragent\Models\CounteragentModel  
{  
    // Создание и настройка модели    $counterAgent = new \App\Counteragent\Models\CounteragentModel();    $counterAgent->setTitle('Название контрагента');    $counterAgent->setInn(123456789);    $counterAgent->setEstablishedAt(new DateTimeImmutable());    $counterAgent->setAccountNumber(123456789);    $counterAgent->setHasEdm(1);    $counterAgent->setTypeId(App_Constant_Table_CounteragentType::CUSTOMER);    $counterAgent->setStatusId(App_Constant_Table_CounteragentStatus::ACTIVE);    $counterAgent->setComment('Комментарий');  
    // Сохранение в базу    $this->counteragentRepository->save($counterAgent);  
    echo "Создан контрагент: Id:" . $counterAgent->getId() . "<br>";    echo "<pre>"; print_r($counterAgent); echo "</pre>"; exit;}  
```  
Проверьте работу метода перейдя по ссылке `/development/index/create-counteragent`:  
- В таблице counteragent должен появиться новый контрагент.  
  
#### Напишите метод для поиска контрагента по Id:  
  
Создайте новый метод `findById` в [репозитории](../../library/App/Counteragent/Repositories/CounteragentRepository.php)  
```php  
public function findById(?int $id): ?CounteragentModel  
{  
    if ($id <= 0) {        return null;    }  
    $condition = new \App\Counteragent\Repositories\Db\CounteragentModel\CounteragentConditions();    $condition->getId()->equal($id);  
    return $this->findOne($condition);}  
```  
  
Создайте новый action в [контроллере](../../application/modules/development/controllers/IndexController.php)  
```php  
public function findCounteragentAction(): ?\App\Counteragent\Models\CounteragentModel  
{  
    $id = (int) $this->_getParam('id');  
    if (!$id) {        exit("Невалидный Id");    }  
    $counteragent = $this->counteragentRepository->findById($id);  
    if (!$counteragent) {        echo "Контрагент не найден"; exit;    }  
    echo "Контрагент найден <br>";    echo "<pre>"; print_r($counteragent); echo "</pre>"; exit;}  
```  
Проверьте работу метода перейдя по ссылке `/development/index/find-counteragent/id/<CounteragentId>`.
