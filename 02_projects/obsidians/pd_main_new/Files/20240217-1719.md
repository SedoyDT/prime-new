**Определено в:** [yii\\base\\Component::\_\_call()](https://www.yiiframework.com/doc/api/2.0/yii-base-component#__call()-detail)

**Вызывает указанный метод, который не является методом класса.**

Этот метод будет проверять, есть ли установленное поведение с указанным методом и выполнит его, если оно доступно.

Не вызывайте этот метод напрямую, так как он является магическим методом PHP, который будет неявно вызван при вызове неизвестного метода.
