1. Демпферная насадка
	1. Самая универсальная  
		1. 👉 Мягкое, «безопасное» воздействие
		2. 👉 Подходит для всего тела
			1. 📌 Используй
				- если есть тревожность/напряжение
				- перед сном
				- если мышцы болят
		- 💡 Это реально база — 80% людей используют её чаще всего
2. Клиновая насадка
	1. 👉 Плоская и жёсткая  
	2. 👉 Делает эффект «скребка»
	3. - лопатки
	4. IT-band (бок бедра)
	5. «разглаживание» мышц
	6. 💡 Она реально имитирует техники типа гуаша и помогает «разгонять» мышцы
3. Насадка для термотерапии холодом
	1. Уже уровень выше  
	2. 👉 Не просто бьёт, а
	3. охлаждает
	4. снижает воспаление
	5. 📌 Используй:
	6. после тренировки
	7. при воспалении/перегрузе
	8. при боли
	9. 💡 Это больше «восстановление», чем массаж
4. Стандартная шаровая насадка
	1. уть жёстче демпфер
	2. Более «глубокий» массаж
	3. Это «рабочая лошадка» для мышц
5. Зубчатая насадка
	1. Не столько для мышц, сколько для нервной системы
	2. разогрев
	3. стимуляция кожи
	4. лёгкий массаж
	5. Даёт ощущение «иголочек» — непривычно, но прикольно
6. Согревающая насадка
	1. расслабляет глубже
	2. усиливает кровоток
	3. уменьшает скованность
7. Вибрационная насадка
	1. снижает напряжение без боли
	2. лучшает кровоток
	3. подходит для суставов и чувствительных зон

## ⚡ Готовые схемы (без теории)

### 😌 Расслабление / тревожность

1. Вибрация
2. Демпфер
3. (опционально) тепло

👉 максимально мягкий сценарий
