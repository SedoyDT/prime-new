Вот как это делается:

### 1. **Добавление заголовка к таблице через Markdown**
Просто напишите заголовок перед блоком Dataview, используя заголовок уровня 2 (`##`) или выше:

```markdown
## Список задач
```dataview
table file.name as "Задача", status as "Статус"
from "tasks"
```
```

> ✅ Результат: В вашей заметке появится заголовок `Список задач`, под которым будет отображаться таблица.

---

### 2. **Динамический заголовок с условием (опционально)**
Если вы хотите, чтобы заголовок зависел от данных (например, количество задач), используйте `= ` для вычисления:

```markdown
## Количество активных задач: = (dataview.api.query("TASKS", "from 'tasks' where status = 'active'").length)
```dataview
table file.name as "Задача", status as "Статус"
from "tasks"
where status = "active"
```
```

> 🔍 Это полезно, если вы хотите динамически обновлять заголовок в зависимости от данных.

---

### 3. **Стилизация заголовка (по желанию)**
Если хотите сделать заголовок более заметным, используйте **стили** через HTML (внутри Markdown):

```markdown
<h2 style="color: #4a90e2; border-bottom: 1px solid #4a90e2; padding-bottom: 5px;">📋 Список задач</h2>
```dataview
table file.name as "Задача", status as "Статус"
from "tasks"
```
```

> 💡 Подсказка: HTML-теги работают в Obsidian, если включён режим редактирования Markdown.
