# ⏱️ 8-ЧАСОВОЙ MVP ПЛАН (BOOTSTRAP AISD CORE)

## 🎯 ЦЕЛЬ 8 ЧАСОВ

Собрать **не систему**, а:

> 🔹 рабочий “скелет автономного dev-оркестратора”  
> 🔹 event-driven backbone  
> 🔹 минимальный AI-loop (идея → задача → код → проверка → лог)

Без лишней философии. Только то, что реально запускается.

---

# 🧱 ЧТО ДОЛЖНО СУЩЕСТВОВАТЬ В КОНЦЕ 8 ЧАСОВ

Минимальный результат:

- Docker-compose (Postgres + Redis + NATS)
    
- Python backend (FastAPI или worker service)
    
- 2–3 агента (минимальные версии):
    
    - idea-generator
        
    - dev-orchestrator
        
    - code-generator (stub + LLM call)
        
- event bus flow (NATS)
    
- таблицы Postgres:
    
    - ideas
        
    - tasks
        
    - code_artifacts
        
    - events_log
        
- git workflow:
    
    - main
        
    - ai/auto-branching system (stub)
        
- CLI или простой endpoint для запуска pipeline

# ⏱️ РАЗБИВКА ПО ЧАСАМ

---

## 🧩 0–1 ЧАС — ФУНДАМЕНТ СИСТЕМЫ

### 📦 Делается:

- создаётся репозиторий:
    
    ```
    aisd-core/
    ```
    
- структура:
    

```
/infra
  docker-compose.yml

/services
  idea-generator/
  dev-orchestrator/
  code-generator/

/shared
  events.py
  schemas.py

/db
  migrations.sql
```

---

### 🐳 Docker-compose:

- Postgres
    
- Redis
    
- NATS
    

👉 цель: просто поднять инфраструктуру

---

## 🧠 1–2 ЧАС — EVENT BUS (NATS CORE)

### 📌 Делается:

- подключение NATS client
    
- базовые события:
    

```
idea.created
task.created
code.requested
code.generated
code.validated
```

---

### 🧪 тест:

CLI отправляет event:

```
idea.created → NATS → logger subscriber
```

---

## 🧠 2–3 ЧАС — POSTGRES + STATE MODEL

### 📌 таблицы:

- ideas
    
- tasks
    
- code_artifacts
    
- event_log
    

---

### 📌 логика:

- каждый event сохраняется в events_log
    
- state НЕ хранится в агентах
    

👉 правило:

> агенты stateless, всё в Postgres

---

## 🧠 3–4 ЧАС — IDEA → TASK PIPELINE

### 🤖 agent: idea-generator

вход:

- текст / заметка / CLI input
    

выход:

- структурированная идея
    

---

### 🤖 agent: dev-orchestrator

делает:

```
idea.created
→ анализ
→ task.generated
→ event emit
```

---

### результат:

- идея автоматически превращается в задачу
    

---

## 🧠 4–5 ЧАС — CODE GENERATOR (СТУБ + LLM HOOK)

### 🤖 agent: code-generator

минимальная версия:

- принимает task
    
- создаёт структуру файлов
    
- вызывает LLM (Qwen via LM Studio API)
    
- пишет код в директорию:
    

```
/workspace/ai_branch_xxx/
```

---

### git:

- создаёт branch:
    

```
ai/task-{id}
```

---

### output:

- code.generated event
    

---

## 🧠 5–6 ЧАС — CODE VALIDATOR

### 🤖 agent: code-validator

проверяет:

- есть ли файлы
    
- базовый lint (optional)
    
- простые тесты (если есть)
    
- sanity check (run script)
    

---

### результат:

- approved
    
- needs_fix
    

---

### event:

```
code.validated
```

---

## 🧠 6–7 ЧАС — FULL PIPELINE LOOP

Собирается цикл:

```
idea → task → code → validate → log
```

---

### добавляется:

- retry loop
    
- простая маршрутизация событий
    
- logging всех шагов
    

---

## 🧠 7–8 ЧАС — UX + УПРАВЛЕНИЕ

### минимальный интерфейс:

- CLI:
    

```
python run.py "make todo app"
```

или FastAPI:

```
POST /idea
POST /run-pipeline
```

---

### вывод:

- статус pipeline
    
- лог событий
    
- путь к сгенерированному коду
