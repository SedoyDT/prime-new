- делает изменения в коде

### 🔁 система

- git (обязательно)

# 🧪 2. УСТАНОВКА ОКРУЖЕНИЯ

## создать venv

```bash
uv venv ai-env

```

---

## установить aider

```bash
uv pip install aider-chat
```

# 🧠 3. НАСТРОЙКА LM STUDIO

## включить сервер

В LM Studio:

- включить **Local Server**
    
- OpenAI-compatible API
    

обычно:

```text
http://localhost:1234/v1
```

---

## загрузить модель

- qwen/qwen3-30b-a3b-2507
    
- нажать RUN
