# Что ты сделал

Ты фактически собрал базу для portable terminal-first development среды 🍏⚙️

Не “редактор поставил”.  
А именно фундамент системы разработки.

# Что было установлено

## Основной стек

|Инструмент|Зачем|
|---|---|
|Neovim|редактор|
|LazyVim|готовая современная конфигурация|
|tmux|терминальные сессии|
|lazygit|git UI|
|`ripgrep`|быстрый поиск|
|`fzf`|fuzzy search|

|`node`|нужен для LSP/plugins|

# Что теперь умеет среда

## ✅ Кросс-OS workflow

Ты можешь почти одинаково работать на:

- macOS
    
- Linux
    
- remote servers
    
- VPS
    
- Docker
    
- SSH
    

---

## ✅ LSP и автокомплит

Ты установил Python language server (`pyright` или `basedpyright`).

Теперь есть:

- автокомплит
    
- подсветка ошибок
    
- переход к определениям
    
- rename symbols
    
- hover docs
    

---

## ✅ Terminal-first подход

Это важно.

Ты двигаешься к архитектуре:

```text
terminal + git + tmux + nvim + AI
```

И это сейчас очень сильная комбинация для:

- AI-assisted coding
    
- remote dev
    
- automation
    
- автономных процессов

# 2. Главные hotkeys LazyVim

|Клавиши|Что делают|
|---|---|
|`Space Space`|найти файл|
|`Space e`|explorer|
|`Space /`|поиск текста|
|`Shift+h/l`|переключение буферов|

---

# 3. Базовые vim-команды

|Команда|Действие|
|---|---|
|`dd`|удалить строку|
|`yy`|копировать|
|`p`|вставить|
|`:w`|сохранить|
|`:q`|выйти|
|`:wq`|сохранить и выйти|

---

# 4. tmux база

|Команда|Действие|
|---|---|
|`tmux`|запуск|
|`Ctrl+b c`|новое окно|
|`Ctrl+b n`|следующее окно|
